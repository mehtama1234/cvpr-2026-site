1 · The original job: end-to-end detection, made to converge

DETR did one bold thing: it stopped treating detection as a pile of overlapping guesses to be filtered, and instead handed the model a fixed set of learnable slots called object queries, each responsible for emitting at most one object. Training uses Hungarian matching to pair every prediction with at most one real object, so there is no need for anchors or a non-maximum-suppression cleanup step at the end. The catch is that these queries are slow to specialize, and the whole scheme assumes a stable, closed world of classes seen all at once. The four papers here take that same query-and-match machinery and stretch it to harder settings: a world where new classes and new domains keep arriving, where only a handful of labeled examples exist, and even where the thing being detected is a thin edge rather than a boxed object. Across all of them the through-line is the same primitive — a set of slots each emit one thing, matched one-to-one to the truth. Read together, they show how much of modern detection is really about keeping that end-to-end matching idea working as the problem gets messier.
CVPR'26EW-DETR: Evolving World Object Detection via Incremental Low-Rank DEtection TRansformer
Problem
A real detector deployed in the wild faces three headaches at once: new object classes keep appearing, the visual conditions shift (think day versus night versus fog), and it will run into objects it was never taught to name. Most methods handle only one of these, and many cheat by keeping a stash of old training images to rehearse on, which is often blocked by storage limits or privacy. This paper asks how one DETR-based detector can grow with an evolving world without ever storing past data.
Approach
EW-DETR bolts three lightweight modules onto a DETR detector. It adds small low-rank LoRA adapters that absorb each new batch of classes and are merged in a data-aware way so old knowledge is not overwritten, and it introduces a Query-Norm Objectness Adapter that separates what a query means from how strong its signal is, making the queries robust when the domain shifts. A final entropy-aware step lets leftover, unmatched queries flag genuinely unknown objects with a calibrated confidence.
Why it matters
This is set prediction under pressure: the same fixed pool of object queries must keep emitting a clean one-object-per-slot set even as classes and domains drift. By stabilizing the query representations and reusing the leftover, un-matched queries as an unknown-object detector, it honors the one-to-one matching contract while extending it to a world that never stops changing.
CVPR'26A Closer Look at Cross-Domain Few-Shot Object Detection: Fine-Tuning Matters and Parallel Decoder Helps
Problem
Suppose you have a strong detector but must adapt it to a brand-new domain — a niche industrial dataset, say — using only a few labeled examples per class. With so little data the training is jittery and the model generalizes poorly, and the domain gap makes it worse. The paper takes a careful look at what actually helps here and finds that the fine-tuning recipe, not fancy tricks, matters most.
Approach
They keep the transformer decoder but run several parallel decoder branches that share the lower layers, each fed denoising queries so the branches produce diverse, complementary guesses that are then ensembled — and crucially this reuses existing weights, adding no new parameters. Wrapped around it is a progressive fine-tuning schedule with plateau-aware learning-rate adjustment that keeps the few-shot optimization from destabilizing.
Why it matters
The object queries are still the unit of prediction, matched one-to-one to ground truth, but here the decoder is duplicated into parallel branches so several sets of query-emitted predictions can vote. It is the set-prediction decoder used as an ensemble: more diverse query outputs, same end-to-end matched-set backbone, tuned to survive on only a handful of examples.
CVPR'26Parameterized Prompt for Incremental Object Detection
Problem
When you teach a detector new classes step by step, it tends to forget the old ones — the classic catastrophic-forgetting problem. A popular fix is to keep a pool of small prompt vectors, one chunk per task, but those pools are discrete and brittle and do not transfer cleanly across different detector backbones. This work wants incremental learning that adds classes over time without a growing bag of fragile prompt pieces and without storing old images.
Approach
P2IOD replaces the discrete prompt pool with a small MLP that generates a task-specific prompt injected into a DETR-family backbone like Deformable-DETR or Co-DETR. When a new step is done, three ingredients fuse the old and new knowledge: keeping the top-k most important prompt parameters, aligning the direction of parameter updates across steps, and a sparse penalty that pushes each step to use different parameters so they do not interfere — with pseudo-labels standing in for the old data.
Why it matters
The detector underneath is still a query-based, one-to-one matched DETR — the prompts simply steer which objects its queries specialize on at each stage. By conditioning that fixed set of object queries with smoothly-mergeable prompts instead of rigid pool entries, the same matched-set decoder can keep emitting correct object sets for both old and new classes.
CVPR'26MatchED: Crisp Edge Detection Using End-to-End Matching-based Supervision
Problem
Edge detectors ideally output thin, one-pixel-wide lines, but in practice they produce fuzzy responses that need hand-crafted cleanup — non-maximum suppression and thinning — to sharpen. Those cleanup steps are non-differentiable, so the network can never actually learn to make crisp edges; it just gets tidied up afterward. The paper wants the crispness to come from training itself, end to end.
Approach
MatchED is a tiny plug-and-play module (about 21K parameters) that you append to any edge detector. Each training iteration it performs a one-to-one match between predicted edge pixels and ground-truth edge pixels, using both spatial distance and confidence, and supervises the network so that exactly one prediction lines up with each true edge point — the same criterion used at test time, so training and evaluation finally agree.
Why it matters
This is DETR-style bipartite matching carried out of boxes and into pixels: instead of queries matched one-to-one to objects, predicted edge points are matched one-to-one to true edge points, and that matching is the training signal. By making the assignment differentiable it replaces the hand-designed non-maximum-suppression cleanup with end-to-end learning — the very move that set prediction made for detection, applied to edges.

2 · Beyond boxes: set prediction for segments, instances, and occupancy

DETR taught detectors a new trick: instead of scoring a dense grid of anchor boxes and cleaning up with non-maximum suppression, you hand a transformer a small set of learnable object queries and train each one, through Hungarian one-to-one matching, to claim exactly one object from the scene. The surprising thing is that nothing about that recipe is specific to boxes. A query is just a slot that gathers evidence and emits one thing, so the same machinery works whenever the answer is a set of items. The papers here carry the idea past the bounding box: one query per 3D instance mask, per class of point-cloud object, per language-referred segment, or per amodal shape. Along the way they wrestle with the classic set-prediction failure mode of queries colliding on the same target, and with how to condition queries on text, clicks, or self-supervision instead of learning them blind. Read together, they show set prediction becoming a general interface for structured output, not just a detection algorithm.
CVPR'26CompetitorFormer: Mitigating Query Conflicts for 3D Instance Segmentation via Competitive Strategy
Problem
In transformer-based 3D instance segmentation, the model hands a set of queries to a point cloud and asks each to carve out one object. The trouble is that several queries often pile onto the same instance, which splits one object into fragmented masks and makes training slow to settle.
Approach
CompetitorFormer makes the rivalry between queries explicit instead of hoping attention sorts it out. A Query Competitor Layer builds a competitive landscape from where query predictions spatially overlap and how confident each is, Relative Relationship Encoding adds that context as a bias inside self-attention, and Rank Cross-Attention normalizes competitively so the dominant query for a region gets to aggregate its features while rivals back off.
Why it matters
This is a direct fix to the core promise of set prediction: each item in the set should be claimed by exactly one query. Hungarian matching enforces that one-to-one assignment at the loss, but here the model also teaches the queries to negotiate who owns what, so the emitted set stays clean rather than redundant.
CVPR'26QueryOcc: Query-based Self-Supervision for 3D Semantic Occupancy
Problem
Predicting the full 3D shape and semantics of a driving scene from cameras normally needs expensive hand-labeled 3D annotation. Self-supervised alternatives lean on indirect 2D rendering tricks or chop space into coarse voxels, which blurs geometric detail.
Approach
QueryOcc supervises occupancy with 4D spatio-temporal queries that probe points in continuous space across neighboring frames, so each query asks what is present and what class it is at a specific location and time, without rendering losses or lidar voxelization. A contractive scene representation, built with a lift-contract-splat step, keeps near-field detail sharp while compressing far-away regions, giving long-range supervision at roughly constant memory.
Why it matters
It stretches the query-emits-one-thing idea from discrete objects to continuous space: rather than one query per object, a query samples one point of the world and reports its occupancy and label. The set being predicted is the occupied, semantically-tagged geometry of the scene itself, showing set prediction at work on dense structure instead of sparse boxes.
CVPR'26SAQN: Semantic-based Adaptive Query Network for 3D Referring Expression Segmentation
Problem
3D referring expression segmentation asks a model to find and mask the point-cloud object that a sentence describes. Methods that give each candidate instance its own query miss the class-level meaning in the words and stumble when a phrase refers to several objects at once.
Approach
SAQN uses a small pool of class-level learnable queries, each conditioned on the language through cross-attention, rather than one query per instance. A Multi-Query Interaction module cycles each query through attention to the 3D points, to the other queries, and to the text tokens, while an Adaptive Query Fusion module folds in extra adaptive queries weighted by spatial priors from the predicted masks and by query-to-query semantic similarity.
Why it matters
It keeps the set-prediction skeleton but changes what a query stands for, from one instance to one semantic category, and makes the query text-aware so language steers which member of the set fires. Multi-object phrases fall out naturally because several point clusters can be emitted under the same class query.
CVPR'26Learning and Aligning Click-Aware Shape Prior for Interactive Amodal Instance Segmentation
Problem
Amodal segmentation has to recover an object's complete mask, including the parts hidden behind other things. Because there is no visual evidence for the occluded region, models fall back on stored shape priors, but a prior that fits one object badly misfits another at test time.
Approach
ClickPriorNet lets a user click on the object to steer which shape prior gets pulled and how it is fitted. A triplet loss trains the retrieval so the chosen prior overlaps well with the true amodal mask, and deformable attention warps that prior to align with the specific instance, after which previous mask, clicks, backbone features, and the aligned prior are combined for iterative refinement.
Why it matters
The click plays the role of a conditioned query: it selects one object from the scene and drives the model to emit that single object's full shape. It carries set prediction into amodal reasoning, where the thing emitted is not a visible mask but a completed shape guessed for the hidden part.

3 · The query as a universal interface: counting, grounding, interactions

DETR made the query — a learnable slot that attends to the image and emits exactly one answer — the atomic unit of prediction, with Hungarian matching assigning at most one query to each ground-truth object. Once a slot can stand for an object here, nothing forces that answer to be a box: the same mechanism can make a slot stand for a region to count, a human-object interaction, an event in a video, or a moment matching a phrase. These four papers all inherit the DETR decoder and then reshape what the slots mean and how they are matched. One mines multi-level visual-language context so each instance query reasons about intra-instance, neighbor, and scene cues before emitting an interaction. One splits queries by role — separate localization and caption slots — and adds losses that keep them from collapsing onto each other. One filters and re-purposes hundreds of object queries by what not to count, and one diagnoses the failure mode when too many query slots go silent. Read together they show the query is less a detection trick than a general programmable interface: define what one slot should mean, define how slots are matched, and the same set-prediction machinery answers a new question.
CVPR'26Mining Instance-Centric Vision-Language Contexts for Human-Object Interaction Detection
Problem
HOI detection has to localize a human-object pair and name the interaction, and vision-language priors help — but existing methods either smear context uniformly across every instance or trap it inside object-bound regions. That leaves the nuanced cues that actually distinguish interactions unused.
Approach
InCoM-Net builds three context levels for each instance from CLIP features using scene-adaptive masks — intra-instance (cues on the target), inter-instance (relations to surrounding objects), and global scene — then a Progressive Context Aggregation module iteratively fuses them into the DETR detector instance features via cross-attention, layer by layer. Masked Feature Training randomly drops either the VLM or the detector stream so no single source dominates.
Why it matters
The DETR instance feature is the query slot — the learnable vector that attends out and returns one human-object pair. Here the paper does not change matching; it enriches what each slot carries before it emits its one answer, turning a detection query into a context-aware interaction query. The set-prediction skeleton is untouched; only the meaning packed into each slot grows.
CVPR'26CountGD++: Generalized Prompting for Open-World Counting
Problem
Open-world counters can say what to count but never what not to count, so visually similar classes — red versus white blood cells, ripe versus unripe fruit — blur together. They also demand a fresh hand-drawn visual exemplar per image and cannot borrow examples from outside the picture.
Approach
Built on Grounding DINO, COUNTGD++ feeds positive and negative text and visual prompts into the encoder, keeping self-attention within matching polarity so positives and negatives do not contaminate each other. Its Cross-Modality Interaction module produces 900 object queries, which are kept only when a query matches a positive prompt more strongly than any negative one; a first pass then harvests top-scoring boxes as pseudo-exemplars to refine a second pass.
Why it matters
Counting here is DETR set prediction with the count read off the surviving queries: 900 slots each emit one candidate object, and the answer is how many pass the prompt filter. The novelty is the matching rule — a slot lives or dies by out-scoring the negatives — so the prompt reprograms which slots are allowed to fire without touching the one-slot-one-object contract.
CVPR'26Stay in your Lane: Role Specific Queries with Overlap Suppression Loss for Dense Video Captioning
Problem
DETR-based dense video captioning makes each query do two jobs — localize an event and describe it — and the shared slot causes task interference plus redundant, overlapping event predictions. Earlier decompositions merely MLP-project one query set into another, so the two roles end up with nearly identical attention.
Approach
ROS-DVC initializes two independent query sets from separate embedding spaces, one for localization and one for captioning, both attending the same visual features. A Cross-Task Contrastive Alignment loss pulls each Hungarian-matched localization-caption pair together while pushing mismatched pairs apart, and an Overlap Suppression Loss penalizes pairwise temporal IoU between predicted boundaries with a ground-truth-aware adaptive weight so well-aligned events are spared.
Why it matters
This takes DETR literally — a query is a slot that emits one answer — and asks what happens when one slot must emit two. Its fix is to split the slot by role and then re-bind the roles with a contrastive loss, while Overlap Suppression revives the set-prediction spirit that adjacent slots should not collapse onto the same event. It is set prediction defended at the level of what each slot is allowed to say.
CVPR'26Beyond Caption-Based Queries in Video Moment Retrieval
Problem
Moment-retrieval models are trained on detailed captions written by annotators who already watched the video, so they crumble on the vague, visually-uninformed search queries real users type. Beyond this language gap, one text query can correspond to several moments, and existing DETR-based retrievers are not built to return that spread.
Approach
The paper reformulates existing datasets into under-specified search-query benchmarks, then pinpoints decoder-query collapse — too few active queries — as the core failure in DETR-style VMR. It removes decoder self-attention and adds a decoder-query dropout regularizer that forces more slots to stay live, lifting multi-moment search-query performance substantially.
Why it matters
Here each decoder query is a slot meant to emit one candidate moment, exactly the DETR unit repurposed to the temporal axis. The diagnosis is that set prediction fails when the slots collapse and only a handful fire, so multiple true moments have no slot to claim them. The remedy — dropout that keeps queries active — is a direct defense of one-slot-per-answer coverage, restoring the interface rather than replacing it.

4 · Queries that persist: tracking and video as set prediction over time

DETR taught a model to emit a whole set of objects for a single image, where each object query is a slot that claims one thing in the picture. The leap this theme captures is simple but powerful: take that slot and carry it forward frame after frame, and it stops being a per-image detector and becomes a track. The same query now follows the same object through occlusion, motion, and time, so multi-object tracking and video segmentation reduce to set prediction over a video rather than a single frame. These four papers all live in that world of persistent queries. One probes what happens when an attacker corrupts a tracker's propagated query state, one aligns two sensor streams so a query can lock onto the same target across modalities, one asks how to model time efficiently by pairing attention with a linear-cost scanner, and one decouples the trajectory a query traces from the language that names it. Read together, they show that once a query persists, an object's identity across a video simply becomes the life of one slot.
CVPR'26Out of Sight, Out of Track: Adversarial Attacks on Propagation-based Multi-Object Trackers via Query State Manipulation
Problem
Modern trackers keep an object alive across frames by carrying its query forward, letting one slot follow one target through a whole video. This works well until you ask whether an attacker can quietly break that chain of memory. The paper studies exactly that unexplored weakness in propagation-based trackers used in safety-critical systems like autonomous driving.
Approach
Their attack, FADE, targets the persistent queries directly in two ways. Temporal Query Flooding injects fake but temporally consistent track queries to exhaust the tracker's fixed budget of slots, starving the real objects of a query to live in. Temporal Memory Corruption instead reaches into the query updater and severs the temporal links, wiping the learned identity a slot has been carrying so the object's history is erased.
Why it matters
This only works because a persistent query is one object's track: the slot and its propagated memory are the object's identity through time. Break or hijack that slot and the object either loses its history or never gets one, which is why manipulating query state, not pixels, is the vulnerability.
CVPR'26Progressive Multi-cue Alignment for Unaligned RGBT Tracking
Problem
Tracking a target across a video gets harder when you have two cameras, a normal color one and a thermal infrared one, that do not point at exactly the same place. Because of sensor offsets and different fields of view, the same object sits at different spots in the two streams, and that misalignment keeps shifting as things move. A tracker trying to follow one target then struggles to agree with itself across the two modalities.
Approach
PMATrack aligns the two streams progressively rather than all at once, in three stages: first estimating the center offset from geometry, then the scale, then a global refinement using semantic cues. A difficulty-aware routing mechanism picks the right alignment expert for how hard the current scene is, and a transformation-guided cross-modal deformable attention uses homography to fuse the two views into a spatially consistent representation the tracker follows over time.
Why it matters
The point of all this alignment is to keep one target's persistent representation coherent as it travels through the video. When the color and thermal views agree on where the object is, the slot following that target stays locked on it across frames, so a well-aligned query is one continuous track.
CVPR'26When Transformers Meet Mamba: A Hybrid Transformer-Mamba Network for Video Object Detection
Problem
Detecting objects across a video means reasoning over long stretches of time, not just single frames. Transformers are great at capturing those long-range temporal dependencies but their cost grows quadratically with sequence length, so long videos become expensive. Mamba runs at linear cost but is weaker at rich contextual reasoning, so neither tool alone gives you both accuracy and efficiency over time.
Approach
TMambaDet combines the two. A Spatial Adaptive Deformable Transformer handles within-frame structure with query-dependent sampling, a Temporal Cascaded Bidirectional Mamba scans across frames in temporal-priority order at linear cost to link the same objects through time, and a Mamba Entangled Transformer decoder fuses attention and Mamba so the per-object representations aggregate spatial and temporal evidence together.
Why it matters
By making the temporal scanner carry each object's evidence from frame to frame cheaply, the model lets a per-object representation persist across the whole clip instead of being rebuilt each frame. That persistence over time is exactly what turns detection in a single image into detection over a video, where one slot's story is the object's track.
CVPR'26DeRVOS: Decoupling Consistent Trajectory Generation and Multimodal Understanding for Referring Video Object Segmentation
Problem
Referring video segmentation asks a model to find and mask the one object a sentence describes, across a whole video full of occlusion and fast motion. Earlier query-based methods tried to learn two hard things at once from scratch: keeping an object's trajectory stable over time, and matching it to the meaning of the language. Doing both together tends to produce jittery tracking and shallow understanding of the described relationships.
Approach
DeRVOS splits the problem into two upstream branches. One uses a pretrained video instance segmentation model to generate consistent object trajectories, giving stable slots that already follow each object through the video. The other uses a pretrained fusion encoder for early vision-language alignment. A Trajectory Alignment and Implicit Selection module then does cross-frame multimodal matching and motion-guided selection, reducing the whole task to picking which stable trajectory the referring expression points to.
Why it matters
Here the persistent query is made literal: each pretrained trajectory is one object's track through the video, a slot that has already committed to following a single instance. Once those trajectories exist, referring segmentation is just matching the sentence to the right persistent slot, which is set prediction over time with the tracking already solved.

5 · Into 3D and the open world: queries for the hardest detection

DETR taught us to treat detection as set prediction: a fixed pool of learnable object queries, refined through a decoder, each betting on one object. This theme pushes that idea into the two hardest arenas for detection. The first is 3D, where a query can no longer just look at a single image plane but must pull from multi-view features or point clouds and reason about where an object sits in space. The second is the open world, where a query must name a category, or a fine-grained attribute combination, that never appeared in training, or else honestly report that it does not know. In every paper the object query stays the unit of prediction, but what it attends to and what it must output grows harder: geometry it was never given, vocabulary it was never taught, or a calibrated confidence about its own guess. The through-line is that DETR gave us a slot to hang uncertainty, novel semantics, and 3D geometry on, and these works fill that slot in.
CVPR'26VGGT-Det: Mining VGGT Internal Priors for Sensor-Geometry-Free Multi-View Indoor 3D Object Detection
Problem
Multi-view indoor 3D detectors usually demand expensive sensor geometry, calibrated camera poses or depth maps, which handheld or repositioned cameras rarely provide reliably. The authors want sensor-geometry-free detection that infers 3D structure directly from unposed images, so the query decoder has no ground-truth geometry to lean on.
Approach
VGGT-Det plugs a pretrained Visual Geometry Grounded Transformer into a transformer detection pipeline and mines its internals rather than its outputs. Attention-Guided Query Generation uses the encoder attention maps as semantic priors to initialize object queries on object regions, and Query-Driven Feature Aggregation adds a learnable See-Query that lets object queries dynamically pull multi-level geometric features from VGGT layers as 2D is lifted into 3D.
Why it matters
This is DETR set prediction reasoning in 3D without explicit geometry: the object queries stay the prediction units, but they are seeded from attention priors and actively aggregate the geometry they were denied. The decoder still assigns one query per object; it just learns the spatial structure by querying a foundation model instead of consuming sensor poses.
CVPR'26SRA-Det: Learning Omni-Grained Open-Vocabulary Detection Beyond Category Names
Problem
Open-vocabulary detectors work at coarse category level and stumble when queries differ by only an attribute or two, such as a metal knife with a black plastic handle, because strong category semantics drown out the attribute cues. The description collapses into a single text vector and the fine-grained distinctions are lost.
Approach
SRA-Det adds a Semantic Retrieval Augmentation module whose learnable queries iteratively attend to token-level text features to extract multiple semantic facets of a description. Multi-Semantic Matching then compares each detected object against all facets with a soft-min operator, a differentiable logical AND that requires every key attribute to be satisfied, and an LLM-plus-CLIP pipeline supplies attribute-augmented training data.
Why it matters
The set-prediction decoder now emits objects that must match a decomposed, multi-facet query rather than one label. It extends DETR beyond category names: object queries are still matched to detections, but the text side is broken into facets so the decoder can name things by attribute agreement, not just by class.
CVPR'26Query2Uncertainty: Robust Uncertainty Quantification and Calibration for 3D Object Detection
Problem
DETR-style 3D detectors emit confidence scores that are poorly calibrated and stay overconfident under corrupted or out-of-distribution input. Standard post-hoc calibration ignores the latent query features, which quietly encode how atypical a detected object is relative to the training distribution.
Approach
Query2Uncertainty fits a RealNVP normalizing flow to the 256-dimensional query features from the last decoder layer, trained class-conditionally on true-positive queries, and turns each query log-density into a standardized deviation. That density signal modulates three calibration variants (density-aware temperature scaling, Platt scaling, and isotonic regression) and rescales the per-parameter box-regression variances, all evaluated on PETR and SECOND under the MultiCorrupt benchmark.
Why it matters
It reads uncertainty straight off the set-prediction machinery: every DETR query already carries a representation of how in-distribution its object is, and this work makes that latent explicit. The decoder still predicts a set of objects; Query2Uncertainty simply attaches a calibrated, corruption-robust confidence to each query it produces.
CVPR'26Prompt-Free Unknown Label Generation for Open World Detection in Remote Sensing
Problem
Open-world detection in aerial imagery must discover and name unknown object categories without any predefined prompts, yet existing methods lean on manual text descriptions or language models that do not transfer to remote sensing. The decoder needs a way to flag and name objects it was never trained to recognize.
Approach
HSGDet builds a Deformable DETR detector over a frozen CLIP encoder and lets queries attend a WordNet semantic graph via Dynamic Hierarchical Graph Attention, going coarse to fine (parent nodes in early layers, child nodes in later ones). Queries whose max attention to known class nodes falls below a threshold are routed as unknown to a CR2T module that synthesizes a pseudo CLIP text embedding from the query, scene context, and parent node, and a buffer-and-cluster step names emerging categories.
Why it matters
The set-prediction slot becomes the natural place to detect the unknown: a low-attention query is an object the decoder cannot name, and instead of dropping it, HSGDet has that query generate its own label. It keeps DETR one-query-per-object matching while extending the vocabulary at inference, so novel objects get a slot and a name rather than being suppressed.

6 · On the robot: end-to-end query detection for drones, vehicles, and cooperative perception

DETR reframed detection as set prediction: a fixed pool of learnable object queries pass through a transformer decoder and each emerges as one object or nothing, dissolving the anchor grids and NMS post-processing that older detectors relied on. That clean, end-to-end interface turns out to matter a great deal once the detector leaves the benchmark and lands on a real robot. On drones and vehicles, dropping hand-tuned anchors and NMS removes brittle, latency-heavy stages from an on-board pipeline that must run in real time. Even more striking, the object query itself becomes a unit of communication: instead of shipping raw sensor tensors between cooperating vehicles, each robot can share the compact set of queries its decoder produced. These four papers push that idea in two directions — making query detection efficient enough for a single drone or vehicle, and using queries as the message format for cooperative, multi-agent perception. In each case the DETR set-prediction view is not decorative; it is what makes the detector deployable, shareable, or bandwidth-cheap.
ROBOTICS'25CoopDETR: A Unified Cooperative Perception Framework for 3D Detection via Object Query
Problem
When self-driving cars share raw sensor data with each other to widen their view, the data volumes are enormous and hard for a receiving vehicle to interpret. The team wanted cooperation that improves 3D detection without flooding the network with sensor regions.
Approach
Each vehicle compresses what it sees into a small set of object-level summaries — the object queries from its decoder — and shares only those. A matching step aligns queries coming from different vehicles, and an aggregation step fuses the matched queries into stronger detections across the whole scene.
Why it matters
This is DETR set prediction used as a communication protocol: because each query already stands for one candidate object, it is exactly the compact, semantically meaningful unit worth transmitting. Sharing object summaries instead of raw sensor regions is reported to cut the data sent by more than 700-fold, which is what lets cars pool their views without saturating a real vehicular network.
ROBOTICS'25UAV-DETR: Efficient End-to-End Object Detection for Unmanned Aerial Vehicle Imagery
Problem
A detection method tuned for ordinary photos performs poorly on drone imagery, where objects are tiny and fine detail gets blurred away. The challenge is keeping the clean end-to-end pipeline while recovering the small-object detail aerial views demand.
Approach
They keep the end-to-end query-based detector but bolt on three upgrades: a module that fuses features across many sizes using frequency-domain tricks, a downsampling step that preserves sharp detail, and a module that stitches features together across different paths before the queries read from them.
Why it matters
By staying end-to-end, UAV-DETR inherits DETR's anchor-free, NMS-free pipeline — valuable on a drone where compute and latency budgets are tight and every extra post-processing stage costs power and time. The enrichments simply give the object queries better small-object features to attend to, reportedly lifting detection on drone photos by a few percent.
ROBOTICS'25CoCMT: Communication-Efficient Cross-Modal Transformer for Collaborative Perception
Problem
When self-driving cars exchange sensor data to perceive collaboratively, the raw volume sent over the network makes real deployment impractical. The goal is to stay coordinated while sending far less.
Approach
Rather than broadcasting all sensor features, the system selects only the most important ones — again the object queries — and transmits just those. A cross-modal transformer decides which features matter, and it is trained with supervision drawn from multiple levels of the network.
Why it matters
CoCMT leans directly on DETR's premise that a handful of queries can stand in for a whole scene of objects, so the query set doubles as a minimal message. Because queries are object-level rather than pixel-level, cars stay coordinated while, as reported, using 83 times less bandwidth — the difference between a cooperative-perception idea and one that can actually run over a real inter-vehicle link.
ROBOTICS'25TS-DETR: Traffic Sign Detection Based on Positive and Negative Sample Augmentation
Problem
Traffic-sign detectors confuse similar-looking signs and miss rare ones, because training data has far more common signs than rare ones. On a vehicle this class imbalance shows up as exactly the errors that matter for safe driving.
Approach
A DETR-style detector is trained with added synthetic images of rare signs plus deliberate near-miss negatives — signs that look alike but differ — so the queries learn finer distinctions, and a multi-scale feature module gathers detail across zoom levels.
Why it matters
The augmentation targets what the object queries must resolve: DETR matches each query to at most one ground-truth object via bipartite set prediction, so hard positive and negative examples directly sharpen those per-query decisions. On a car, cutting the confusion rate between look-alike signs is a straight line from the set-prediction interface to safer, more reliable on-board perception.
Reading it whole. Top to bottom, the themes trace one idea outward from the task that birthed it: first the detector itself, made to converge; then the query re-pointed from boxes to segments and occupancy; then to anything at all — a count, an interaction, a video moment; then carried through time to become a track; then pushed into 3D and the open world; and finally onto a robot, where the same set of object queries becomes something two agents compress and share. The tasks differ wildly; the primitive — a fixed set of queries, each emitting one thing, matched one-to-one — never changes.
