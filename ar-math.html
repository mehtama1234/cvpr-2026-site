The problem, as a quantity

Any sequence has a joint probability p(x₁, x₂, …, x_n). To generate it we need to sample from that joint. But the joint is high-dimensional and entangled. The chain rule of probability offers a way out: factor the joint into a product of conditionals, each depending only on what came before:

p(x) = p(x₁) · p(x₂|x₁) · p(x₃|x₁,x₂) · … = ∏_i p(x_i | x_

This factorization is exact—no approximation. But it unlocks a generation strategy: sample left-to-right, one token at a time, feeding each choice back as context for the next. Training becomes a sum of log-probabilities of true next tokens given true prefixes (teacher forcing).

The price: generation is now sequential and fragile. Errors in early tokens drift forward and compound. A model trained on truth can fail when it sees its own mistakes during decoding.

Chain rule factorization

foundation

The model never sees the answer to its own prediction task at training time. This structure makes the problem tractable: one supervised classification problem per position, solvable with cross-entropy.

Teacher forcing and exposure bias

training-generation gap
At training, feed the model true prefixes and predict the true next token: L = Σ_i log p(x_i | x_its own sampled outputs, not ground truth. Early mistakes go unobserved during training. Small errors become amplified: wrong token at position t becomes noisy context for t+1, pushing the conditional further from training distribution. Exposure bias: model has never learned to recover from mistakes.

Sequential generation as bottleneck

speed
Sampling one token per forward pass means n forward passes for a length-n sequence. With long horizon (video, code, long-form text) this is slow. Parallel decoding schemes (drafting, speculative, iterative refinement) break the sequential constraint by predicting multiple tokens or different levels of structure at once, sacrificing the exact left-to-right factorization for speed.

The approaches, as variations on the math

Coarse-to-fine: Generate a low-res or high-level summary first (rough shape, key points), then iteratively refine each region or detail, conditioned on coarser structure. Trades sequential full-resolution generation for hierarchical steps. Escaping one-token-at-a-time: Parallel decoding (medusa heads, draft-verify), non-autoregressive decode (discrete diffusion, iterative masking), or multi-token lookahead (SpecDecode). Predict 2–many tokens in one step, losing the exact chain-rule guarantee but gaining speed. Unify read and write: Instead of sampling then feeding back, learn to condition on a sketch or plan (separate from generation). Reasoning models add thought tokens; planning models roll out coarse action sequences then detail them. Roll out fast: Use smaller models to draft, large model to verify; or use cached key-value tensors to avoid recomputing prefixes on each step.

The through-line. The chain rule is exact—any joint factors into left-to-right conditionals. But it forces sequential generation: each step is a classification task given all prior choices. Errors drift forward, and the model never trained on its own mistakes. Faster and more robust generation breaks the strict left-to-right order through hierarchy, parallelism, or planning, at the cost of approximation or added components.
