What changes between vision and a robot

axisCVPR 2026 (vision)Robotics 2025
What an object isa slot / entity discovered in the imagea thing to grasp, move, or place
Why separate themcompositional reasoning, binding, controllable editingact on one object without disturbing the rest
The representationslots, object tokens, per-object masksobject-level poses, object nodes in a map
The payoffgeneralization and control from structureclean manipulation and a nameable, queryable map
The through-line. Object-centric learning splits a scene into separable objects instead of one blob, so each can be bound, composed, or acted on independently. In vision it enables compositional reasoning and per-object control; in robotics it gives one handle per thing to grasp and a map built from named objects — the same primitive, an object to reason about versus an object to act on.
