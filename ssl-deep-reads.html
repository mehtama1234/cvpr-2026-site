1 · Predict the hidden part

The simplest way to learn from data with no labels is to hide a part of the input and ask the model to fill it back in. Because we removed that part ourselves, we already know the right answer, so the data is its own answer key and no human has to mark anything. The trick is to hide a lot of the input at once: if only a sliver is missing, the model can cheat by copying nearby texture, but when most of it is gone the only way to guess the hidden piece is to understand what the scene actually contains. So a high mask ratio quietly forces the model to infer meaning rather than parrot pixels. But the pretext task has to be re-invented for every kind of data: a video hides across time, radar hides through a fog of speckle noise, and satellite tiles hide across the continuous surface of the Earth. In each case the same idea — predict the hidden part — yields features that transfer to real tasks without a single label.

CVPR'26Recurrent Video Masked Autoencoders
Problem

Most video self-supervised models look at a whole clip at once and treat time as if it ran in both directions equally. That makes them awkward for anything that streams in live, and it leaves them weak at dense spatial jobs like tracking a point or reading depth. A model that watches a video the way we do — one moment leading to the next — would fit real, ongoing footage far better.

Approach

RVM watches a video frame by frame, in order. It takes a few earlier frames it can see clearly, then hides 95% of the next frame and asks the model to reconstruct that hidden frame from what came before. A shared vision encoder reads each frame, and a recurrent core — a memory that carries a running summary forward with gates that decide what to keep and what to overwrite — passes understanding from one moment to the next. Because almost the entire target frame is masked, the model cannot copy pixels across from a neighbor; it has to predict how the scene will actually evolve, which is a far deeper demand. Training runs on 8.4 million unlabeled clips with a plain pixel-matching loss, no annotations anywhere.

Why it matters

By inventing a self-graded game — guess the next hidden frame — RVM learns features that beat much larger models on eight tasks and stay stable over long sequences, all without a single label.

CVPR'26MuM: Multi-View Masked Image Modeling for 3D Vision
Problem

Most self-supervised models learn what is in a picture but not where things sit in space, so their features are semantic rather than geometric. The 3D-focused alternatives are fragile: they need two views of the same scene that overlap heavily, which makes gathering training data brittle, and the strongest general models cost enormous compute. What is missing is a simple, scalable way to learn genuinely geometric features.

Approach

MuM takes several photos of the same scene from different viewpoints, masks patches out of every view, and runs each masked view through one shared encoder. A joint decoder then reconstructs all the missing patches together, letting the views attend to one another — so to fill a hole in one image the model must borrow evidence from the others, which only works if it has figured out how the viewpoints relate in 3D. Because the reconstruction target is just the original pixels, the images grade themselves and no ground-truth 3D geometry is ever required. It also accepts any number of views with flexible sampling, so it is not chained to heavily-overlapping pairs.

Why it matters

Learning to fill hidden patches across views forces geometric understanding for free, and it beats the leading models on 3D matching and pose while using about 30 times less compute.

CVPR'26SARMAE: Masked Autoencoder for SAR Representation Learning
Problem

Radar satellite imagery (SAR) sees through clouds and darkness, but it comes with a grainy speckle noise baked in by the physics of how radar bounces back, which makes fine detail hard to learn. There is also far less of it than ordinary optical imagery, and past methods largely ignored what makes SAR special. So its rich content stays underused.

Approach

SARMAE first builds SAR-1M, the first million-image SAR dataset, each radar image paired with a matching ordinary optical photo. It then trains a masked autoencoder: hide most of the SAR image and reconstruct the missing parts, so the data supplies its own targets. Two twists make it fit radar. It deliberately injects realistic speckle noise during training so the model learns to see structure through the grain instead of memorizing it, and it anchors the SAR features to the paired optical image so the meaning it learns stays consistent and training converges faster. The heavy masking pushes it toward the semantics of the scene rather than the noisy texture.

Why it matters

By re-inventing the hide-and-reconstruct game for the peculiar physics of radar, SARMAE learns label-free features that set the state of the art on SAR classification, detection, and segmentation.

CVPR'26NeighborMAE: Exploiting Spatial Dependencies between Neighboring Earth Observation Images in Masked Autoencoders Pretraining
Problem

The Earth's surface is continuous — a river, a road, or a field runs on across many satellite tiles — yet standard masked-modeling methods treat each tile as an isolated island. That throws away the rich clues that neighboring tiles carry about one another. Those neighbors are plentiful and closely related, but they sit unused.

Approach

NeighborMAE pairs up satellite images that are physically next to each other on the ground (chosen by how much their map footprints overlap), masks patches out of both, and reconstructs them jointly, letting tokens from one tile attend to the other. To fill a hole, the model can lean on a neighboring scene — but only if it has understood the continuity of terrain, land use, and infrastructure across them. Shared coordinate embeddings tell it how the tiles line up in space. Crucially, dynamic masking and careful loss weighting stop it from taking a shortcut: without them the model could just copy from an overlapping visible region instead of truly inferring the hidden part.

Why it matters

Making the reconstruction depend on the ground next door turns free spatial neighbor-relationships into a self-supervised signal, yielding stronger label-free features across many Earth-observation tasks.

2 · Match two views

The core intuition of this family is simple: take one image, make two altered copies of it — crop it differently, shift its colors, blur one — and demand that the encoder produce nearly the same description of both. If a network can be trained to make two views of the same thing agree, it is forced to learn what actually stays constant about the object (its essence) while ignoring what merely changed between views (the incidental details of crop, lighting, or angle). But there is an obvious cheat. If the network is only rewarded for making its two outputs match, the laziest possible solution is to output the exact same vector for every input — mapping everything to a single constant point in space. Two views always agree perfectly when everything agrees perfectly, and the encoder has learned nothing. This failure is called collapse, and defeating it is what actually distinguishes the methods in this theme. Three fixes recur: negatives (also push apart views of different things, so the space cannot shrink to a point); a momentum teacher whose weights are a slow-moving average of the student and whose gradient is stopped, giving the student a stable, non-collapsing target to imitate; and prototype clustering (the DINO family), where views are matched through soft assignments to a shared set of learned cluster centers, kept balanced by centering so no single cluster can swallow everything.

CVPR'26Towards Foundation Models for 3D Scene Understanding: Instance-Aware Self-Supervised Learning for Point Clouds
Problem

Self-supervised learning on 3D point clouds has mostly chased semantic agreement — teaching the network that a chair is a chair regardless of viewpoint. But that objective throws away the fine geometry that separates one chair from the chair next to it, so the learned features transfer poorly to instance-level jobs like telling individual objects apart in a crowded scene. A foundation model for 3D needs both the category and the individual, and pure semantic invariance delivers only the former.

Approach

PointINS uses a teacher-student self-distillation setup with two branches. The semantic branch is where the two-views idea lives: teacher and student each encode a differently augmented version of the same point cloud, and both projections are matched not directly but through a shared set of learnable category prototypes, with cross-view agreement enforced by a KL-divergence distillation loss. This is the DINO-style recipe: matching through prototype assignments rather than raw vectors, so collapse to a single point is blocked by the clustering structure — features must distribute across prototypes rather than pile onto one. A second offset branch adds genuine geometry, predicting a vector from each point toward its object's center, and two regularizers keep it honest: Offset Distribution Regularization aligns the predicted offsets with the real long-tailed-magnitude, uniform-direction statistics of scenes, while Spatial Clustering Regularization runs K-means and breadth-first search to carve out pseudo-instances that enforce local coherence.

Why it matters

By pairing prototype-clustered semantic matching with explicit offset geometry, one encoder learns both what an object is and where each individual object begins and ends — yielding 2.5–4.6% mAP gains on indoor instance segmentation and 3.4–4.8% PQ gains on outdoor panoptic segmentation over prior SSL baselines.

CVPR'26TimeBridge: Self-Supervised Video Representation Learning via Start-End Joint Embedding and In-Between Frame Prediction
Problem

Video is harder than a still image because the two things you want to relate — the start and end of a motion — are connected by complex, non-linear change, not a simple augmentation. Plain joint-embedding methods treat the frames as views to align but stay blind to the transformation between them, while trying to predict the far future is ill-posed and drifts into approximation errors.

Approach

TimeBridge extends iBOT — a self-distillation, masked-image method — from images to video, and it treats the start and end frames as the two views to embed jointly. Following iBOT, it pulls a class token from each endpoint through the teacher-student self-distillation machinery that iBOT and the DINO family rely on, where a momentum/EMA teacher with a stopped gradient supplies a stable target and prevents the embeddings from collapsing to a constant. On top of that joint embedding it adds a reconstruction task: the class tokens from the two endpoints are cross-concatenated and recombined through lightweight decoders to reconstruct the intermediate frames, trained with an L2 loss. Predicting the frames between two known endpoints is a well-posed problem — the answer is boxed in on both sides — so the model learns concrete frame-to-frame dynamics without the guesswork of open-ended future prediction.

Why it matters

Matching two endpoint views while filling in the middle forces the encoder to represent genuine temporal evolution, reaching 73.5 J&F on DAVIS 2017 and 47.5 mIoU on VIP part propagation.

CVPR'26Scaling Self-Supervised and Cross-Modal Pretraining for Volumetric CT Transformers
Problem

Building a foundation model for 3D CT scans breaks the standard transformer recipe: the volumes explode into far too many tokens, the voxels are geometrically anisotropic, and the clinical labels are weak and scarce. There was no open, general, fully transformer-based 3D CT model trained on accessible data rather than proprietary hospital archives.

Approach

SPECTRE pairs a local transformer that extracts high-resolution volumetric features with a global transformer that models whole-scan context, and pretrains it in two stages. The first stage is pure two-views self-supervision: DINO-style self-distillation, where a teacher and student see different augmented views of the same CT volume and the student is trained to match the teacher's output distribution. Collapse is prevented exactly the DINO way — the teacher is an EMA (momentum) copy of the student with the gradient stopped, giving a stable target, and its outputs are centered so no single response can dominate and pull everything to one point. The second stage then aligns those visual features with language through SigLIP vision-language matching against paired radiology reports, so the geometry learned in stage one is grounded in clinical meaning. The whole model is trained exclusively on open datasets.

Why it matters

Self-distillation first teaches the encoder what CT anatomy looks like, then report alignment gives it clinical vocabulary — beating 11 prior CT foundation models and topping four of six biomarker benchmarks.

3 · Predict in latent space, and fight collapse

If you train a model to fill in a hidden patch of an image or video by reconstructing the exact pixels, it burns most of its effort on tiny details that do not matter — the precise texture of grass, the flicker of a shadow. JEPA (Joint-Embedding Predictive Architecture) sidesteps this: instead of predicting the missing pixels, it predicts the missing part's embedding — a compact summary of what is there — which is cheaper and forces the model to capture meaning rather than surface detail. The obvious risk is that the model cheats by mapping everything to the same dull vector, so the target summaries are produced by a separate stop-gradient target encoder whose weights are not pushed around by the prediction loss, which keeps the targets stable and holds this collapse at bay. A striking pattern at CVPR 2026 is that JEPA is rarely re-derived from scratch; instead a pretrained V-JEPA-2 is imported as a ready-made tool — a physics-plausibility judge, or a physics-aware latent space to generate into. Collapse, meanwhile, is the universal enemy of any learned representation, so a whole line of work studies what actually makes features good — suppressing noise directions that carry no meaning, and forcing diversity so evidence does not pile into a few dominant directions. Together these papers say: represent the world in a compact latent space, and spend real effort keeping that space rich rather than degenerate.
CVPR'26Inference-time Physics Alignment of Video Generative Models with Latent World Models
Problem
State-of-the-art video generators make footage that looks great but breaks basic physics — objects pass through each other, fluids move wrongly, motion jumps. Some blame the pretraining, but physically-plausible videos probably already exist somewhere inside what the model can produce; the trouble is finding them at generation time.
Approach
The paper repurposes a pretrained V-JEPA-2 latent world model as a physics referee rather than retraining anything. Because V-JEPA-2 predicts what should happen next in embedding space, its surprise score — how badly its latent prediction misses the actual next frames — is a natural signal for physics implausibility. They wrap this into a reward called WMReward and use it two ways: pick the best of N generated candidates by lowest surprise, and steer the denoising process toward the physics-plausible region of the distribution. This works across text-to-video, image-to-video and video-to-video with several base models (MAGI-1, Sora2, latent diffusion), and the gains grow as you let it search a bigger candidate pool.
Why it matters
It shows a JEPA latent model is useful not just for perception but as an off-the-shelf judge of physical realism, winning first place on the ICCV 2025 PhysicsIQ Challenge (62.0%) with no changes to the generator itself.
CVPR'26PHANTOM: Physics-Infused Video Generation via Joint Modeling of Visual and Latent Physical Dynamics
Problem
Scaling up video diffusion models gives better-looking clips but does not teach them physical laws, so the results stay physically implausible. The goal is to bake an understanding of dynamics into generation without a simulator and without hand-specifying object properties like mass or friction.
Approach
PHANTOM adds a dedicated physics branch to a pretrained video diffusion model, and — crucially — that branch operates inside the physics-aware latent space of V-JEPA-2 rather than in pixels. So alongside generating the visual content, the model infers and predicts the latent physical dynamics of the scene, again borrowing V-JEPA-2 as a ready-made abstract embedding space rather than deriving one. The two branches are coupled by bidirectional cross-attention in a dual-branch flow-matching architecture, so physical-state information and visual detail continuously inform each other. The model never needs explicit physical properties or a physics engine — it learns to predict the latent dynamics directly.
Why it matters
By predicting in an abstract physics-aware latent space instead of raw pixels, PHANTOM lifts physical consistency by 50.4% on VideoPhy while keeping visual fidelity, showing latent prediction can inject physics that pixel-level generation misses.
CVPR'26Suppressing Non-Semantic Noise in Masked Image Modeling Representations
Problem
Masked Image Modeling learns features by predicting hidden patches, but its reconstruction objective rewards features that just guess where a patch is — positional artifacts that carry no meaning. This non-semantic noise pollutes the embeddings and drags down downstream tasks like segmentation and salient object detection.
Approach
This is a fight-the-degeneration paper: rather than let meaningless directions dominate the representation, it identifies and removes them. The authors define a Semantic Invariance (SI) score that asks, for each direction in feature space, how much it changes across positions within the same object — a direction that stays stable is semantic, a direction that swings with position is positional noise. Their SOAP module then builds a projection that zeros out the noisiest eigenvector directions, weighting them by SI score through a smooth Fermi window over rank, so the noise subspace is projected away while meaning is kept. This is training-free: SOAP is a lightweight post-processing layer estimated from a small unlabeled calibration set and applied to any frozen MIM backbone (they test CAPI, BEiT, MAE). The result is a universal quality boost with no retraining.
Why it matters
It shows that a good representation is partly about what you remove: projecting out non-semantic noise lifts CAPI salient-segmentation F-measure from 72.5 to 85.2, a clean gain from a purely post-hoc cleanup.
CVPR'26Diversity over Uniformity: Rethinking Representation in Generated Image Detection
Problem
Detectors of AI-generated images tend to latch onto the single most obvious forgery cue and squash all their evidence into a few dominant feature directions — a form of feature collapse. That low-rank representation looks fine on the generators it trained on but shatters on unseen generators, new content, or new perturbations.
Approach
The paper argues the problem is not a lack of usable clues in the data but how the features are organized, and treats collapse as the enemy to attack head-on. Its Anti-Feature-Collapse Learning (AFCL) adds a training objective that penalizes overlap — correlation — between different forgery-cue directions, pushing the representation to stay diverse, complementary and high-rank instead of homogenizing onto one cue. At the same time it filters out task-irrelevant dimensions, so it keeps many judgment perspectives without hoarding noise. Collapse is measured and controlled through the effective rank of the feature matrix, and a theoretical constraint keeps enough forgery-relevant signal while dropping the redundant parts. It plugs in alongside the ordinary binary-classification loss and works with various backbones.
Why it matters
It reframes generalization as a representation-diversity problem: keeping features high-rank instead of collapsed yields a 5.02% cross-model accuracy gain, arguing that a good representation preserves many complementary clues rather than one.

4 · SSL as infrastructure

Self-supervised learning used to be the research question: can a model learn useful vision features from images alone, with no labels? At CVPR 2026 that question is settled, and SSL has quietly become plumbing. The features that come out of a frozen DINOv2 or DINOv3 backbone are so semantically organized that patches belonging to the same object, part, or concept already cluster together in feature space. That means whole tasks fall out with no decoder and no labels at all: you can segment a new concept just by clustering those frozen features and matching them against a reference, or caption an arbitrary region just by averaging the patch features under it. The telling pattern across the corpus is a ratio: for every paper that invents a new self-supervised objective, roughly two or three simply consume a frozen backbone as a fixed component and build on top of it. SSL matured from a topic you study into an ingredient you reach for.
CVPR'26INSID3: Training-Free In-Context Segmentation with DINOv3
Problem
You want to segment an arbitrary concept in a new image given just one reference example of it, across any domain, without training. Fine-tuning a model helps on the domain you tuned for but wrecks its ability to generalize elsewhere, and stacking multiple specialist models to preserve generality gets complicated and heavy.
Approach
INSID3 does the whole thing with a frozen DINOv3 and no training. It clusters the target image's frozen patch features agglomeratively into part-level region candidates, then uses cross-image similarity between the reference's prototype and those candidate clusters to pick which regions are the concept, aggregating them with DINOv3's own self-similarity as the guide. The one subtlety is that DINOv3 features carry a positional bias — where a patch sits nudges its features — so INSID3 estimates that bias subspace from a noise image and does its matching only in the orthogonal complement, cleanly removing it. Nothing is learned; the segmentation ability is simply read off features that were already semantically structured. It beats prior methods by +7.5% mIoU with 3x fewer parameters.
Why it matters
This is the infrastructure point in its purest form: a task that used to need a trained decoder and masks now emerges directly from a frozen SSL backbone, so the segmentation was latent in the features all along and just needed to be surfaced.
CVPR'26A Mixed Diet Makes DINO An Omnivorous Vision Encoder
Problem
DINOv2 was trained on ordinary RGB images, so its features do not line up across modalities — the feature of an RGB photo and the feature of its own depth map are about as similar as two unrelated images. That makes the backbone hard to reuse when your downstream task mixes RGB, depth, and segmentation maps.
Approach
Rather than train a new encoder, this work adapts the frozen one with a lightweight teacher-student setup. A student initialized from DINOv2 is fine-tuned on just its high-level blocks with two goals: pull the features of matching cross-modal views together, while a distillation loss anchored to the frozen DINOv2 teacher keeps the original semantics intact. To stop the model from cheating, it manufactures hard positives by recoloring depth and segmentation into natural color palettes, and blends modalities during training so the encoder learns to be invariant to which modality it is looking at. The result aligns RGB, depth, and segmentation features while preserving the discriminative power of the base DINOv2.
Why it matters
Here the frozen backbone is the fixed reference point you build outward from — you extend DINOv2 to new modalities by adapting a few blocks and distilling against the original, not by paying to pretrain from scratch.
CVPR'26One Patch to Caption Them All: A Unified Zero-Shot Captioning Framework
Problem
Zero-shot captioning normally works only on the whole image, because it leans on a single global image feature. Captioning an arbitrary region, a bounding box, or a spot the user points at would ordinarily need expensive region-level caption supervision.
Approach
Patch-ioner turns captioning into a patch-level problem on top of frozen features. It takes the dense per-patch embeddings from a frozen Talk2DINO backbone (DINOv2 with a text-aligned projection), and to caption any region it simply averages the patch features inside that region — a parameter-free mean, no region supervision anywhere. A text decoder trained on text-only data then turns that averaged feature into a caption, with the visual-to-text modality gap bridged by tricks like memory projection or noise injection. Because the whole thing is just choose-your-patches-then-average, one framework covers four tasks at once: whole-image captioning (all patches), dense captioning (patches in a box), region-set captioning (patches across several boxes), and trace captioning (patches along a mouse trace). The DINOv2-based backbone consistently beats CLIP-based ones on these local tasks — dense captioning mAP 21.31 versus RegionCLIP's 15.85.
Why it matters
The captioning power comes from the frozen backbone's dense features being spatially meaningful patch by patch, so a bare mean over patches replaces what used to require a trained region model — the SSL substrate does the heavy lifting.
CVPR'26Vision Foundation Models Can Be Good Tokenizers for Latent Diffusion Models
Problem
Latent diffusion models generate images inside the latent space of a visual tokenizer, so the tokenizer quality caps everything downstream. The usual trick is to distill a vision foundation model into a VAE, but that distillation step degrades the very robustness that made the foundation model's features good in the first place.
Approach
VFM-VAE skips distillation and plugs a frozen vision foundation model straight in as the tokenizer's encoder. It concatenates multi-scale features pulled from shallow, middle, and final layers of the frozen backbone and maps them to the diffusion latent with only a lightweight learnable projection — the foundation model itself never changes. A specialized decoder does the hard work of reconstructing a sharp image from those semantic features, splitting the latent into a global part and multi-scale spatial parts and rebuilding resolution by resolution. Because the encoder is frozen, the tokenizer inherits the foundation model's semantic structure intact rather than eroding it. It hits gFID 2.22 in an order of magnitude fewer epochs, and its features stay robust (SE-CKNNA drops only 1.6% under perturbation versus a distillation baseline's 33.2%).
Why it matters
Even the generative-modeling side of the field now treats a frozen SSL-style backbone as a drop-in component — using its features directly beats distilling them, so the foundation model is infrastructure you wire in, not a thing you reprocess.

5 · Learning from the robot's own experience

A robot never stops recording. Cameras, wheels, joints, and force sensors pour out a torrent of raw data every second, and no human will ever sit down to hand-label even a sliver of it. So where does the answer key come from? It turns out the world hands it over for free, if you know where to look. Two cameras a fixed distance apart disagree about where a pixel sits, and that disagreement is the depth. The next frame quietly answers the question what happens next?, so time itself becomes the label. And when the robot commands a motion and then feels how the terrain shoves back, that action has just labeled its own dynamics. For the harder job of naming what things mean — grass versus gravel, mug versus clutter — robots skip the labeling problem entirely and borrow a frozen backbone that computer vision already trained on the whole internet, most often DINOv2. In every case the supervision is smuggled in from the physics of having a body: geometry, the passage of time, and the robot's own forces.
ROBOTICS'25Watch Your STEPP: Semantic Traversability Estimation Using Pose Projected Features
Problem
A legged robot like ANYmal has to decide, pixel by pixel, which patches of ground it can safely walk on in messy outdoor terrain. Pure geometry maps — is this spot flat or bumpy? — miss the point, because what matters is this specific robot's mobility, not raw shape. And nobody is going to hand-label thousands of images with walkable versus hazard.
Approach
The trick is to never label anything. A frozen DINOv2 vision transformer — trained on internet images with no robotics involved — turns each pixel into a rich feature vector that already knows a lot about texture and material. Those dense features are projected onto the terrain the robot is looking at, then fed through a small encoder-decoder that is trained only to reconstruct the features it saw while a human simply walked around on good ground. Because it only ever practiced on safe terrain, it reconstructs safe patches cleanly and stumbles on anything unfamiliar. High reconstruction error therefore flags a hazard — the supervision is this looks like where we walked versus this does not, no labels required.
Why it matters
It is the same anomaly-detection idea a beginner might sketch, but the teacher is a frozen internet-scale backbone, so the notion of normal ground is far richer than any hand-tuned feature could capture.
ROBOTICS'25Cage: Causal Attention Enables Data-Efficient Generalizable Robotic Manipulation
Problem
A manipulation policy learned from a handful of demonstrations tends to collapse the moment the scene looks different — a new table, new lighting, new background clutter. Collecting enough labeled demos to cover every possible environment is hopeless. The robot needs to generalize from as few as 50 examples.
Approach
CAGE leans on a frozen DINOv2 foundation model to see. Because that backbone was self-supervised on enormous image collections, its features already ignore distracting background shifts and latch onto what actually matters, so the policy inherits visual robustness it never had to learn from robot data. A lightweight LoRA adapter nudges those frozen features toward the manipulation task, a causal perceiver compresses them into a few tokens, and a diffusion action head — the same generative machinery behind image models — samples smooth action sequences conditioned on that compressed view. The demonstrations only supply the actions; all the heavy visual understanding is borrowed.
Why it matters
The behavior-cloning core is textbook, but standing it on a frozen SSL backbone plus a diffusion head is what lets 50 demos survive a total change of scene — the richer teacher does the generalizing.
ROBOTICS'25VertiCoder: Self-Supervised Kinodynamic Representation Learning on Vertically Challenging Terrain
Problem
An off-road robot crawling over boulders and steep vertical ledges needs a model of how it will move when it drives onto a given terrain patch. Building a separate labeled model for every task — predicting motion, planning actions, imitating a driver — wastes data and overfits. There is no external annotator for how rock and dirt will push back.
Approach
VertiCoder makes the interaction data label itself. It takes patches of terrain-and-motion experience, hides random pieces, and trains a Transformer to fill in the blanks — masked prediction, the same self-supervised trick that powers language models. To reconstruct what it masked, the network is forced to internalize the real physics of how the robot and terrain interact. The result is one shared representation that then serves forward and inverse dynamics, behavior cloning, and patch reconstruction all at once. The action-and-outcome stream is the supervision: what the robot did and what happened next is the answer key.
Why it matters
It is masked autoencoding, the plainest SSL recipe there is, but pointed at the robot's own kinodynamic experience — and that one self-supervised representation beats task-specific models with 77% fewer parameters.
ROBOTICS'25ORB-SfMLearner: ORB-Guided Self-supervised Visual Odometry with Selective Online Adaptation
Problem
A robot needs to know how it moved through the world just from its camera — its ego-motion, frame to frame. Learned methods for this have been shaky and travel badly across new environments. And you can never hand-label the true depth of every pixel or the exact motion between frames.
Approach
The label comes from the pictures themselves. If the network correctly guesses the scene's depth and how the camera moved, it can take one frame, warp it, and reproduce the next frame — so any mismatch in brightness between the predicted and the real next frame is a free error signal. This photometric consistency across time trains depth and pose together with no ground truth at all; the passage of time supplies the supervision. ORB-SfMLearner sharpens this by feeding in classical ORB feature points to guide the pose network via cross-attention, and adds selective online adaptation so it can quickly retune itself when it crosses into a new domain.
Why it matters
The photometric-consistency loop is the standard self-supervised depth-and-motion idea, but guiding it with battle-tested ORB features and letting it adapt online is what carries it across domains where plain learned odometry drifts.

6 · Align across sensors and places

A robot has to recognize that this is the same street corner it drove past this morning, even though the sun has moved, the shadows have flipped, and half the parked cars are gone. Harder still, it has to know that the blob in its camera image and the cloud of laser points from its LiDAR are looking at the same place, despite one being colored pixels and the other being bare geometry. Nobody can hand-label these correspondences at scale — you cannot pay a human to mark, for millions of frames, which RGB pixel matches which laser point, or which touch from one tactile sensor equals a touch from a different sensor. So the field turns to what nature hands out for free: co-occurrence. The same place gets seen twice; the same instant gets recorded by two sensors at once; the same object gets pressed by two different fingers. Contrastive learning takes these naturally paired observations, pulls their embeddings together while pushing unrelated ones apart, and out of that pull-and-push a shared space emerges — one where the camera view and the laser scan of a single corner land in the same neighborhood, no labels required.
ROBOTICS'25$U2$ Frame: A Unified and Unsupervised Learning Framework for LiDAR-Based Loop Closing
Problem
When a robot revisits a place it has already mapped, it needs to recognize the return so it can correct accumulated drift — this is loop closing. Training a detector to do this normally demands ground-truth robot poses telling the model which two LiDAR scans came from the same spot, and those poses are expensive to collect and often unreliable. The matching-across-a-gap problem here is temporal: the same place, revisited minutes or hours later from a slightly different angle, must be tied to its earlier scan without anyone labeling the link.
Approach
Instead of pose labels, the framework mines its supervision from the point cloud sequence itself. As the robot moves, consecutive scans naturally overlap — nearby-in-time scans genuinely see overlapping geometry, so they form positive pairs, while scans from far-apart moments form negatives. This temporal-spatial correlation becomes the free supervision signal that trains a network to jointly learn a local descriptor and a global place fingerprint. A revisited place then lands near its earlier self in the embedding, flagging the loop; a verification module using high-order geometry then recovers the relative pose. The whole thing learns detection and pose estimation without a single ground-truth label.
Why it matters
By treating the robot's own motion-induced overlap as the teacher, the method drops the labeling bottleneck entirely — and still beats supervised state-of-the-art, showing that co-occurrence in a sensor stream is a stronger signal than hand-made labels.
ROBOTICS'25Contrastive Touch-to-Touch Pretraining
Problem
Every tactile sensor design produces its own strange, private signal — a GelSlim reports something quite different from a Soft Bubble even when they press the same object. That means a model trained on one finger is useless on another, and you cannot build a general sense of touch. Bridging this sensor-to-sensor gap by hand is hopeless: there is no way to manually annotate what a GelSlim reading means in Soft-Bubble terms.
Approach
The trick is to let the same physical contact speak through both sensors at once. The authors collect a dataset where identical objects are probed by both the GelSlim and the Soft Bubble, so each real touch produces a naturally co-occurring pair of readings. Contrastive learning then treats the two readings of the same contact as a positive pair to pull together, and readings from different contacts as negatives to push apart. Out of this emerges a shared tactile embedding space where the two sensors' signals for the same touch coincide. No task labels are needed — the physical simultaneity of the two presses is the entire supervision.
Why it matters
Once the space is shared, a policy trained with one tactile sensor transfers directly to another without retraining — turning heterogeneous, incompatible fingers into interchangeable ones.
ROBOTICS'25Monocular Visual Place Recognition in LiDAR Maps via Cross-Modal State Space Model and Multi-View Matching
Problem
A cheap monocular camera needs to find where it is inside a pre-built LiDAR map of the world. But an RGB image is colored pixels and a LiDAR map is bare 3D geometry — the appearance gap between the two is enormous, and there is no obvious way to say which image matches which patch of point cloud. Labeling image-to-point-cloud correspondences across a whole city is not feasible.
Approach
The system learns a single embedding space that both modalities share. A VMamba visual state-space backbone encodes the RGB image and the point cloud into descriptors, and cross-modal contrastive learning supervises them: an image and the piece of LiDAR map that genuinely depicts the same place form a positive pair pulled together, while mismatched place pairs are pushed apart. Because a point cloud looks different from different angles, the method renders several viewpoint descriptors per place and matches them against the image using a 3D visible-point overlap similarity, so the right view wins. The pixel-view-scene training strategy builds the alignment at several granularities at once. The camera image thus retrieves its correct location in the laser map purely by landing in the same embedding neighborhood.
Why it matters
This lets a lightweight camera localize inside expensive LiDAR maps — cross-modal contrastive alignment does what no hand-labeled image-to-point-cloud dataset ever could, reaching state-of-the-art on KITTI and KITTI-360.
ROBOTICS'25Cohere3D: Exploiting Temporal Coherence for Unsupervised Representation Learning of Vision-Based Autonomous Driving
Problem
A self-driving car's camera should treat the same car ahead as one consistent object frame after frame, even as it turns, gets partly hidden, or changes apparent size. But scenes are dynamic and appearances shift wildly across time, so unsupervised vision methods tend to lose track of instance identity. Nobody can hand-label, across long driving logs, which pixel-blob at second five is the same object as which blob at second twenty.
Approach
Cohere3D borrows the labels it needs from a second sensor the car already carries. LiDAR is used to establish, frame to frame, which detections belong to the same physical instance over time — these instance-wise temporal correspondences become free supervision. Contrastive learning then trains the camera's bird's-eye-view features so that the same instance across different timesteps forms a positive pair pulled together, while different instances are pushed apart. Because the pairing comes from LiDAR-verified physical identity rather than raw appearance, the learned features stay coherent even when the object's look changes across a long sequence. The camera ends up with view-invariant, temporally stable instance representations, all learned without human labels.
Why it matters
Using one sensor's certainty about object identity to teach another sensor's representation, the method builds features that stay locked onto the same object over time — boosting data efficiency and accuracy across perception, mapping, prediction, and planning.
Reading it whole. Top to bottom, the themes walk the same idea outward: making pixels, then lifting them into 3D, then editing and restoring them, then turning the generator into a perceiver — and finally denoising a robot into motion, and the race to do all of it in fewer steps. The outputs differ wildly; the machinery — invent a task the data grades itself on, and avoid collapse — does not.
