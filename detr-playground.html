One object, one query

The why page says DETR's whole trick is a one-to-one match: each object may be claimed by exactly one query, so duplicates never form and the old clean-up pass disappears. Here you can feel the difference. Flip between DETR's one-to-one rule and the classic score-threshold rule, and watch the duplicate boxes appear and vanish.

← All themesThe big pictureIn the wildThe papers

What to notice. In one-to-one mode the optimal assignment gives every true object exactly one query (a solid line); every leftover query says nothing (faded) — zero duplicates, no clean-up needed. Flip to score threshold and every query that lands near an object fires, so popular objects collect a stack of overlapping boxes — the duplicate count jumps, and a hand-tuned de-duplication pass would be needed to collapse them. That removed pass is exactly what set prediction buys you.
