1 · Which order do I read a 2D image

Mamba was built to read sequences — words in a sentence, one after another — keeping a small running memory as it goes, so its cost grows only in a straight line with length instead of exploding the way attention does when it compares every element to every other. But an image is not a line; it is a 2D grid. To hand a picture to Mamba you first have to serialize it — unroll the grid into a single 1D stream of patches. The trouble is that any single unrolling order breaks the neighborhoods: two patches sitting side by side in the picture can end up far apart in the stream, so the running memory never learns they were touching. That is why nearly every vision-Mamba paper is really answering one question — in what order do I read the pixels? — with answers ranging from scanning several directions at once, to diagonals, snake paths, space-filling Hilbert curves, or letting the image content itself pick the route; the shared goal is a linear-time backbone that still respects 2D structure, and a parallel theory strand asks what Mamba's compressed memory actually captures compared to full attention.
CVPR'26RNN as Linear Transformer: A Closer Investigation into Representational Potentials of Visual Mamba Models
Problem
Mamba works well on images, but nobody could clearly say why — or exactly how much of a picture it can hold in its small running memory compared to full attention. Without that understanding, designing better vision backbones is guesswork.
Approach
The authors open up the math and show that Mamba is essentially attention with a data-dependent mask that it learns on the fly: instead of comparing every patch to every other patch in full, it applies a learnable, content-aware filter that decides what to remember and what to forget as it reads. Through a rank analysis they place Mamba between plain linear attention and full softmax attention — richer than the cheap linear approximation because that learned selective mask buys back expressiveness, but still a low-rank, compressed stand-in for the real thing. To measure this concretely they introduce a Binary-AUC score that objectively rates how sharp and meaningful a model's activation maps are, and they drop Mamba into the DINO self-supervised training recipe. The result is a backbone that captures genuine long-range relationships across the image while keeping the linear-time cost.
Why it matters
It gives the theory behind the whole theme — why a linear-time reader can still see across a whole image — by showing Mamba is a learnable, low-rank approximation of attention rather than a weaker cousin, reaching 78.5% ImageNet accuracy with clean, interpretable feature maps.

CVPR'26CrackSSM: Reviving SSMs for Crack Segmentation via Dynamic Scanning
Problem
Cracks are long, thin, wandering shapes that stretch across a whole image, so a segmenter has to connect pixels that are far apart. Standard vision-Mamba uses a fixed set of scan directions, which shoves distant crack pixels next to each other in the 1D stream and puts genuinely neighboring pixels far apart, scrambling the very continuity the crack depends on.
Approach
CrackSSM's idea is to let the picture choose its own reading order instead of forcing every image through the same raster path. A lightweight branch first predicts, at each spot, which way the crack is heading — horizontal, vertical, or one of two diagonals — trained against edge-direction labels made from a Sobel filter. Using that direction map, the model builds snake-like 1D sequences along each orientation and then reorders the tokens so that patches lying along the same crack become neighbors in the stream — exactly what a sequential reader needs, so its running memory can flow along the crack rather than leaking across empty background. Those content-aware sequences go through ordinary Mamba (S6) blocks with no changes to the core, are folded back into 2D, and a wavelet-guided decoder sharpens the thin edges. This is a data-dependent scan path rather than a one-size-fits-all one.
Why it matters
It is the cleanest illustration of the scanning-order problem and its fix: a fixed raster order breaks a crack's neighborhoods, so making the scan content-adaptive keeps distant-but-connected pixels together — reaching top scores on all three benchmarks at roughly a quarter of the prior method's compute.

CVPR'26SSM-Aware Token-Efficient VMamba via Adaptive Patch Pruning and Merging for Person Re-Identification
Problem
Recognizing the same person across camera views needs fine detail but must run fast on limited hardware. Even though vision-Mamba is already linear-time, it still grinds through every image patch, and many of those patches are redundant background that add cost without adding identity clues.
Approach
The insight is that Mamba's own reading process already tells you which patches matter — so use its state signals, not borrowed attention tricks, to decide what to throw away. As the model scans, each patch causes a certain amount of change in the running memory; patches that barely move the state, or that don't line up with the scan's direction of travel, are the uninformative ones. In the early, shallow layers TE-VMamba prunes those low-impact patches outright; in deeper layers it merges similar neighbors together, with the cut-off threshold adapting per layer and per image rather than being fixed. Because the importance score is read straight from the SS2D state-update behavior and directional coherence, the pruning respects Mamba's sequential, recurrent nature instead of fighting it. The stream that survives is shorter, so every downstream block runs cheaper.
Why it matters
It shows the scan is not just a way to read the image but a source of information in its own right — the running state reveals which tokens carry identity — letting the model shed over 60% of its compute while holding accuracy, keeping the backbone genuinely lightweight.

CVPR'26Scaling Parallel Sequence Models to Vision Foundation Models
Problem
The biggest, most capable vision models hit a wall because attention's cost grows with the square of the number of patches — double the resolution and the bill explodes. That quadratic blowup caps how large a model or how high a resolution you can afford to train.
Approach
The approach is to swap the expensive engine for a linear-time one and see whether it still scales up to foundation-model size. In place of quadratic self-attention, the model uses parallel sequence and state-space blocks — the same read-in-order-with-a-running-memory machinery Mamba is built on — whose cost climbs only in a straight line as patches or resolution grow. Crucially the team pushes this not just on a small network but all the way up to large, general-purpose foundation models meant to serve many downstream tasks, testing whether the sub-quadratic substitution holds its accuracy at scale. The result is that these linear-time backbones match or beat their attention-based counterparts while being far cheaper to train and run at high resolution — evidence that the whole vision stack can move off quadratic attention.
Why it matters
It answers the payoff behind this entire theme — why bother serializing images for Mamba at all — by showing the linear-time state-space backbone scales cleanly to foundation-model size and higher resolution without giving up performance.

2 · Where linear time pays off most

Video and streaming inputs can be thousands of frames long, and attention's cost grows with the square of the sequence length, so a full-attention model simply cannot fit an hour-long clip into memory. This is exactly where linear-time state-space models pay off most. Instead of comparing every frame to every other frame, they carry a running memory that slides forward through the video and updates as each new frame arrives, so the cost grows only in a straight line with length. That single running state lets them model long video, the structure of actions over time, or live streaming data at linear cost. The papers here often add multi-scale or bidirectional scans so the same model can catch both fine, fast motion and slow, long-range context at once. The recurring challenge is not letting fine frame-level detail get forgotten while the model summarizes a very long past into one compact memory.
CVPR'26TimeViper: A Hybrid Mamba-Transformer Vision-Language Model for Efficient Long Video Understanding
Problem
Understanding a long video means feeding thousands of frames into a model, and a pure Transformer chokes because its cost grows with the square of how many tokens it sees. A pure state-space model stays cheap but is not expressive enough for hard multimodal questions. On top of that, once a long video is turned into tokens, huge numbers of those visual tokens are redundant and just waste compute.
Approach
TimeViper uses a hybrid backbone that stacks Mamba's cheap running-memory layers together with a few attention layers, so it keeps state-space efficiency but borrows attention's expressive power where it matters. Its TransV module then transfers and compresses the crowd of vision tokens into a small set of instruction tokens inside the language model, using gated cross-attention to decide what to keep. The authors noticed that in these hybrid models information naturally flows from vision tokens into text tokens at the deeper layers, so most vision tokens can be dropped once that transfer has happened. This lets the model digest hour-long videos with thousands of frames without carrying dead weight. The result is roughly 40% faster token generation than a comparable Transformer while staying competitive on video question answering, grounding, and captioning.
Why it matters
Quadratic attention simply does not fit thousands of frames into memory, so the Mamba half provides a linear-cost running memory and the token transfer throws away the redundancy that would otherwise sink even that.

CVPR'26MS-Temba: Multi-Scale Temporal Mamba for Understanding Long Untrimmed Videos
Problem
Spotting exactly when actions happen in long, untrimmed videos, up to about 40 minutes, is hard because many actions overlap and unfold at very different speeds. Transformers hit their quadratic wall at that length, but a plain Mamba scan smears fine-grained timing detail because it only tracks one running state. The model needs to be both cheap over long stretches and precise about short, fast events.
Approach
MS-Temba extends Mamba by running its state-space scans at several temporal scales at once, using dilated SSMs that skip frames at different strides to see both quick dynamics and slow, long-range structure. Its Temba Blocks combine these multi-branch dilated scans with projection-based alignment so the different scales stay comparable, plus scale-aware supervision that trains each branch to attend to its own time range. A lightweight Multi-scale Mamba Fuser then merges the scale-specific views back together, again with an SSM, to produce boundary-accurate predictions of where each action starts and ends. Because every piece is a state-space scan rather than attention, the whole thing stays linear in video length. It reaches state-of-the-art action detection on dense daily-living benchmarks with only 17 million parameters, roughly five times fewer than Transformer competitors.
Why it matters
Attention's square-law cost makes 40-minute videos infeasible, while multi-scale dilated state-space scans give a linear-time way to hold long-range context and still keep the fine timing needed to pin down action boundaries.

CVPR'26HieraMamba: Video Temporal Grounding via Hierarchical Anchor-Mamba Pooling
Problem
Video temporal grounding means finding the exact moment in a long, untrimmed video that matches a natural-language query, like the moment I pick up the knife. Transformer-based groundings run into quadratic cost as videos get long, and cannot efficiently juggle context at many time scales. A naive Mamba scan fixes the cost but loses that multi-scale temporal structure.
Approach
HieraMamba stacks Hierarchical Anchor-Mamba Pooling blocks that process the video and the text query at several temporal resolutions at the same time. Each block runs a selective Mamba scan over anchor-pooled windows of the timeline, producing a scale-aware summary that still carries global context through the state-space recurrence rather than through expensive attention. These multi-scale features are then fused and trained with two matching losses: an Anchor-Contrastive Consistency loss that lines up the right query-moment pairs across scales, and a Scalable Pair Contrastive loss that pushes valid moment proposals apart from invalid ones. Together this lets the model localize a language query in hour-long footage while avoiding full self-attention. It sets state-of-the-art on the long-video Ego4D-NLQ, MAD, and TACoS grounding benchmarks.
Why it matters
Full self-attention over a long video is quadratic and will not fit, so Mamba's linear-time recurrence carries the global context while the hierarchical pooling recovers the multi-scale detail needed to point at one exact moment.

CVPR'26ReMoRa: Multimodal Large Language Model based on Refined Motion Representation for Long-Video Understanding
Problem
Multimodal language models struggle with long-form video because attention's cost grows with the square of the number of frames, and processing every RGB frame is enormously redundant. Sampling only a handful of frames evenly saves compute but throws away temporal coverage, so the model misses what happened in between.
Approach
ReMoRa sidesteps the redundancy by working in the compressed domain of the video codec itself instead of decoding every raw frame. It keeps only sparse RGB keyframes (the codec's I-frames) for appearance, and reuses the motion vectors the codec already stored to describe how things moved between frames. A Refined Motion Representation module cleans up those noisy, blocky motion vectors into fine-grained motion that approximates dense optical flow. A Hierarchical Motion State Space module then compresses the long motion sequence in linear time, carrying a running memory of the whole clip rather than attending across it. This compressed, motion-aware pipeline lets the model reason over long videos cheaply, and it outperforms baselines on LongVideoBench, NExT-QA, and MLVU.
Why it matters
Quadratic attention over every RGB frame does not scale to long video, so ReMoRa leans on the codec's own motion data plus a hierarchical state-space module that summarizes the whole sequence at linear cost.

3 · Every pixel, and unordered 3D

Segmentation, super-resolution and restoration are jobs where the model must reason about every single pixel of a large image, not just a summary of it. That is exactly the regime where classic attention becomes unaffordable, because attention compares every pixel to every other pixel and the cost grows with the square of the number of pixels. Mamba changes the deal: it sweeps through the image once in a single pass and still lets faraway pixels influence each other, giving a global view at a cost that grows only linearly with size, which is why this is the densest cluster of vision-Mamba work, spanning medical scans and remote sensing alike. Point clouds push the same idea into three dimensions, where the problem is even harder because a point cloud is an unordered bag of 3D points with no natural first-to-last order to feed a sequential scanner. So these papers design geometry-aware scan orders — walking points along a space-filling Hilbert curve, or sorting them by curvature and distance — so that the one-pass linear scan still respects the underlying 3D shape. In both settings the same linear-time engine handles inputs that are simply too large, or too unstructured, for attention to touch.

CVPR'26GeoSemba: Reconstructing State Space Model for Cross Paradigm Representation in Medical Image Segmentation
Problem

Medical image segmentation has to label every pixel of a scan so doctors can plan treatment precisely, so a model that can look everywhere at once without exploding in cost is very attractive. But to feed a 2D scan into a Mamba you first flatten it into a single 1D line of pixels, and that flattening tears apart the anatomy — pixels that sit next to each other in the body end up far apart in the line. On top of that, most methods handle where things are (space) and what tissue they are (channels) as two separate problems, so they miss the joint cues a radiologist actually uses.

Approach

GeoSemba rebuilds the core state-update step of the state-space model so that anatomical geometry survives the flattening from 2D into 1D. Its Semantic-guided State Refiner first groups pixels into region representatives, then conditions how the scan carries information forward on the geometric relationships between those regions — so when the scan moves from one region to a structurally related one, the running memory is steered to propagate coherent, tissue-aware information instead of just marching pixel by pixel. A second piece, the Cross-dimensional Affinity Refiner, works coarse-to-fine to strengthen the informative interactions between spatial position and channel identity while damping weak, noisy correlations, so the model reasons about where and what together rather than in isolation. Crucially, all of this happens inside a single scan, so the model keeps geometric faithfulness and channel discrimination without paying attention's quadratic cost. The result is state-of-the-art segmentation accuracy across six different medical imaging modalities while staying computationally efficient.

Why it matters

By making the linear-time scan geometry-aware, GeoSemba shows you can label every pixel of a medical scan with a global view of the whole image, at a cost that scales linearly rather than with the square of image size.

CVPR'26VEMamba: Efficient Isotropic Reconstruction of Volume Electron Microscopy with Axial-Lateral Scanning
Problem

Volume electron microscopy images cells in 3D, but the depth (axial) direction is captured five to ten times more coarsely than the in-plane (lateral) directions, so the volume looks sharp sideways and blurry through its stacked slices. Restoring an even, isotropic volume means filling in that missing depth detail, which requires seeing long-range relationships across the whole 3D block. Accurate diffusion-based restorers can do it but are enormously expensive (15M parameters, 22.51T FLOPs), while a plain Mamba scan in one or two fixed directions is blind to the specific axial-versus-lateral structure of the data.

Approach

VEMamba builds an Axial-Lateral Cross-SSM scan that deliberately traces information both from depth into the image plane and from the plane back into depth, so the model reasons about the anisotropy instead of ignoring it. Concretely it sweeps the volume along 8 trajectories — 4 axial-to-lateral and 4 lateral-to-axial — split into two hemispheres of directions, so no orientation of the 3D block is left unscanned. A Dual-Window Aggregation Module then fuses these directional streams, computing features from the 4-direction and the 8-direction scans and learning attention weights that adaptively decide how much each directional stream should contribute at each location. To handle scans degraded by different amounts, VEMamba is pretrained self-supervised with a MoCo-style contrastive objective on paired subvolumes, and a Volume Degradation-Informed Modulation module conditions the network on a learned descriptor of how degraded the input is, so the model can retune its restoration at test time. All of this runs at just 0.94M parameters and 0.28T FLOPs — dramatically leaner than the diffusion baseline while matching or beating its quality.

Why it matters

By tailoring the linear-cost scan order to the axial-lateral geometry of the microscope, VEMamba restores full 3D volumes with a global receptive field at a tiny fraction of the compute a quadratic or diffusion model would demand.

CVPR'26Mamba Learns in Context: Structure-Aware Domain Generalization for Multi-Task Point Cloud Understanding
Problem

A point cloud is an unordered set of 3D points, and Mamba needs a 1D order to scan them, so most methods just sort by raw coordinates. But that coordinate ordering flips around whenever the viewpoint changes or part of the object is missing, which shatters the object's natural part-to-whole structure and makes the sequence unstable. Across different domains this structural drift compounds, so a model trained in one setting reads the same object as a different sequence in another and fails to generalize.

Approach

SADG builds a Structure-Aware Serialization that orders points by properties intrinsic to the shape rather than by raw coordinates — using centroid distance and geodesic-curvature spectra — so the same object produces the same sequence even after it is rotated, moved, or partly occluded, giving a transformation-invariant order for the scan. On top of that ordering, a Hierarchical Domain-Aware Modeling stage consolidates the structure within each domain and then fuses relationships across domains, so the sequential model stays stable when the data distribution shifts. At test time a lightweight Spectral Graph Alignment nudges the target features toward the source prototypes without retraining the model at all. Framed as in-context learning, this lets one Mamba handle several point-cloud tasks — reconstruction, denoising, registration — while preserving both global topology and local geometric continuity. It consistently beats prior methods across tasks with better structural fidelity, and the authors release the MP3DObject benchmark built from Matterport3D to test it.

Why it matters

By choosing a scan order that respects the object's geometry instead of its arbitrary coordinates, SADG lets the linear-time engine read unordered 3D data stably across domains — the point-cloud analogue of giving Mamba a global, structure-preserving view.

CVPR'26RI-Mamba: Rotation-Invariant Mamba for Robust Text-to-Shape Retrieval
Problem

Text-to-shape retrieval — typing a description and getting back matching 3D objects — normally assumes every shape sits in a tidy canonical pose, which breaks the moment real objects appear at arbitrary orientations. Existing methods also lean on human annotations and pre-aligned shapes, which pins them to a handful of object categories. The result is retrieval that works in the lab but not for messy real-world catalogs like e-commerce or scene design.

Approach

RI-Mamba is the first rotation-invariant state-space model for point clouds: it uses global and local reference frames to separate an object's pose from its underlying geometry, so a chair recognized as a chair no matter how it is turned. To turn the unordered points into a sensible 1D order for scanning, it applies Hilbert sorting — walking the points along a space-filling curve so that points close in 3D stay close in the sequence — giving the scan a geometrically meaningful order. Because throwing away pose entirely loses useful context, it adds patchwise orientational embeddings via feature-wise linear modulation that recover pose information in linear time, sidestepping the quadratic cost of earlier pairwise approaches while keeping rotation invariance intact. For training without labels, it generates triplets automatically using rendering, image captioning, and text prompts, so it can scale to diverse data. Tested on OmniObject3D with over 200 categories, it reaches state-of-the-art retrieval under arbitrary orientations.

Why it matters

Hilbert sorting gives Mamba a rotation-robust, geometry-respecting order for unordered 3D points, so the linear-time scan can match text to shapes at any orientation without the quadratic cost of pose-aware attention.

4 · Fast context plus sharp reasoning

Pure Mamba is fast, but on some tasks it is less expressive than attention because it summarizes everything it has seen into a lossy, fixed-size memory that quietly forgets the details it does not think it will need. A large group of papers responds by combining the two ideas: let Mamba carry cheap global or temporal context across a long sequence, and let attention do the sharp, precise local reasoning where exact detail matters. A parallel line instead fixes the core itself, giving the state-space model a smarter memory and better scan so that its single running summary keeps more of the past accountable. But the whole reason anyone reaches for Mamba is real, measured savings, so another line foregrounds the payoff rather than the mechanism. That means real-time detectors that gain global awareness without paying attention's quadratic bill, tiny on-device backbones, and linear-time 3D reconstruction that beats quadratic baselines on the actual wall-clock. Both directions are chasing the same goal: making linear-time modeling actually expressive and actually deployed.
CVPR'26When Transformers Meet Mamba: A Hybrid Transformer-Mamba Network for Video Object Detection
Problem
Detecting objects in video needs strong spatial reasoning within each frame and strong temporal reasoning across frames. Transformers handle both well but cost grows quadratically as the sequence of frames gets long, while Mamba is linear-cost but a weaker context learner. Neither one alone gives the right accuracy-versus-speed trade-off.
Approach
TMambaDet splits the work along the two axes and gives each to the tool that fits. Inside a single frame, a Spatial Adaptive Deformable Transformer uses attention that samples a query-dependent set of points, spending its expensive precision only where the object actually is. Across frames, a Temporal Cascaded Bidirectional Mamba scans the frame sequence forward and backward at linear cost, carrying temporal context cheaply so long clips do not blow up the compute. A final Mamba Entangled Transformer decoder weaves the two back together with multi-scale deformable attention. The design is a clean division of labor: attention for sharp intra-frame detail, bidirectional Mamba for cheap inter-frame memory.
Why it matters
This is the fast-context-versus-sharp-reasoning trade-off made concrete: Mamba pays the linear-time price for the long temporal dimension where quadratic attention would hurt most, and attention is reserved for the fine spatial reasoning where its precision earns its cost, reaching state-of-the-art on ImageNet VID and EPIC-KITCHENS-55.

CVPR'26Gated KalmaNet: A Fading Memory Layer Through Test-Time Ridge Regression
Problem
State-space models run at constant memory and linear compute, but they keep only a lossy fading summary of the past, so they do poorly when a task requires recalling a specific earlier detail. Softmax attention recalls perfectly by holding a growing cache of everything, but that cache scales badly in time and storage. The open question is whether one layer can have SSM efficiency and attention-level recall at once.
Approach
Gated KalmaNet fixes the memory itself instead of bolting attention on top. It treats the running state as the answer to a small ridge regression that is re-solved online at test time, using a Kalman-filter-style update so each new token corrects the summary rather than just fading it. An input-dependent gate applies adaptive regularization, controlling how ill-conditioned that regression can get so the state stays trustworthy. To make this stable in low precision and fast on a GPU, it runs a Chebyshev Iteration in a hardware-aware, chunk-wise scheme. The result is a fading-memory layer that accounts for far more of the past without giving up the SSM cost profile.
Why it matters
By turning the SSM's summary into a self-correcting estimate rather than a leaky average, it closes much of the recall gap that separates cheap linear models from expensive attention, gaining over 10% on long-context RAG and LongQA out to 128k tokens and beating Mamba2 and Gated DeltaNet on recall.

5 · Linear-time vision on a small onboard GPU

A field robot, a drone, or a self-driving car has to segment the scene, detect objects, and clean up its images in real time, and it has to do all of that on a small GPU bolted onto the machine itself. The trouble is that transformer backbones, the usual workhorse for this kind of vision, get more expensive in a way that grows with the square of the image size or the number of points in a cloud, so as the picture gets bigger or the sensor gets richer, the compute bill explodes and blows the onboard budget. Mamba, a state-space model, does the same job of relating far-apart parts of an image to each other, but its cost grows only linearly with size. So the papers here swap the attention blocks out for selective-scan blocks, and several of them keep a few attention layers around as a hybrid to get the best of both. This turns out to be by far the largest use of Mamba in robotics. The appeal is squarely about efficiency and being able to actually ship the thing, not about remembering long stretches of history. The payoff is a perception stack that genuinely runs onboard in real time instead of only in the lab.
ROBOTICS'25CoMamba: Real-time Cooperative Perception Unlocked with State-Space Models
Problem
When several connected cars share what their sensors see so they can perceive the road together, the shared features pile up fast as more vehicles join in. The usual transformer that fuses all that data costs grow with the square of how much is shared, so adding agents quickly overwhelms an onboard computer and cooperative 3D detection stops being real-time.
Approach
CoMamba throws out the transformer attention that fused features across vehicles and puts a bidirectional state-space model (Mamba) in its place. Bidirectional means it scans the combined stream of features both forward and backward, so every agent's view can inform every other's, the same all-to-all mixing attention gave you. The key difference is that this scan costs grows only linearly with the amount of shared data instead of quadratically. They test it on standard vehicle-to-everything and vehicle-to-vehicle driving datasets for 3D object detection.

The result matches transformer-level accuracy while staying real-time as the number of connected agents keeps growing, which is exactly what an onboard driving computer with a fixed compute budget needs.

Problem
A drone trying to follow a target at night has three problems at once: there is little good nighttime training footage, most trackers lean on a separate image-brightening step, and the vision-transformer backbones they rely on are heavy to run in the air. Approach

6 · A memory that persists, a policy small enough to run

The deepest robotics appeal of a state-space model like Mamba is a memory that stays a constant size and can run forever onboard. A robot never stops: it acts continuously and keeps receiving observations for as long as it is switched on. Attention, the mechanism behind most modern models, keeps a key-value cache that grows by one entry every single timestep, which is exactly the wrong shape for a device meant to run for hours on a battery. Mamba instead carries a fixed-size running state that summarizes everything so far without ever getting bigger, which fits a real-time, memory-bounded control loop. This shows up most literally in localization and place recognition, where one paper here uses that running state as an actual memory bank that carries map history forward, and in shrinking a heavy policy until it is small enough to run on a real arm. The honest reality check from the 2025 corpus is that this persistent-memory half of the promise appears in only a few places. Most robotics Mamba work so far is an efficiency story first and a long-memory story second: it wins by being cheaper and faster, and only occasionally by genuinely remembering longer.
ROBOTICS'25MambaMap: Online Vectorized HD Map Construction using State Space Model
Problem

Approach
MambaMap keeps a memory bank that stores historical bird's-eye-view features and map-element queries from earlier moments, then uses a Mamba state-space model to fold that stored history into what the car sees right now. It adds multi-directional and spatial-temporal scanning so the model can relate map pieces across both space and time, plus a gating mechanism that selectively decides which stored past information is still worth integrating. This is the clearest genuine case in the corpus of Mamba's running state being used as a real persistent memory rather than just a cheaper backbone. The result is a road map that stays coherent even where the current sensors are blind.

Top to bottom, the themes walk the same scan outward: first solve how to read a 2D image in order, then let linear time pay off on long video, then reason over every pixel and every point, then blend Mamba with attention and prove the payoff — and finally hand the constant-size memory to a robot that must run forever onboard.
