1 · Slots and object discovery: finding objects without labels

Object-centric learning challenges the entangled-feature paradigm: instead of one monolithic blob per scene, split it into slots that compete to explain different spatial regions. Each slot binds one object, discovering identity and position from pixels alone—no manual labels. This deep-read traces four architectures attacking the core problems: fragmentation (too many slots per object), geometric gaps (synthetic to real), semantic clarity (tokens to objects), and layer-by-layer interpretability (how does a transformer actually encode object structure?). The papers share a single primitive: constraint-based slot allocation or pruning that ensures one slot, one concept.
CVPR'26Finding Distributed Object-Centric Properties in Self-Supervised Transformers
Problem
Self-supervised vision transformers (DINO, MAE) learn object-centric properties but their encoding remains opaque: where in the network does position live, which heads encode shape, how is size tracked across layers? Interpretability is crucial for understanding what representations models actually learn.
Approach
Probing techniques trace how object properties (position, size, shape) are encoded across transformer layers and attention heads. Analysis of information flow from input to output quantifies which components specialize in different object aspects.
Why it matters
Distributed encoding reveals that specific layers and heads partition labor—early transformer layers capture spatial properties while deeper layers encode semantic attributes. This insight informs better model design and enables direct observation of object-binding mechanisms without manual supervision.
CVPR'26EvObj: Learning Evolving Object-centric Representations for 3D Instance Segmentation without Scene Supervision
Problem
Unsupervised 3D instance segmentation fails across the domain gap: models pretrained on synthetic ShapeNet objects shatter when applied to real ScanNet scans, struggling with occlusions and topological variation. Collecting scene annotations is prohibitively expensive.
Approach
EvObj extends GrabS with two modules: Object Discerning evolves object candidates through self-supervised pseudo-labeling accumulated from target data; Object Completion reconstructs partial geometries to recover hidden surfaces. Progressive adaptation bridges synthetic-to-real without manual labels.
Why it matters
Each object slot becomes adaptive: as the model processes real data, candidates refine their priors incrementally. Completion ensures occlusion-fragmented geometry stays unified within one slot, achieving state-of-the-art unsupervised 3D segmentation on multiple benchmarks.
CVPR'26Reconstruction-Guided Slot Curriculum: Addressing Object Over-Fragmentation in Video Object-Centric Learning
Problem
Video slot models over-fragment: a single object spreads across multiple redundant slots as the model tries to minimize reconstruction loss while utilizing all available slots. This defeats the purpose of semantic object discovery.
Approach
SlotCurri starts with minimal slot budget (e.g., 2) and progressively allocates new slots only in regions with persistent high reconstruction error. Structure-aware loss preserves edges and local contrast. Cyclic inference propagates slots forward and backward through video for temporal consistency.
Why it matters
Reconstruction error becomes the sole guide for slot necessity: high error signals true missed objects; low error signals redundancy. Progressive allocation eliminates over-fragmentation a priori rather than post-hoc merging, yielding sharper semantic boundaries and temporally coherent object representations.
CVPR'26CORE: Compact Object-centric REpresentations as a New Paradigm for Token Merging in LVLMs
Problem
Large Vision-Language Models waste computation: visual tokens grow quadratically with resolution, and standard compression ignores semantic structure, losing information about which tokens belong to which object.
Approach
CORE merges visual tokens into compact object-centric representations using segmentation priors. An efficient segmentation decoder generates masks guiding which tokens fuse; centroid-guided sorting restores spatial order. Shared ConvNeXt backbone serves both segmentation and the language model.
Why it matters
Each object becomes one token slot: consolidating all pixels of a bird into a single learned representation preserves semantic identity while cutting computation 16x and KV-cache 182x. This object-centric merging paradigm outperforms pixel-grid compression because it respects the natural structure of scenes.

2 · Compositional scenes: building and decomposing a scene from parts

Object-centric learning decomposes scenes into separable parts and objects that can be understood independently and then reasoned about compositionally. Rather than treating a scene as a monolithic whole, these approaches model individual objects with their own geometry, dynamics, and semantics, enabling recomposition, editing, and transfer across contexts. This theme spans spatial decomposition—breaking a 3D scene into object parts—temporal factorization of motion into object-specific dynamics, and semantic labeling of reconstructed parts. By grounding scene understanding in object parts instead of holistic representations, these methods enable interactive editing, compositional generalization, and robust transfer to novel scenarios.
CVPR'26Inferring Compositional 4D Scenes without Ever Seeing One (COM4D)
Problem
Reconstructing dynamic 4D scenes with multiple moving and static objects from single video is intractable without 4D labeled data. Existing static 3D scene data and dynamic per-object data exist separately, making joint training on compositional 3D structure and temporal dynamics impossible through conventional means.
Approach
COM4D uses a single 21-block Diffusion Transformer with shared weights, routing spatial reasoning to even blocks (trained on multi-instance static scenes) and temporal reasoning to odd blocks (trained on dynamic object sequences). At inference, Attention Mixing recombines these capabilities: even blocks handle multi-object spatial composition while odd blocks process per-object temporal history, enabling 4D decomposition without paired 4D supervision.
Why it matters
By factorizing the scene into spatial (where objects are) and temporal (how each object moves) components trained separately, COM4D recovers compositional 4D structure where each object's geometry and motion remain disentangled and recomposable, even from a single video.
CVPR'26Pano3DComposer: Feed-Forward Compositional 3D Scene Generation from Single Panoramic Image
Problem
Generating complete 3D scenes from panoramic images requires decomposing the problem into object generation and object placement, but iterative layout optimization is slow and cannot handle panoramic distortions and full 360-degree coverage in feed-forward mode.
Approach
Pano3DComposer decouples object generation from layout through an Object-World Transformation Predictor that converts 3D objects from local to world coordinates using target crop, multi-view renderings, and camera parameters. A Coarse-to-Fine alignment mechanism iteratively refines geometric consistency by rendering feedback, enabling efficient compositional placement without gradient optimization.
Why it matters
By treating generated 3D objects as separable, transformable parts with explicit world-coordinate predictions, the method composes complete panoramic scenes while maintaining object identity and pose, enabling downstream editing and reuse of individual components.
CVPR'26Training-free Motion Factorization for Compositional Video Generation
Problem
Compositional video generation with multiple instances and diverse motion types fails because uniform diffusion guidance cannot differentiate motion semantics per instance, resulting in similar and implausible motion across diverse objects.
Approach
Motion Factorization decomposes motion into canonical categories (motionlessness, rigid, non-rigid), using Structured Motion Reasoning on a graph encoding instances and interactions to infer frame-wise changes. Disentangled Motion Guidance applies specialized branches: static anchoring, geometric invariance for rigid bodies, and displacement fields for deformable objects, each guiding generation differently.
Why it matters
By factorizing motion into object-specific categories and applying tailored guidance per instance, the method ensures each object in the scene generates appropriate motion consistent with its type, enabling compositional video synthesis where motion remains object-specific and recombosable.
CVPR'26Semantic Foam: Unifying Spatial and Semantic Scene Decomposition
Problem
3D reconstruction methods like Gaussian Splatting and NeRF produce photo-realistic outputs but lack clean semantic decomposition, suffering from occlusion artifacts and inconsistent labeling that prevent reliable object extraction and scene editing.
Approach
Semantic Foam extends the Radiant Foam volumetric representation by adding per-cell semantic feature fields parameterized at the Voronoi mesh level. A volumetric total variation loss on the Voronoi adjacency graph enforces spatial smoothness and semantic consistency, enabling clean part-level segmentation without occlusion artifacts.
Why it matters
By grounding semantics directly in the Voronoi volumetric mesh—where each cell represents a spatial partition—objects and parts become explicitly labeled, extractable, and editable. Scene decomposition into semantically coherent parts enables compositional editing operations like removal, insertion, and transfer without floating artifacts.

3 · The binding problem: tying concepts to the right object

The binding problem—ensuring each feature or concept attaches to its correct object—is fundamental to visual understanding. When models learn abstract concepts or recognize objects in cluttered scenes, they must prevent attribute confusion: a red ball in a blue room should not confuse ball-ness with blueness, and motion from a hand should not bind to a camouflaged target behind it. This deep-read explores four approaches to binding: composing visual concepts by tethering them to prompt tokens, disambiguating camouflaged objects through fine-grained semantic probes, aligning multi-sensor IMU signals to specific body parts, and learning hierarchical concept decomposition so that novel combinations remain grounded in their constituent parts.
CVPR'26Composing Concepts from Images and Videos via Concept-prompt Binding
Problem
Visual concept composition struggles with accurately extracting complex concepts from visual inputs and combining concepts from both images and videos without rigid LoRA adapters or masks that fail under occlusion, temporal change, or non-object attributes. The core challenge is preventing learned concepts from bleeding into one another or contaminating the target generation with irrelevant visual details.
Approach
BiCo (Bind & Compose) binds visual concepts directly to textual tokens via a hierarchical binder structure embedded in the Diffusion Transformer cross-attention. A Diversify-and-Absorb Mechanism enriches prompts while filtering out concept-irrelevant details, and a Temporal Disentanglement Strategy uses dual-branch binders to learn image and video concepts separately, ensuring each concept remains tethered to its intended semantic token.
Why it matters
By binding each concept to a specific textual token rather than relying on loose spatial masks, BiCo ensures that complex visual properties—including motion, texture, and non-object attributes—stay attached to their source object and do not leak across composition boundaries.
CVPR'26Training-Free Open-Vocabulary Camouflaged Object Segmentation via Fine-Grained Object Binding and Adaptive Hybrid Prompt
Problem
When objects visually camouflage into backgrounds, sparse textual prompts and weak patch-level modeling fail to bind object semantics to the target region, allowing background interference to mask the true object boundary. The binding challenge here is acute: the model must separate object features from background features that are nearly identical in appearance.
Approach
A semantic probe decouples object and background features by ranking inter-patch categorical similarity, while entropy-guided text embedding adjustment (EGTEA) optimizes textual representations to sharpen object-concept binding. Adaptive hybrid prompt generation feeds these refined semantic signals into SAM, ensuring fine-grained spatial binding between the segmentation mask and the true object extent.
Why it matters
Fine-grained object binding through semantic probes prevents the segmentation model from mistakenly attaching object labels to background pixels; by explicitly measuring categorical consistency between patches, the method keeps the target object semantically isolated from its visually similar surroundings.
CVPR'26MoBind: Motion Binding for Fine-Grained IMU–Video Pose Alignment
Problem
Integrating IMU signals with 2D video pose requires binding motion measurements to the correct body parts, yet irrelevant visual backgrounds clutter the alignment, multi-sensor IMU configurations lack structured modeling, and coarse semantic alignment misses fine-grained temporal correspondence between sensor and skeletal motion. Binding failure occurs when hand motion in the background interferes with torso IMU readings, or when limb trajectories are assigned to the wrong sensor.
Approach
MoBind employs hierarchical contrastive learning that aligns IMU signals with skeletal motion (not raw pixels), decomposing full-body motion into sensor-aligned local body-part trajectories. Token-level contrastive learning achieves sub-second temporal binding while global aggregation preserves full-body action semantics, and Masked Token Prediction ensures each IMU reading remains semantically grounded to its corresponding body part.
Why it matters
By binding each IMU signal to specific body-part trajectories rather than global video features, MoBind prevents background motion and unrelated limb activity from corrupting sensor-pose correspondence, keeping each multimodal signal tethered to its true anatomical source.
CVPR'26Learning by Analogy: A Causal Framework for Compositional Generalization
Problem
Models fail to generalize to novel combinations of learned concepts because they do not bind concept components hierarchically; attributes remain entangled rather than modular, so composing red+sphere from learned red and sphere components produces gibberish rather than a red sphere. The binding problem here is about maintaining separable semantic levels so that concepts can be recombined without interference.
Approach
A hierarchical data-generating process encodes concepts at different levels using causal modularity and minimal-change principles, with latent hierarchical structures provably recoverable from text-image pairs. Diffusion timesteps are interpreted as hierarchical levels, and sparsity regularization on concept attention maps ensures that low-level components bind to specific attributes while high-level concepts remain distinct.
Why it matters
By binding each concept level to a distinct causal mechanism with minimal-change constraints, the framework ensures that when novel concept combinations are encountered, the model recomposes from modular, hierarchically-bound primitives rather than attempting to extrapolate from memorized instances.

4 · Object-centric control: per-object generation, layout, and pose

Object-centric representation decompose a scene into independent entities—each object is a controllable unit with its own geometry, appearance, and spatial position. This primitives enables precise control: you can place each object independently, edit its attributes without affecting neighbors, or generate novel compositions by rearranging elements. The papers below show object control realized across three dimensions—generation quality per object, spatial layout via coordinates, and 6D pose refinement—each proving that treating objects as atomic handles unlocks capabilities frozen models cannot match.
CVPR'26OSPO: Object-Centric Self-Improving Preference Optimization for Text-to-Image Generation
Problem
Text-to-image generation models suffer from object hallucination and misalignment—generating incorrect object attributes, missing objects described in text, or adding spurious objects not mentioned. Existing self-improving methods use only coarse image-level supervision, failing to enforce fine-grained object-level correctness.
Approach
OSPO constructs object-centric preference pairs by automatically generating multiple images per prompt, masking individual objects, and using object-level rewards to score alignment. The framework trains on these fine-grained pairs using object-weighted SimPO loss, teaching the model to reason about and refine each object independently rather than optimizing the image as a whole.
Why it matters
By treating each object as a separate decision unit with its own reward signal, OSPO decouples object generation from image-level noise. Per-object handles let the model learn which attributes matter for which objects, eliminating cross-object interference that plagues standard preference optimization.
CVPR'26ConsistCompose: Unified Multimodal Layout Control for Image Composition
Problem
Multi-instance image generation requires spatial control that most unified multimodal models cannot provide. Task-specific architectures (region-aware U-Nets) break generality; systems either do layout control or general understanding, rarely both without sacrifice.
Approach
ConsistCompose embeds spatial coordinates directly into text prompts as linguistic tokens, creating what authors call Linguistic-Embedded Layout-Grounded Generation (LELG). This allows a single transformer to handle layout constraints, identity preservation, and general understanding using only prompt-level conditioning and coordinate-aware classifier-free guidance, without architecture-specific branches.
Why it matters
Coordinates as language tokens give each object an explicit spatial anchor point in the prompt. This per-object localization moves spatial control from network architecture into the input space, enabling a unified model to compose scenes by placing objects at specified positions while preserving identity and semantic coherence.
CVPR'26PoseGaussian: 6D Pose Estimation for Unseen Objects via Sparse-View Object-Level 3D Gaussian Splatting
Problem
Accurate 6D pose estimation for unseen objects is difficult without CAD models and fails in sparse-view, low-texture scenarios where Structure-from-Motion breaks down. Existing methods require dense views and pre-training on specific object classes.
Approach
PoseGaussian reconstructs an object-level 3D Gaussian Splatting by injecting depth priors from RGB-D, then refines pose through three stages: geometry-aware ICP initialization, learning-guided alignment from coarse to fine, and differentiable rendering refinement. Each stage treats the object as a unified 3D entity with consistent geometry and appearance.
Why it matters
Object-level 3DGS representation provides a differentiable geometric handle—pose refinement becomes aligning one coherent 3D object, not solving for camera parameters in a scene. Per-object reconstruction isolates the object from background clutter, making pose recovery robust to sparse views and weak features.
CVPR'263D-Object Perception Transformer (3PT)
Problem
Zero-shot 3D object perception (detection, segmentation, pose) requires heavy ensembles of frozen foundation models with poor generalization to industrial objects and scenes outside training distribution. Methods demand depth or dense multi-view input.
Approach
3PT is an end-to-end transformer using object-centric specialization: a detection stage trained directly on 3D object models for joint 2D/3D reasoning, followed by an RGB-only pose refinement stage. The model learns object-specific representations without relying on frozen foundation model features, enabling single unified inference for detection, segmentation, and 6DoF pose.
Why it matters
Training directly on object models teaches the transformer to reason about individual objects as first-class entities with identity and geometry. Per-object conditioning in the transformer allows pose refinement to tune each object independently, unlocking industrial-grade accuracy without requiring depth or expensive ensemble composition.

5 · Objects to act on: object-centric manipulation and navigation

A robot that manipulates or navigates must reason about discrete things to grasp, push, and move. Object-centric representations—one entity per object—make this natural: the robot learns what an object looks like and what physical properties matter for the task, then acts on that object regardless of scene clutter. This breaks the coupling between perception and control: a diffusion policy can learn from human hand videos because the task is described as object motion, not robot kinematics; a language model can identify task-relevant objects in a point cloud and let collision penalties emerge at runtime without retraining; a planner can work from object relationships rather than pixel coordinates. Four papers show how object-level abstractions enable generalization, compositionality, and transfer.
ROBOTICS'25Language-Guided Object-Centric Diffusion Policy for Generalizable and Collision-Aware Manipulation
Problem
Manipulation policies trained on demonstrations do not adapt to new scene layouts and do not naturally avoid bumping into obstacles that were not in the training data.
Approach
The policy takes a natural-language instruction, uses a language model to identify the relevant objects from the scene's 3D point cloud, and trains a diffusion model on those objects' geometry only; during execution, collision penalties are added to the motion-generation process to steer away from obstacles without any retraining.
Why it matters
Focusing on task-relevant object geometry rather than the full scene makes the policy adapt to new layouts, while injecting collision costs at run time avoids obstacles the policy was never trained to handle.
ROBOTICS'25ZSORN: Language-Driven Object-Centric Zero-Shot Object Retrieval and Navigation
Problem
A robot that must find and navigate to objects described in plain language fails when those specific objects were not in its training data.
Approach
ZSORN matches a spoken or typed description to candidate objects in the scene using language-driven, object-level zero-shot learning—meaning it generalizes from what it has seen before rather than needing new training examples for each new object type.
Why it matters
Grounding language descriptions to object-level features rather than whole-scene features lets the system recognize new objects by what they look like and what words describe them, without retraining.
ROBOTICS'25SPOT: SE(3) Pose Trajectory Diffusion for Object-Centric Manipulation
Problem
Imitation learning policies are tied to a specific robot body, so demonstrations from one robot or from a person's hands cannot easily teach a different robot.
Approach
Tasks are described as how target objects move in 3D space (SE(3) pose trajectories) rather than as robot joint motions, and a diffusion policy then converts those object trajectories into actions for whatever robot is available—learning from as few as eight demonstrations, including videos of human hands with no robot at all.
Why it matters
Describing the task in terms of what the object does, not what the robot does, separates the goal from the body so any robot can follow the same instructions.
ROBOTICS'25Bootstrapping Object-Level Planning with Large Language Models
Problem
Getting a robot to plan a new manipulation task in a standard planning language (PDDL) is difficult because large language models often produce goals that are inconsistent or impossible to satisfy.
Approach
Instead of asking the language model to write the plan directly, the system asks it to describe what objects are involved and how they relate (using a representation called FOON); a separate tool then converts that description into valid planning goals that a standard planner can solve.
Why it matters
Using the language model only for what it is good at—describing object relationships from common sense—and leaving formal planning to a dedicated solver avoids the errors that arise when language models try to do both.

6 · Object-level maps: SLAM and mapping built from objects

A robot that names, tracks, and queries discrete objects builds richer scene understanding than point clouds or voxel grids alone. Object-centric SLAM grounds maps in things—an electrical connector, a chair, a landmark—that a robot can reason about, manipulate, and communicate. These four papers show the frontier: multi-robot data fusion via object messages instead of raw observations, force-informed assembly by reading object geometry through touch, language-grounded 3D object models that handle open vocabularies, and semantic SLAM that densely labels 3D scene geometry as named objects. The shift is from geometry-only to geometry-plus-semantics-plus-agency: maps become queryable scene graphs instead of passive sensor dumps.
ROBOTICS'25Distributed Invariant Kalman Filter for Object-Level Multi-Robot Pose SLAM
Problem
When multiple robots share sensor data to localize themselves and each other, they accumulate inconsistent position estimates because correlations between their error sources are unknown, and broadcasting raw observations consumes bandwidth.
Approach
The work adapts Kalman filtering to work on Lie groups (the proper mathematical space for rotations and positions) and uses covariance intersection to safely merge estimates without knowing error correlations. Robots exchange only high-level object-detection results rather than raw sensor data.
Why it matters
Covariance intersection guarantees consistency even when error dependencies are opaque, and object-level communication slashes bandwidth; multi-robot SLAM becomes tractable by treating shared observations as named objects each robot can independently verify.
ROBOTICS'25LE-Object: Language Embedded Object-Level Neural Radiance Fields for Open-Vocabulary Scene
Problem
Scene reconstruction systems often misalign object boundaries and only recognize objects from a fixed training vocabulary; open-world manipulation requires maps that understand arbitrary user descriptions.
Approach
Each object is modeled as a separate 3D Neural Radiance Field (NeRF) paired with embeddings understood by language models. The system reconstructs and identifies any object a user describes without retraining.
Why it matters
Language-embedded object-level NeRFs let a robot query the map by name or description; the map becomes a queryable semantic scene graph where objects are discrete, language-aware entities a robot can locate and reason about.
ROBOTICS'25OpenGS-SLAM: Open-Set Dense Semantic SLAM with 3D Gaussian Splatting for Object-Level Scene Understanding
Problem
Fixed-vocabulary SLAM systems miss objects outside their training set, trapping robots in closed-world assumptions; open-set mapping is essential for real-world robotics.
Approach
The system builds a 3D map using Gaussian Splatting and assigns each Gaussian cluster labels from an open-vocabulary vision model, then refines labels across views. Consistency checks remove misaligned labels.
Why it matters
Open-vocabulary labeling on explicit Gaussian geometry creates a map where any object can be named; the robot queries the scene graph by visual description or learned object class, and the map directly supports downstream manipulation.
ROBOTICS'25Geometry and Force-Informed Robotic Assembly with Small Relative Initial Deviations for Circular Electrical Connectors
Problem
Inserting a round connector into a socket is difficult when socket pose is unknown and the connector has internal features; tactile alone is usually insufficient without geometric priors.
Approach
The robot follows a search trajectory while monitoring force feedback. Each geometric feature of the connector produces a distinctive force signature that tells the robot its progress through the assembly sequence.
Why it matters
Force signatures become object-level tactile queries that let the robot navigate assembly without vision; the connector's geometry is encoded as a tactile map the robot reads by feel, enabling manipulation of objects defined by their geometric signatures.
