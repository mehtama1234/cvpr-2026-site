The problem, as a quantity

A single prompt (point, box, or text) is fundamentally ambiguous: a point on a shirt could mean the shirt fabric, the person wearing it, or the whole scene. The map from prompt to mask is one-to-many. Classical segmentation tries to average over possibilities or pick one arbitrarily, blurring incompatible interpretations together. Real segmentation needs to acknowledge that multiple correct masks exist at nested scales and confidence levels.

The core ideas — and why they work

Hypothesis ensemble over averaging

Instead of outputting a single blurry mask, predict K candidate masks with a confidence score (predicted IoU) for each. The best-scoring mask resolves the ambiguity by letting the model express uncertainty explicitly.
A point lives at multiple scales: local object boundary, instance, category, scene. A single averaged mask spreads prediction probability across all these nested hypotheses, producing a muddy boundary. K independent masks let each hypothesis maintain sharp edges, and the confidence score picks the most likely one. Training learns which scale a given (image, prompt) pair asks for—the embedding captures appearance, and the prompt interpreter learns to read it. With K=3 or K=4, the model almost never fails to include the right answer.

Billion-scale training on diverse masks

Training on billions of segmentation masks makes the image embedding general-purpose, so querying it with new prompts becomes cheap inference, not expensive retraining.
An image embedding f(image) captures rich visual structure—edges, textures, regions, hierarchies—in a learned representation. Once f is trained on billions of (image, mask) pairs at diverse scales, it learns to separate objects, surfaces, and scenes implicitly. A new prompt (point or box) is just a lookup into that embedding—the model's decoder asks 'given this appearance, what mask does this prompt specify?' The embedding is frozen; only the prompt interpreter runs per-query. Cost scales with prompt specificity, not image complexity.

Point is cheap, box is richer

A single point is maximally ambiguous, so K masks are necessary. A box partially resolves scale but still allows multiple interpretations; adding text further constrains the search. The prompt grammar trades annotation cost for mask quality.
Given only a point, the model must predict K hypotheses to express that multiple valid answers exist. Given a box, the point-hypothesis ensemble can be smaller—the box already narrows scale. Given 'person', the scale is nearly fixed and K=1 suffices. This is a spectrum: sparser prompts require richer hypotheses to compensate for ambiguity. The system is elegant because the same mask-prediction head works for all three prompt types; the prompt encoder just produces higher- or lower-entropy features.

Masks as a reusable label factory

Once trained, the model generates high-quality masks for any image and prompt without per-image annotation. These masks become training data for downstream tasks (object detection, instance segmentation, video tracking).
Billion-scale pretraining creates a frozen embedding that generalizes. Querying it with prompts generates masks for novel images at near-zero marginal cost. These masks can label the pixels ('this pixel belongs to a shoe') so downstream models learn to recognize shoes, people, etc. The embedding captures the appearance variations that make generalization hard; the prompt interpreter learns the geometry of selection. The model doesn't overfit to specific categories because masks are purely geometric—a shoe is just a region, not a shoe-shaped classifier.

The approaches, as variations on the math

Point-and-cut: interactively refine a mask by adding prompts (point inside the object, point outside). Point once, follow it cheaply: SAM2 tracks a mask through video frames by re-embedding frames and re-running the decoder—the prompt stays fixed. Cross-domain transfer: train on diverse masks (photos, medical images, synthetic 3D renders, drawings), so the embedding learns appearance-invariant features. Which pixels do I grasp: robotics prompt—given an RGB-D image and a grasp point, output the graspable pixels (a segmentation task disguised as robot control). Mask generation: run the prompt interpreter on a dense grid of points to cover the whole image; pick non-overlapping masks via NMS to build an instance segmentation.

2Point once, follow it, cheaply
Frame_t (prompt p) → T_t = image encoding (reusable). Video frames 1..N share embedding T_t across time. Best keyframe k selected by attention, then propagated via memory-augmented tracking → single inference pass per frame.
The billion-scale image embedding makes embeddings cheap to reuse across video frames. Instead of encoding every frame, select one keyframe with the highest informativeness (attention weight), encode it once, then propagate via learned tracking memory. This trades frame-by-frame recomputation for a single rich embedding repeated.
Robust Promptable Video Object Segmentation — Benchmark defines measurement of prompt robustness, establishing variance metric for mask quality across video frames.

Fast Reasoning Segmentation for Images and Videos — Structured intermediate scene representation separates perception from grounding, enabling efficient downstream reasoning.
3Where the pixels look nothing like photos
3D scan {slice_z} → 2D projections from K canonical views. Each view → SAM prompt p_k → mask M_k(x,y). Union/intersection over K views aggregates 3D geometry: vol_3D ∝ Σ_k proj_back(M_k).
Medical images (CT, MRI) and CAD scans have pixel values far from natural photo statistics, breaking the image embedding. The solution: render 2D orthogonal slices from multiple angles, apply SAM per 2D view (reusing the natural-image embedding), then lift back to 3D by aggregating masks across canonical viewpoints. Ambiguity is resolved by consensus over angles.
VoxTell: Free-Text Promptable Universal 3D Medical Image Segmentation — Vision-language model trained on 62000+ volumetric scans learns unified embedding space for anatomical regions and pathologies.
GeoSAM2: Unleashing the Power of SAM2 for 3D Part Segmentation — 3D segmentation reduced to 2D: render 3D point cloud from multiple canonical views, apply 2D SAM2 per view, aggregate votes.
ReSAM: Refine, Requery, and Reinforce: Self-Prompting Point-Supervised Segmentation — Iterative self-prompting loop: Refine output mask, Requery with that mask as new prompt, Reinforce via confidence threshold.
Discover, Segment, and Select: A Progressive Mechanism for Zero-shot Cross-Domain Segmentation — Three-stage pipeline progressively constrains search space: discover candidates, segment each, select highest-confidence output.
4A free label factory, and which mask
Mask M(x,y) → boundary edges E(x,y). Downstream task (depth, matting, detection) trains on (image, E) pairs. Quality Evaluator Q: M → score_quality, filters K candidates → argmax_k Q(M_k).
SAM outputs high-confidence masks for any image without per-image annotation. These masks become training data: extract object boundaries or use masks as weak supervision. When multiple mask hypotheses exist (K>1), train a learned quality evaluator to score each mask and select the best one per image, avoiding manual annotation while maintaining downstream task quality.
RoSAMDepth: Robust Self-supervised Depth Estimation Leveraging Segment Anything Model Masks — SAM masks as three training supervision signals: object boundary, instance separation, and occlusion edges.
Learning to Drive is a Free Gift: Large-Scale Label-Free Autonomy Pretraining from Off-the-Shelf Models — Ensemble of off-the-shelf models (SAM2, optical-flow, detection) labels raw video without manual annotation, stochastically selects highest-confidence predictions.

MatAnyone 2: Scaling Video Matting via a Learned Quality Evaluator — Matting Quality Evaluator scores predicted alpha per pixel, allowing beam search over candidates to select best per-pixel matting.
5Which pixels do I grasp
Mask M(x,y) → grasp quality heatmap G(x,y,θ). For each pixel, sample gripper angle θ and compute success probability via learned scorer. Argmax_(x,y,θ) G → grasp pose.
SAM cuts out objects precisely, giving the robot sharp boundaries. The grasp detection layer then learns which pixels and angles lead to stable grasps by scoring candidate gripper poses on the segmented object. The mask resolves identity ambiguity, leaving only the pose search, reducing hypothesis space from object-scale to grasp-geometry scale.
GraspSAM: When Segment Anything Model Meets Grasp Detection — SAM output mask transformed to grasp candidates via geometric heuristics: antipodal points mapped to gripper configuration space.
RoboNurse-VLA: Robotic Scrub Nurse System based on Vision-Language-Action Model — Vision-language-action fusion: SAM2 masks fused with Llama 2 language reasoning and robotic action primitives in unified embedding.
Generalizable and Actionable Part Detection and Manipulation with SAM-Guided Gripper Pose Estimation — SAM masks clean fragmented part proposals via morphological rectification, then gripper pose regressed from boundary pixels.
High-Quality Unknown Object Instance Segmentation via Quadruple Boundary Learning — Boundary-centric loss with four edge types (instance, semantic, soft, hard) replaces mask pixel loss, refining edges without naming objects.
6Cut out what has no name, and put it on the map
2D masks {M_v}_v from K viewpoints → 3D Gaussian splat centers + covariance. Open-vocabulary CLIP embedding per mask → semantic label. 3D map = {(center, Σ, CLIP_feat)}_i.
Open-vocabulary segmentation removes the need for a closed label set. Apply SAM + CLIP to each 2D view to get mask + semantic embedding, then lift to 3D by fusing splat geometry across views and attaching the CLIP feature to each Gaussian. The result is a navigable 3D map with semantic labels for regions the model has never seen before.
DA-Fusion: Deformable Attention-Based RGB-D Fusion Transformer for Unsupervised Depth Completion — Deformable attention kernel dynamically shifts spatial offsets per query, fusing color and depth streams without pre-alignment.
Instance Segmentation-Based Hazard Detection with Lunar South Pole Lighting and Terrain Shadows — Synthetic dataset recreates extreme 2.5-7.5 degree lunar illumination angles, training segmentation to detect shadow-occlusion hazards.
OVSG-SLAM: Open-Vocabulary Semantic Gaussian Splatting SLAM — Scene represented as 3D Gaussians (learnable means, covariances, opacities) with open-vocabulary language tags attached per Gaussian.
SAM-Guided Pseudo Label Enhancement for Multi-Modal 3D Semantic Segmentation — SAM 2D boundaries treated as geometric templates, refined to 3D via matching to point-cloud geometry and fusion of RGB-D features.
The through-line. Sparse prompts under-determine segmentation, so predict multiple candidate masks with confidence scores instead of a single blurry average. Billion-scale training on geometric masks makes the image embedding reusable—new prompts are cheap queries. The same model generalizes across domains, scales, and downstream tasks because it learns to select regions, not classify categories.
