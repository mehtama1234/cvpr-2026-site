How to read the corpus without getting lost

Four practical routes through the field, from a short overview to a week-long study path and a builder path.

homesynthesisfield map30 articles
Path 1

90-minute overview

Read the synthesis, then the field map, then the first ten foundational articles. This gives the primitive objects: pixels, boundaries, boxes, words, depth, views, time, diffusion, evidence, and relations.

Path 2

One-day deep read

Read all eight forces in the field map, then the 30 articles in ranked order. For each article, read only the representative paper groups and named examples before moving on.

Path 3

One-week study plan

Day 1: pixels, boundaries, detection, grounding. Day 2: depth, multi-view geometry, splatting, dynamic 3D. Day 3: video memory, tracking, flow, video generation. Day 4: diffusion, editing, restoration, synthetic data. Day 5: VLM evidence, relations, tokens, agents. Day 6: embodied action and driving. Day 7: adaptation, continual learning, efficiency, robustness, provenance.

Path 4

Builder path

Start with the field map, then use the project studio. Build one perception inspector, one 3D reconstruction view, one video tracker, one VLM evidence checker, one controlled editor, and one learning-trust dashboard.
