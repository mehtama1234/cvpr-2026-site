1 · You point, it cuts

The whole promise of promptable segmentation is point in, mask out: you tap somewhere in an image, and the model traces the exact outline of the thing you pointed at and lifts it away from everything else. The remarkable part is that it works on objects it was never taught to name — you are not choosing from a menu of known categories, you are just indicating a spot and getting back a shape. But a single click is deeply ambiguous: touch a person's chest and you might mean the shirt, the torso, or the whole person, and the model has no way to read your mind from one dot. The papers in this theme all make the interface smarter rather than just the model bigger. Some feed it better prompts, some let it learn from your corrections as you go, and some quietly refine a rough, messy prompt into a clean mask before you ever see it. The thread running through them is a feedback loop — the more you interact, the better the cut gets.
CVPR'26Live Interactive Training for Video Segmentation
Problem
When you correct a segmentation model like SAM2 on a video frame — say, clicking to fix where it lost track of an object — it uses your correction only for that one instant and then forgets it. So the same mistake keeps coming back frame after frame in hard cases like occlusions or camouflage, and you end up making the same fix over and over.
Approach
The idea, called Live Interactive Training, is to let the model actually learn from your corrections while you are still using it, not just apply them once. Each time you correct something, it trains a tiny add-on module — a small set of extra weights called a LoRA — on the fly from that single correction. Because the add-on is small, this takes only about half a second and adds almost no overhead. The model then carries what it learned forward, so it stops repeating that error on the following frames of the same video. The same trick works across several SAM2 variants and even extends to image classification.
Why it matters
This turns the one-click feedback loop into something cumulative: instead of fighting the same recurring mistake, your effort compounds, cutting total corrections by 18 to 34%. The interface learns you and this video as you work.

CVPR'26PromptMoE: A Segmentation Refinement Framework Leveraging Mixture of Experts for Improved Prompting
Problem
A promptable model is only as good as the prompt it gets, and a rough or noisy starting mask can send it badly astray — with fuzzy boundaries, the wrong object, or prompt points that fight each other. Existing tools that clean up these prompts follow fixed rules, so they crack the moment the images or the failure modes change.
Approach
PromptMoE fixes noisy prompts with a mixture of experts — a panel of ten specialists, each offering a different visual cue about where the real object is. A lightweight router decides which experts to trust for this particular image and how they should combine, instead of dumping every opinion together and drowning out the useful ones. A third piece then places the actual prompt points so they cover the object well while staying on high-confidence ground. The whole thing sits in front of the segmenter as a plug-in prompt-fixer, adapting to each image rather than applying one recipe to all.
Why it matters
Because a single click or a weak mask is inherently ambiguous, deciding which hints to believe per image is what turns a noisy guess into a clean cut — here worth +6.24 IoU over prior refiners across five benchmarks.

CVPR'26PR-MaGIC: Prompt Refinement Via Mask Decoder Gradient Flow For In-Context Segmentation
Problem
In in-context segmentation you show the system one example — this is the object I want — and it tries to find the same thing in a new image by auto-generating a prompt for SAM. But when the new image looks different from your example, that auto-prompt misses the target and the mask comes out wrong.
Approach
PR-MaGIC refines a weak prompt without any training, right at the moment you use it. Its trick is to run SAM's mask decoder and then let the error signal flow backward through it — the same gradient math used for training, but aimed at nudging the prompt instead of the model. It gently shifts the query representation so it lines up with what a good target should look like, closing the gap between your example and the new image. It changes no weights and adds no new parts, and it picks the most trustworthy result by checking which candidate mask best matches your original example. The authors even prove it converges.
Why it matters
It shows a rough, ambiguous prompt can be auto-corrected by borrowing the knowledge already baked into the decoder — a training-free feedback loop that plugs into any such pipeline and reliably lifts quality across six datasets.

CVPR'26Conversational Image Segmentation: Grounding Abstract Concepts with Scalable Supervision
Problem
Today's segmenters are great at object names and simple where-is-it queries but cannot handle intent — asking for something safe to sit on or a stable place to put a cup means reasoning about function, physics, and safety, not just recognizing a chair. Standard referring benchmarks skip these conversational, purpose-driven requests entirely.
Approach
This work defines Conversational Image Segmentation: prompting by what you mean rather than by clicking or naming. It covers five families of concepts — entities, layout, relations and events, affordances and functions, and physics and safety. Since no one has labeled data for this, the authors build an automated data engine where a vision-language model generates conversational request-and-mask pairs and then verifies them, producing 61,000 training examples with no human annotation, plus a human-checked benchmark. Their model fuses SAM2's image encoder with a Qwen vision-language model through small adapters, so a spoken-style intent turns into the right cut.
Why it matters
This pushes the prompt from a point to a sentence of intent, dissolving the one-click ambiguity by letting you simply say what you want — and it still stays competitive on the classic referring benchmarks.

2 · Point once, follow it, cheaply

SAM2's real superpower is that you point at an object once and it follows that same object through every frame of the video, remembering what it looks like as it moves. But real video is cruel to that memory: things get hidden behind other things, footage is grainy or blurry or shot in rain and fog, and over hundreds of frames the model slowly drifts off the object or collapses onto the wrong one. So one line of work hardens the tracking, giving each followed object a little memory-conditioned adapter that keeps it locked on under corruption, and teaching the model to reason first about which frame to trust before it commits to a mask. Separately, there is a plainer problem: SAM is a big, slow, billion-parameter model, which is painful on a phone, a robot, or an edge camera that has to run in real time. So another line quantizes it down to 4-bit arithmetic that fits tiny hardware, or distills a giant reasoning-segmentation model into a small fast one. Both lines keep the exact same point-once, get-a-mask promise while making it survive real video and actually fit on real devices.
CVPR'26Robust Promptable Video Object Segmentation
Problem
When you point at an object and ask SAM2 to follow it through a video, it works beautifully on clean footage but falls apart the moment the input gets messy: sensor noise, motion blur, dim light, rain, snow, or fog all make it degrade badly. That fragility is exactly the wrong trait for the places you most want it, like a self-driving car or a robot, where bad conditions are guaranteed rather than rare.
Approach
The authors first build a proper way to even measure this, a benchmark of 351 real-world clips plus a large set of synthetic clips where corruptions are added consistently across frames rather than one frame at a time. Their method, called Memory-object-conditioned Gated-rank Adaptation (MoGA), is a lightweight adapter that ties the clean-up process to each individual object the model is already remembering in its memory. Because the fix is conditioned on that per-object memory, a scene with several tracked objects gets each one handled on its own terms, and the correction stays steady from frame to frame instead of flickering. In effect it robustifies the object you are following, not just the raw pixels, so the same object stays locked on even as the picture quality falls apart. Across many corruption types, on both the synthetic and the real clips, this gives consistent gains and sets a first strong baseline for the problem.
Why it matters
This is what lets point-once tracking survive an entire real-world video shot in bad weather, which is the difference between a demo and something you could trust in a car or a robot.

CVPR'26Reinforcing Video Object Segmentation to Think before it Segments
Problem
Earlier video reasoning-segmentation systems squash everything they understand about a whole video into a single opaque token and then segment from it, which makes them brittle in long, occlusion-heavy clips and gives you no window into why they picked an object. They also tend to need large grab-bags of training data and offer no readable intermediate reasoning you can check.
Approach
This work, Veason-R1, reframes the task as a two-step decision: first find the single most informative keyframe in the video, then ground the object spatially on that frame, both written out as explicit chain-of-thought inside think and answer tags. It starts by fine-tuning an 8B vision-language model on chain-of-thought annotations, then sharpens it with reinforcement learning (GRPO) driven by four checkable rewards. Those rewards score whether the output follows the required format, whether the chosen keyframe really is the most salient one, whether the predicted boxes match the truth by overlap, and, crucially, whether the masks that SAM2 propagates forward from that keyframe through the rest of the video stay faithful to the ground truth. That last reward ties the model's own frame choice directly to how well the mask survives being carried across the whole clip. Because the signals are verifiable, it learns from a single dataset yet reaches state-of-the-art on ReVOS and ReasonVOS and generalizes zero-shot to MeViS.
Why it matters
Picking a good keyframe to start from, and being rewarded for masks that stay consistent all the way through, is what keeps SAM2 from drifting or collapsing over a long, occlusion-prone video.

CVPR'26CAR-SAM: Cross-Attention Reconstruction for Post-Training Quantization of the Segment Anything Model
Problem
SAM is over a billion parameters, so running it on a phone, camera, or embedded board strains both compute and memory. The usual trick of shrinking numbers to low-bit arithmetic breaks on SAM's mask decoder specifically: attention dissipates (it collapses to nothing under aggressive quantization) and the reconstruction oscillates because the decoder's cross-attention feeds back on itself in both directions.
Approach
CAR-SAM is a post-training quantizer built for exactly those two decoder quirks, meaning it compresses an already-trained model without retraining it from scratch. Its first piece, MatMul-Aware Compensation, moves the error introduced when you quantize an activation backward into the preceding layer's weights, which matters here because the decoder mixes very different kinds of inputs (image features versus the prompt tokens you clicked). Its second piece, Joint Cross-Attention Reconstruction, tunes the two coupled attention branches together rather than one at a time, damping the back-and-forth oscillation that otherwise wrecks low-bit accuracy. Together they let SAM run at 4-bit while keeping the collapse and the wobble under control, and the same framework covers SAM2 too. The result beats prior quantization methods by 14.6 percent mAP on SAM-B and 6.6 percent on SAM-L.
Why it matters
Getting SAM down to 4-bit without wrecking its masks is what makes it small and cheap enough to actually run on an edge device instead of a datacenter GPU.

CVPR'26Fast Reasoning Segmentation for Images and Videos
Problem
Reasoning segmentation, where you describe an object in plain language and the model figures out which region you mean, currently rides on multimodal LLMs with billions of parameters that no edge device can hold. Worse, naively distilling such a model into a small one loses the very thing that makes it work: its ability to reason in multiple steps.
Approach
FastReasonSeg's trick is to insert a digital twin, a structured intermediate description of the scene that separates perceiving the scene from reasoning about it. By handing the student that clean abstraction, the multi-step reasoning actually transfers instead of evaporating during distillation. Training goes in two stages: first supervised fine-tuning on reasoning chains written by the large teacher, then reinforcement fine-tuning with a reward that jointly grades both the final segmentation accuracy and the quality of the reasoning that led there. The whole thing works for both single images and video with one unified model. The payoff is a 0.6B-parameter model that beats models 20 times its size while running at 7.79 frames per second on just 2.1GB of memory.
Why it matters
Squeezing billion-parameter reasoning segmentation into a real-time 0.6B model on 2.1GB is what lets an embodied agent or robot reason about what to segment on the hardware it actually carries.

3 · Where the pixels look nothing like photos

Segment Anything learned to cut objects out of images by studying millions of everyday web photos, so it quietly assumes the world looks like a snapshot from a phone. Feed it an X-ray, a slab of sonar, a satellite tile, an electron-microscope slice, or a camouflaged animal and the model wobbles, because those pixels look nothing like the data it grew up on. This turns out to be the single largest cluster of follow-up work built on SAM. The common recipe is to graft SAM or its video sequel SAM2 onto a strange new domain by bolting on domain-specific prompts, small trainable adapters, or a memory that carries context across views. The payoff is that the model keeps its magic point-in, mask-out skill even in fields where expert labeling is painfully scarce and expensive. The dream is to segment a tumor, a rooftop, or a hidden insect with nothing more than a single click or a short line of text.
CVPR'26VoxTell: Free-Text Promptable Universal 3D Medical Image Segmentation
Problem
Medical scans are 3D volumes, and doctors describe what they want in messy, specialized language that no fixed menu of labels can capture. Earlier text-guided tools were locked to a predefined list of anatomy, so they broke the moment a clinician named an unusual structure or phrased it differently. What was missing was a system that could take any free-form clinical sentence and find the matching region inside a CT, MRI, or PET volume.
Approach
VoxTell is a 3D vision-language model trained on more than 62,000 CT, MRI, and PET volumes covering over a thousand anatomical and pathological classes. Instead of matching text to pictures only at the very end, it fuses language and image features repeatedly across many layers of the decoder, aligning the words to the scan at several scales at once. A pretrained text encoder lets it absorb everything from a single word to a full clinical sentence, shrugging off synonyms and even spelling mistakes. Because the language side is genuinely understood rather than looked up in a table, the model can point to structures it was never explicitly trained on. In practice it segments the same organ or lesion whether you type one word or a paragraph of doctor-speak.
Why it matters
Medical pixels are the classic case where photos-trained models fail, and expert voxel-by-voxel labeling is among the most expensive annotation in all of imaging. By letting a free-text prompt drive zero-shot 3D segmentation across modalities, VoxTell carries the point-in, mask-out idea into the clinic while sidestepping that labeling bottleneck.

CVPR'26GeoSAM2: Unleashing the Power of SAM2 for 3D Part Segmentation
Problem
Cutting a 3D object into its meaningful parts is awkward: methods that reason about scale are slow and unintuitive per object, while fast feedforward methods give you no fine control over which part you actually want. Neither lets a person simply point at the part they mean the way SAM lets you click on a photo. The gap is a way to steer 3D part segmentation with the same easy, precise prompts.
Approach
GeoSAM2 reframes the whole 3D problem as ordinary 2D mask prediction seen from several canonical camera angles. It renders normal maps and point maps of the object from those viewpoints and feeds them to a SAM2 backbone, which is nudged toward geometry using small LoRA adapters and a residual fusion of geometric features while keeping SAM2's original photo-trained instincts intact. A user then drops a simple click or box on one chosen view, exactly as they would on a snapshot. Those per-view masks are back-projected onto the 3D shape, and a full-view memory bank plus light smoothing keeps the answer consistent across every angle. The result is scalpel-precise control over which part gets segmented, with very little added compute.
Why it matters
Rendered 3D geometry looks nothing like the web photos SAM2 was trained on, so the adapters and memory bridge that gap while inheriting its interactive skill. This turns tedious 3D part labeling into a couple of 2D clicks, slashing the expert effort normally needed to annotate object parts.

CVPR'26ReSAM: Refine, Requery, and Reinforce: Self-Prompting Point-Supervised Segmentation for Remote Sensing Images
Problem
Segmenting high-resolution satellite and aerial imagery normally demands dense, pixel-perfect labels that are slow and costly to draw by hand. SAM does poorly on this overhead imagery because it is a foreign domain, and it has no built-in way to learn from just a single labeled point. The challenge is to close that domain gap using almost no supervision.
Approach
ReSAM runs a self-prompting loop it calls Refine, Requery, Reinforce, or R-cubed. Starting from a lone point, it produces a rough pseudo-mask, then automatically constructs its own box prompt around that mask and re-queries SAM to get a cleaner result, tightening the mask each pass. To stop small errors from compounding as the loop repeats, a Soft Semantic Alignment component keeps rolling queues of features and applies gentle cosine-similarity losses to hold the meaning steady. Crucially, this replaces heavy memory-hungry prototype methods, so the whole thing stays lightweight. The model effectively teaches itself better prompts from a single click, no dense masks required.
Why it matters
It carries SAM's point-in, mask-out ability into the satellite domain where its photo training breaks down, driven by nothing but one-point labels. That closes the gap to fully supervised models to within 1.3 to 8.5 percent while eliminating the expensive dense annotation those models need.

CVPR'26Discover, Segment, and Select: A Progressive Mechanism for Zero-shot Camouflaged Object Segmentation
Problem
Camouflaged animals are built to blend into their backgrounds, so their pixels barely stand out from the scene. Prior zero-shot pipelines leaned entirely on a multimodal language model to first spot the creature, which led to sloppy localization, false alarms, and missed animals, especially when several were hidden in one frame. The weak link was trusting the language model alone to find the object.
Approach
DSS splits the job into three progressive stages so no single component has to do everything. First, Feature-coherent Object Discovery mines the image's own visual features to propose many candidate regions, using a Part Composition module and similarity-based box generation to stay robust when multiple instances are present. Second, SAM refines each proposal into a crisp candidate mask, doing what it does best. Third, Semantic-driven Mask Selection brings the multimodal language model back in, but only to judge the finished candidates and pick the best one. By demoting the language model from finder to final selector, the pipeline kills off the false positives and missed detections that plagued earlier MLLM-to-SAM systems, all without any training.
Why it matters
Camouflage is precisely where photo-trained models struggle because the object hides in its surroundings, so leaning on SAM for the actual cut and reserving reasoning for selection fixes the errors. It reaches state-of-the-art zero-shot results with no training or labels at all, sidestepping annotation entirely.

4 · A free label factory, and which mask

Here SAM is not the star but the free labor. Because it produces clean object masks for almost anything, other tasks stop paying humans to draw boundaries and instead lean on SAM's masks as free supervision — using them to keep depth predictions sharp at object edges, to isolate individual objects inside a 3D reconstruction, and to auto-generate training data for a self-driving car, all with no hand annotation. But a mask is only useful if you can trust it, and two things get in the way. First, a single click is ambiguous — do you mean the wheel or the whole car? — and masks are often coarse and ragged right at the boundary where fine detail matters most. So a second line of work controls which mask you get, dialing granularity smoothly from part to whole object, and judges how clean a mask is without any ground truth to check against. Together these two ideas make SAM's masks trustworthy enough to build the next system on top of.
CVPR'26RoSAMDepth: Robust Self-supervised Depth Estimation Leveraging Segment Anything Model
Problem
Teaching a camera to guess distance without a depth sensor works by checking whether consecutive frames line up, but that check falls apart at night, in rain, and in fog. When it breaks, the usual fixes treat every confusing pixel the same, so the depth map goes blurry and, worse, a single car ends up with different depths across its own body. Ordinary semantic segmentation could add object cues but it merges nearby instances, is stuck with a fixed list of classes, and does not transfer to new scenes.
Approach
RoSAMDepth borrows SAM's masks purely as a source of object boundaries and feeds them into training in three ways. It pulls pixels inside the same SAM mask together in the feature space and pushes different masks apart, so the network learns that a mask is one coherent object. It then replaces the raw pixel-by-pixel depth check with a per-region rule: depth inside each SAM mask should follow one smooth distribution, outlier pixels that disagree are thrown out, and the smoothness is only enforced within a mask — so boundaries between objects stay crisp instead of being smeared over. Finally it scores how reliable each region's depth cues are and down-weights the shaky ones, which matters most under bad weather. Crucially the SAM masks are computed once, offline, and are never needed at test time, so this is free supervision that leaves no runtime cost.
Why it matters
This is SAM as free supervision in its purest form: clean object masks, generated with no human labeling, become the scaffold that keeps depth sharp and consistent per object exactly where photometric self-supervision would otherwise fail.

CVPR'26Learning to Drive is a Free Gift: Large-Scale Label-Free Autonomy Pretraining from Unposed In-The-Wild Videos
Problem
The internet is full of dashcam and driving videos, but they come with nothing attached — no camera poses, no semantic labels, no LiDAR — even though they are packed with the exact geometry and motion cues a car needs to react safely. The open question is how to turn that raw, unlabeled footage into useful driving knowledge without paying anyone to annotate it.
Approach
The method, called LFG, treats several off-the-shelf models as free teachers that label the raw video automatically, with SAM2 supplying the object and instance masks alongside a segmentation model for semantics and a point tracker for motion. From those auto-generated signals it builds a single pseudo-4D target — geometry, semantics, and motion together — and trains a lightweight autoregressive transformer on top of a pretrained encoder to predict point maps, poses, segmentation, and motion for the current and future frames. No human ever touches these videos; the teachers manufacture all the supervision. The pretrained model is then fine-tuned for planning, and it drives well from a single front camera. It reaches state-of-the-art planning on the NAVSIM benchmark, beating multi-camera and LiDAR baselines and staying competitive with only 10% of the labeled data.
Why it matters
This is the free-label factory scaled up to an entire self-driving stack: SAM2's masks (plus its teacher peers) convert unlimited unlabeled YouTube driving footage into free training data, so autonomy can be pretrained with essentially no human annotation.

CVPR'26S2AM3D: Scale-controllable Part Segmentation of 3D Point Clouds
Problem
Cutting a 3D object into its meaningful parts is hard because 3D training data is scarce, and borrowing knowledge from 2D images leaves seams — the same part gets labeled differently from different viewpoints. Pure 3D methods do not generalize, while 2D-driven ones stumble on occlusions and give inconsistent cuts across views. And there is a deeper ambiguity: the right number of parts depends on what you mean, since one object can be split coarsely or very finely.
Approach
S2AM3D first fixes the seam problem by aggregating features from many 2D views into one 3D representation and training it with a native-3D consistency objective, so a part looks the same no matter which angle you came from. Its centerpiece is a scale-aware prompt decoder: instead of a fixed granularity, you feed in a continuous scale signal that slides the segmentation smoothly from fine parts up to whole components, adjustable in real time. A scale modulator plus cross-attention lets that one dial control exactly how coarse or fine the cut is. To make this trainable at all, the authors built a pipeline that auto-collects over 100,000 labeled part instances. It matches the strong P3-SAM baseline with far less training data and clearly beats SAMPart3D and PartField.
Why it matters
This directly answers the one-click-many-masks problem in 3D: rather than guessing whether you meant the wheel or the whole car, a single continuous dial lets you choose the granularity you want on the fly.

CVPR'26MatAnyone 2: Scaling Video Matting via a Learned Quality Evaluator
Problem
Video matting — cutting a subject out of video with soft, hair-fine edges — is starved for realistic training data because labeling alpha mattes by hand across every frame is prohibitively expensive. Reusing segmentation masks gives stable, correct shapes but they are coarse at the boundary, so the results look like cutouts with missing fine detail. The core difficulty is knowing whether an automatically produced matte is actually good, both in its overall shape and along its delicate edges, when there is no ground truth to compare against.
Approach
MatAnyone 2 trains a Matting Quality Evaluator (MQE) that scores a predicted matte pixel by pixel — judging both semantic correctness and boundary detail — without ever seeing a ground-truth matte. This one judge does double duty: during training it turns its scores into penalty maps that push the model to fix low-quality regions, and offline it acts as a gatekeeper that curates raw footage into clean training data. A dual-branch pipeline pairs a video model (for stable shape) with an image model (for crisp edges), and the MQE arbitrates which output to trust. Fueled by this, the authors auto-build VMReal, a real-world dataset of 28K clips and 2.4M frames — roughly 35× larger than the previous one. A reference-frame strategy pulls in long-range frames to handle appearance changes over long videos, and the model reaches state-of-the-art matting, e.g. 4.73 MAD on VideoMatte versus 5.15 for its predecessor.

5 · Which pixels do I grasp

To pick something up, a robot first has to know which pixels are the thing — and homes, warehouses, and operating rooms are full of objects it was never trained on. This is where SAM's promptable cutouts become the front end of grasping: you prompt with a point, a box, or a spoken or typed name, SAM isolates the target object or a specific part like a handle or a button, and the grasp planner then computes where to close the gripper on exactly those pixels. The mask turns grasp something into grasp this. In vision, a mask is scored by IoU — how well it overlaps the ground-truth outline — but here the scoring is physical: a good mask is a successful grasp and a bad one is a dropped object. Because SAM segments anything without knowing the object's category, the robot can be pointed at a brand-new tool or an unfamiliar part and still get a clean handle to grab. That is why this is the strongest, cleanest robotics use of Segment Anything: the cutout is not the answer, it is the thing the gripper closes on.
ROBOTICS'25GraspSAM: When Segment Anything Model Meets Grasp Detection
Problem
Systems that decide where a gripper should close usually only work well on the object categories they were trained on, and they give you little say in which object to grab. The bottleneck is data: there simply is not enough labeled grasp training to cover every object a robot might meet.
Approach
GraspSAM takes SAM, which already knows how to cut out almost anything from a picture, and teaches it to output a grasp instead of just a mask. It leaves SAM's big pretrained backbone mostly frozen and bolts on lightweight adapters, a few learnable token embeddings, and a modified decoder, so only a small part needs training. Because it inherits SAM's promptability, you can point at a target with a click, draw a box around it, or name it in language, and the model returns a grasp on that specific thing. It works category-agnostically — it does not need to have seen the object's type before — and it reached state-of-the-art results on the Jacquard, Grasp-Anything, and Grasp-Anything++ benchmarks. The prompt selects the object and the isolated pixels tell the gripper exactly where to close.
Why it matters
This is the mask-as-handle idea in its purest form: the same cutout that a vision model would call the answer is here fed straight to the gripper. Prompt SAM, get the target's pixels, close on them — a clean mask is a clean grasp, a sloppy one is a miss.

Problem

ROBOTICS'25High-Quality Unknown Object Instance Segmentation via Quadruple Boundary Error Refinement
Problem
In cluttered, unstructured scenes a robot must segment objects it has never seen, and the segmentations it gets are messy right at the edges — sometimes splitting one object in two, sometimes merging two into one. Those sloppy boundaries are exactly what causes downstream grasps to fail.
Approach
QuBER attacks the boundaries directly. Starting from an initial segmentation, it estimates four kinds of boundary error pixel by pixel — where the edge was correctly kept, correctly left out, wrongly added, and wrongly missed — giving a detailed map of what is wrong along each object's outline. It then applies an error-guided fusion mechanism that uses that map to repair both fine-grained pixel errors and larger instance-level mistakes, snapping the boundaries back to the true object edges. It is agnostic to the segmentation backbone, so it plugs on top of existing state-of-the-art methods and consistently improves them. In real-robot tests, the sharpened boundaries translated into higher grasp success in cluttered scenes.
Why it matters
This is the reminder that in robotics the edge of the mask is where the gripper lands — a boundary that is off by a few pixels puts the fingers on the wrong spot and drops the object. Cleaning the outline is not cosmetic; a sharper mask is directly a more reliable grasp.

6 · Cut out what has no name, and put it on the map

The world is full of things a robot was never trained to name: the tangle of parts in a picking bin, a rock sitting in an odd shadow, an obstacle that belongs to no category anyone labeled. A robot cannot safely ignore what it cannot label, because the thing it has no word for is exactly the thing that trips it. A promptable, class-agnostic segmenter answers a different question than what is this — it answers where does each object stop and start, cutting out every object in view including ones far outside the training set, so the robot can pick a single item out of clutter or steer around a hazard it has no name for; here a clean mask literally prevents a failed grasp or a missed obstacle. But beyond a single grab, a robot needs more than a one-off answer: it needs a map it can reason about later, and it needs labels it did not have to hand-draw. So it lifts those cutouts off the image and into a 3D map or scene graph the planner can query by name, or it treats the free masks as automatic labels to bootstrap other perception models that run when the segmenter is gone. Either way the mask stops being a fleeting reply on one frame and becomes durable world knowledge — geometry the planner can trust, names it can look up, training signal it never had to pay a human to draw.
ROBOTICS'25DA-Fusion: Deformable Attention-Based RGB-D Fusion Transformer for Unseen Object Instance Segmentation
Problem
A robot picking parts out of a cluttered bin faces objects it was never trained on, jammed together at every angle. Color alone over-segments — it splits one patterned object into many pieces because it mistakes surface texture for object edges. Depth alone under-segments — it fuses touching objects into one blob because their shapes flow together. Neither cue on its own tells the gripper where one object truly ends and the next begins.
Approach
DA-Fusion runs the color image and the depth image as two parallel streams and fuses them with a deformable attention Transformer. Ordinary attention compares every spot to every other spot on a rigid grid; deformable attention instead lets each location reach out to a few learned, shifted sample points, so a color feature can pull in exactly the depth evidence that lines up with it despite small misalignments between the two sensors. The network learns when to trust color (for a clean boundary between same-shaped objects) and when to trust depth (for a texture-rich surface that is really one object), weighting the two adaptively per location. The output is a class-agnostic instance mask for every object in the bin, including ones never seen in training. To measure this the authors also built OCBD, a top-down bin-picking benchmark of exactly this cluttered, unseen-object situation.
Why it matters
The robot never has to name the part it is grasping — it only has to know precisely where the part is, so a good mask is the difference between a clean pick and a fumbled one. Fusing color and depth means the unlabeled object in the bin is still cut out cleanly instead of being ignored because it had no known class.

ROBOTICS'25OVSG-SLAM: Open-Vocabulary Semantic Gaussian Splatting SLAM
Problem
As a robot moves through a room, SLAM builds a live map of where things are, and semantic SLAM tries to attach meaning to that map — but conventional systems only know a fixed, predefined list of categories. Anything outside that closed set becomes an unlabeled void in the map. That is fatal for open-world use, where the planner may be asked about an object the map was never told existed.
Approach
OVSG-SLAM builds its map as a cloud of 3D Gaussians — soft, splattable blobs that together reconstruct the scene — and hangs open-vocabulary meaning on them. It runs the Segment Anything Model to cut out objects in each 2D camera frame class-agnostically, then attaches vision-language feature embeddings to those cutouts so each region carries a searchable meaning rather than a fixed label. Those 2D masks and embeddings are fused into the 3D Gaussian map as the robot tracks its own motion, so meaning accumulates in 3D instead of living on one frame. To keep embeddings from blurring together across objects and to hold down compute, the authors add a differentiable identity-aware encoding and an identity loss that sharpens which Gaussians belong to which object. The result maps, tracks, and segments in 3D on Replica and ScanNet without ever committing to a closed category list.
Why it matters
The mask stops being a one-off answer on a single image and becomes durable 3D world knowledge the planner can query by open-ended name later. Because meaning is open-vocabulary, the robot can ask about an object no one pre-listed — the unlabeled thing still lands on the map instead of vanishing from it.

ROBOTICS'25SAM-Guided Pseudo Label Enhancement for Multi-Modal 3D Semantic Segmentation
Problem
To make a 3D segmentation model work in a new environment without fresh human labels, robots use self-training: the model labels the new data itself and learns from its own confident guesses. But strict quality pruning throws out most of those guesses, leaving pseudo-labels so sparse that the model barely improves. There is real signal being wasted for lack of a way to spread it.
Approach
This work uses the Segment Anything Model as a free source of clean object boundaries in the 2D image, which it treats as a template to be filled with meaning. Within each SAM mask it takes whatever sparse pseudo-labels survived pruning and runs majority voting, assigning the whole mask the class its confident points agree on. Then Geometry-Aware Progressive Propagation (GAPP) pushes that class outward to all the 3D points falling inside the mask — densifying a handful of labeled points into a fully labeled region. Crucially GAPP handles 2D-to-3D misalignment, so points that project imperfectly between the camera image and the 3D cloud are not mislabeled during the spread. A few trustworthy labels per object become many, giving self-training far more to learn from.
Why it matters
SAM's masks become automatic labels the robot never had to hand-draw, bootstrapping a 3D perception model that has to run on its own once SAM is gone. The mask turns a fleeting cutout into durable training signal, so knowledge earned on one domain carries into the next.
