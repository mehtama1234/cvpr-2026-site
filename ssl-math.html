Self-supervised Learning — why it works, mathematically

Representations emerge when data grades itself—catch the mathematical trick that prevents collapse when the task is 'any constant vector passes the test'.

The problem, as a quantity

Supervised learning binds a label to every image: 'cat' or 'car'. SSL inverts the burden: the data poses its own question, grading its own answer. Take one image, corrupt it twice (crop, color-shift, rotate)—ask the encoder: do these two views encode the same content? If so, push their embeddings together; push other images away. Simple. But here is the trap: the trivial minimizer is to output the same vector for every input. Send f(x) = c (a constant, dimension 1) for all x? Every pair pulls toward the same target, every comparison looks identical, and a softmax loss over negatives becomes L = log(N)—flat, done. All views win equally when none are distinguished. The core mathematical tension: enforce two views of the same image to align (invariance) while forcing all embeddings to spread (dimensionality, entropy). The loss itself, if left unguarded, has a zero-measure fixed point at collapse. The entire theme is how to algebraically block that trap.

The core ideas — and why they work

Contrastive learning (InfoNCE)

L_InfoNCE = −log[ exp(s(f(x_i), f(x_i'))/τ) / ( exp(s(f(x_i), f(x_i'))/τ) + Σ_k exp(s(f(x_i), f(x_k))/τ) ) ]

Take one image x, augment it twice: x_i (the anchor) and x_i' (positive). Encode both: f(x_i), f(x_i'). In embedding space, ask: which of N vectors is the true partner? The loss treats this as a classification: the positive is the 'correct' class, N-1 negatives are distractors. A softmax normalizes: exp(sim⁺/τ) / (exp(sim⁺/τ) + Σ neg terms). Why this stops collapse: the denominator must sum over all N options. If f(x) = constant for all x, all N similarities are identical, numerator = denominator, and the loss becomes log(N)—a high plateau, not a minimum. To lower the loss, the encoder must make the positive similarity higher than the negatives, which demands variance: embeddings must spread to carve out a hierarchy. Temperature τ trades off: small τ sharpens the softmax (negatives must be far), large τ smooths it (negatives are nearly indistinguishable). Same primitive elsewhere: this is the negative partition function from energy-based models and the softmax bottleneck that appears in attention and MoE routing—any time you ask 'pick one of N', the denominator forces coverage.

Non-contrastive: stop-gradient + variance (BYOL, VICReg, DINO)

L = |f(x_i) − sg[f(x_i')]|² + λ_var(−Var_batch[z]) + λ_cov C_batch

Contrastive methods need large batches (N → thousands) to work: more negatives → stronger partition-function repulsion. BYOL removes negatives entirely. Instead, encode the positive view normally, encode the other view with a stop-gradient (frozen, no backprop). Match them with MSE: L = (f(x_i) − sg[f(x_i')])². Why doesn't this collapse immediately? Because one side is frozen. If f(x_i) shrinks to a tiny constant, gradients flow backward only through the encoder of x_i and its predictor—the frozen side does not learn. The predictor head quickly fits the constant target, equilibrium is reached instantly, learning halts. The model is stuck. To escape, BYOL adds a second barrier: maximize the variance of embeddings across the batch. VICReg makes this explicit: L_var = −Var[z_i] (negative variance, pulling embeddings toward their target spread). It also decorrelates: reshape the batch embeddings into a covariance matrix C, regularize it toward identity (make components independent). DINO uses centering and momentum instead. Core principle: without the softmax denominator forcing coverage, you must regulate entropy and dimensionality by hand. Variance and decorrelation replace the negative partition function. The enemy it defeats: this is the same collapse trap that appears everywhere: MoE routers collapsing to one expert, VQ codebooks dying (all vectors used becomes one), RL reward-hacking (collapse to any constant reward), and test-time adaptation mode-seeking—wherever an objective can be minimized by uniformity. The solution is always the same family: add an anti-collapse regulator, not the objective itself.

Masked reconstruction (MAE, masked language models)

L_recon = |x_hidden − decoder(encoder(x_visible))|², masking ratio m ∈ (0.5, 0.9)

Hide a large fraction of the input (75% of image patches, or 80% of tokens). The encoder sees only the visible parts; the decoder reconstructs what is missing, using only the compressed embedding of the visible parts. The asymmetry is critical: the encoder cannot afford to drop information—if it does, the decoder has nothing to work with. This creates an information bottleneck by design. Why it avoids collapse: if encoder(visible) = constant regardless of content, the decoder receives zero signal about which patches are hidden and which are visible. Reconstruction loss skyrockets for any masking pattern. The task intrinsically rewards dense, high-dimensional latents. Pixel-level or token-level reconstruction naturally discourages dimensionality collapse—more bits in the bottleneck → more information available → lower loss. Unlike contrastive learning (which asks 'same content?'), masked modeling asks 'what was missing?'—a task only content-aware representations can solve. The masking ratio m controls the difficulty: high m (80%, 90%) forces the encoder to extract maximally useful, fine-grained structure.

Joint-embedding predictive architecture (JEPA)

L = |predictor(proj_1(f(x_i))) − sg[proj_2(f(x_i'))]|² + λ_var(−Var[z]) + λ_cov||C − I||

JEPA is the modern synthesis: predict one augmented view in the embedding space of another, both processed through encoders. Use a frozen target (like BYOL—stop-gradient on one branch) to block the instant-fit collapse. But also add explicit variance and decorrelation regularization (like VICReg), so the predictor cannot output small-norm or correlated vectors. The architecture has three lines of defense: (1) stop-gradient prevents the trivial predictor solution (fit a constant, freeze, done), (2) variance and decorrelation losses block the predictor from outputting uniform or low-entropy vectors, and (3) the two encoder branches learn symmetrically. The two projectors proj_1, proj_2 map the encodings to a learned embedding space; they can have different architectures, which breaks symmetry and avoids collapse in a different direction—neither branch is privileged. Why this is minimal-variance anti-collapse: you have redundant safeguards (stop-gradient and explicit regulation), so even if one regulatory mechanism loosens, the others catch the collapse. The predictor still runs in latent space (not pixel space), so the gradient is not diluted by reconstruction's high-dimensional noise. Same primitive elsewhere: this is the same multi-level defensive principle that appears in energy models (score function + Gaussian + boundary conditions to prevent collapse to delta) and variational inference (ELBO + entropy regularization + KL divergence to prevent mode-seeking).

The approaches, as variations on the math

Contrastive alone: Push one augmented view close, push others far via a large negative batch. Scale to thousands of negatives per iteration; temperature tuning is essential. Works well when batch diversity is high—each image has distinct negatives. Cost: GPU memory, synchronization across distributed training.

Non-contrastive (BYOL recipe): Remove negatives, add stop-gradient. Simpler to code and deploy; does not require synchronized batches across GPUs. Trade-off: must explicitly regulate variance; weaker without large batch sizes. Modern simplification: remove the second predictor head, just match encodings directly with variance loss.

Masked prediction + fine-tuning: Pre-train by predicting hidden patches or tokens (MAE, BEiT). Representations learn dense, pixel/token-level detail because the decoder must reconstruct. Fine-tune downstream: replace decoder with task head, freeze encoder or do lightweight tuning. Advantage: pre-trained encoder already encodes structure.

Cross-modal (CLIP-style): Images and captions are two 'views' of the same concept. Contrastive loss aligns image and text embeddings. Generalization: the model learns that visual features map to semantic concepts, enabling zero-shot prediction on new classes (find image nearest in semantic space to new text query).

Robot learning from video: A robot's video stream is unlimited SSL signal. Hide the next frame, predict it (temporal prediction). Or use stereo cameras: left and right are two views of the same 3D scene. Model learns what is content (world, agent pose) vs. noise (lighting, camera noise). Combine with world models to learn world dynamics.

1Predict the hidden part
x_hat = decoder(encoder(x_visible)); minimize ||x_hidden - x_hat||² — unmasked regions encode enough to reconstruct masked regions without seeing them
Masked prediction works because images are redundant: neighboring patches share structure. The encoder must compress all scene information into visible patches, then the decoder leverages spatial coherence to predict what's missing. Papers (RVM, MuM, SARMAE, NeighborMAE) extend this to video frames, 3D views, radar, and satellite time-series by changing WHAT is visible (temporal, multi-angle, cross-modal) but keeping the core principle: unobserved content lives in the observed parts.
Recurrent Video Masked Autoencoders — Autoregressive masking over time: each frame's decoder uses only prior frames as context, enforcing temporal causality via sequential prediction.
MuM: Multi-View Masked Image Modeling for 3D Vision — Multi-view reconstruction loss: masked patches in each view are decoded using the encoder's joint embedding across all views, so geometry constrains the shared space.
SARMAE: Masked Autoencoder for SAR Representation Learning — Cross-modal alignment in reconstruction: SAR radar patterns are decoded using the same latent as optical photos, so the mask predicts through sensor modality shift.
NeighborMAE: Exploiting Spatial Dependencies between Neighboring Earth — Spatial coherence loss: adjacent satellite tiles share a contrastive anchor in latent space, making mask reconstruction rely on neighbor geometry as implicit label.
2Match two views
z₁ = encoder(view₁); z₂ = encoder(view₂); maximize similarity(z₁, z₂) via teacher-student distillation with EMA updates to target encoder
Two views of the same scene contain the same semantic signal but different pixels. A teacher network extracts stable semantics from one view; a student catches up via gradient descent on the other. EMA-updating the teacher prevents collapse by ensuring the target drifts slowly, so the student always chases a moving goal. Papers (PointINS, TimeBridge, SPECTRE) apply this to point clouds, video frames, and volumetric scans—the lever stays: transform different modalities/times into the same learned space.
Towards Foundation Models for 3D Scene Understanding: Instance-Aware S — Teacher-student on point sets: two branches with stop-gradient on teacher encode and supervise the student via instance-level similarity in 3D space.
TimeBridge: Self-Supervised Video Representation Learning via Start-En — Temporal endpoints as views: start and end frames are masked views of the same video, supervised via iBOT masked-image distillation applied to motion sequences.
Scaling Self-Supervised and Cross-Modal Pretraining for Volumetric CT — Local-global fusion: high-res and whole-scan transforms share latent space via contrastive loss at two scales, making the embedding jointly sensitive to detail and context.
3Predict in latent space, and fight collapse
z_t = encoder(x_t); z_pred = predictor(z_t); loss = ||z_pred - sg(z_target)||² + λ·covariance_regularization(z_pred) — stop-gradient + variance penalty
Latent prediction is cheaper than pixel reconstruction but invites collapse: the network can shrink z_pred to a point and achieve zero loss. Variance/covariance regularization forces z_pred to spread across the feature space; stop-gradient on z_target blocks the predictor from collapsing the target too. Papers (PHANTOM, V-JEPA, degeneration studies) show this lever works across video, physics models, and diffusion—regularization is the anti-collapse insurance.
Inference-time Physics Alignment of Video Generative Models with Laten — Frozen physics referee in latent space: V-JEPA-2 latent predictions are scored against physics constraints (conservation laws) without weight updates, preserving variance.
PHANTOM: Physics-Infused Video Generation via Joint Modeling of Visual — Physics branch covariance regularization: dedicated physics encoder's latent variance is constrained to stay orthogonal to visual directions, preventing semantic collapse into dynamics.
Suppressing Non-Semantic Noise in Masked Image Modeling Representation — Directional degeneration pruning: identify and zero out low-information eigenvectors in the representation covariance, surgical anti-collapse without architectural change.
Diversity over Uniformity: Rethinking Representation in Generated Imag — Feature organization as collapse cause: rearrange embeddings to maximize pairwise distance among semantic classes rather than enforcing uniform sphere normalization.
4SSL as infrastructure
frozen_backbone = load_pretrained(); new_task_head = train_only_head_on_downstream(frozen_backbone) — extract + adapt
Self-supervised pretraining learns a universal visual codec in the backbone. Frozen features + lightweight heads are cheaper to adapt than retraining and often outperform task-specific training. Papers (INSID3, DINO omnivorous, Patch-ioner, VFM-VAE) show that one pretrained encoder (DINO, DINOv3) can be plugged into segmentation, captioning, diffusion, in-context learning—the lever is reuse without retraining.
INSID3: Training-Free In-Context Segmentation with DINOv3 — Frozen foundation encoder as label factory: DINOv3 features directly feed a nearest-neighbor classifier without fine-tuning, making SSL output a reusable backbone.
A Mixed Diet Makes DINO An Omnivorous Vision Encoder — Lightweight teacher-student on frozen DINO: adapter network learns domain-specific mappings while DINO's representation stays fixed, achieving efficient transfer.
One Patch to Caption Them All: A Unified Zero-Shot Captioning Framewor — Patch aggregation from frozen features: caption tokens are predicted from per-patch DINO embeddings with learned pooling, no visual encoder retraining.
Vision Foundation Models Can Be Good Tokenizers for Latent Diffusion M — Foundation model as VAE encoder: frozen VFM replaces the learned tokenizer encoder in diffusion, letting SSL representations directly compress image space.
5Learning from the robot's own experience
y_label = self_supervise(x_future_or_paired_modality); minimize task_loss(predictor(x_now), y_label) — no human labels, only physics/geometry
Robots generate their own labels by acting: future frames tell whether a motion was good (traversability), multi-camera views agree on odometry, contact forces self-label touch. Papers (STEPP, CAGE, VertiCoder, ORB-SfMLearner) show that kinematics, optics, and physics provide free supervision—the lever is mining labels from the environment instead of human annotation.
Watch Your STEPP: Semantic Traversability Estimation Using Pose Projec — Ego-motion as self-label: robot pose changes between frames supervise traversability via geometric reprojection, no manual annotation needed.
Cage: Causal Attention Enables Data-Efficient Generalizable Robotic Ma — Frozen DINOv2 + causal masking: foundation model features are pruned via causal attention to suppress future information, making representation causally consistent with action.
VertiCoder: Self-Supervised Kinodynamic Representation Learning on Ver — Interaction data self-labels: motor commands and proprioception are paired in contrastive loss, so the embedding ties state to actionability without external reward.
ORB-SfMLearner: ORB-Guided Self-supervised Visual Odometry with Select — Photometric consistency + ORB guidance: odometry is learned via image reconstruction loss weighted by ORB feature reliability, making visual self-supervision attention-aware.
6Align across sensors and places
z_lidar = encoder_lidar(point_cloud); z_rgb = encoder_rgb(image); maximize similarity(z_lidar, z_rgb) where both see the same scene — contrastive or joint embedding
LiDAR and cameras see the same place in different ways; audio and touch feel the same contact. Learning a shared embedding forces each modality to extract what is invariant across sensors. Papers (U2 Frame, touch pretraining, monocular place rec, Cohere3D) pull this by mining correspondence from time (two frames apart = same place) or geometry (point cloud + image = same scene) rather than labels, then enforce agreement in a joint space.
$U2$ Frame: A Unified and Unsupervised Learning Framework for LiDAR-Ba — Point cloud self-supervision: LiDAR sequences generate contrastive pairs from temporal coherence and spatial consistency, no pose labels, alignment emerges from data geometry.
Contrastive Touch-to-Touch Pretraining — Dual-sensor identity loss: tactile readings from the same contact are positive pairs across modalities, making the latent space fuse force and vision via shared events.
Monocular Visual Place Recognition in LiDAR Maps via Cross-Modal State — Shared embedding bridge: camera and LiDAR encoders map to a common latent space via contrastive loss, so place identity is learned cross-modally without pose.
Cohere3D: Exploiting Temporal Coherence for Unsupervised Representatio — Multi-sensor temporal coupling: 3D points are tracked across frames and sensor modalities via consistency loss, letting time and redundancy provide pseudo-labels.
The through-line.

The theorem is simple: a representation is useful if it compresses content while discarding nuisance variation. SSL poses a question the data answers alone: 'do two corrupted views encode the same content?' But that question has a pathological solution—collapse all embeddings to a constant, and all comparisons look identical. The entire theme is the algebra that blocks this trap. Contrastive methods force coverage via the softmax denominator (no single vector wins all comparisons). Non-contrastive methods regulate dimensionality and variance by hand (the negative partition function built into the loss). Masked methods hide parts of the input, so the encoder must preserve information—the task itself is anti-collapse. These are not separate ideas; they are different handles on the same lever: compress content while maintaining entropy. That tension, encoded into a differentiable loss, extracts features no labels were needed for.
