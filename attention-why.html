Why attention — letting each token choose what to look at

Attention is the engine under almost everything modern AI does — the Transformer it powers is the default backbone of vision, language, and, increasingly, robotics. This page is the plain-language story: the one problem it solves, the single idea that solves it, a real run where you can see attention doing its deepest trick, the measured reason it needs depth, its one real weakness, and the surprise that the same mechanism now drives robots.

1 · The problem — how does a token get the right context?

A model reads a sequence — words, or the little patches an image is cut into. No token means much on its own; each one needs information from other tokens to make sense. The word “it” needs whatever noun it refers to; an image patch of an ear needs the patches that make it a cat. The hard part is: which other tokens, and where are they?

The problem, stated once: every token needs to pull in exactly the other tokens that are relevant to it — which could be anywhere in the sequence, at a distance that changes every time.

The older tools each fall short. A convolution only looks at fixed nearby neighbours, so it misses long-range links (the noun ten words back). A plain fully-connected layer wires fixed positions together, so it can't handle a sequence whose length or arrangement varies. What you want is a layer where the connections themselves depend on the content — where each token decides, on the fly, who to listen to.

2 · The reframe — a content-based lookup each token runs for itself

The idea: let every token ask a question, and let every token answer. Each token emits a query (“what am I looking for?”) and also offers a key (“here is what I am”). A token's query is compared against every key; the better the match, the more that token contributes. The result is a weighted average of everyone's values — and the weights are computed fresh from the content. That is attention: a soft, learned dictionary lookup each token runs for itself.
attention(Q,K,V) = softmax( Q·Kᵀ / √d ) · V     # match every query to every key → weights → weighted average of values

Three things fall out for free. It connects any token to any token regardless of distance, so long-range links are as easy as short ones. It works for any length and doesn't care about the raw ordering (position is added separately), so it is far more flexible than a fixed-wiring layer. And you can run several lookups in parallel — the “heads” of multi-head attention — each free to track a different kind of relationship. Stack these layers and something remarkable happens: they start to compose into little algorithms. The clearest one you can actually watch is next.

3 · Seen on a real run — the induction circuit

Every number below is measured. We trained tiny transformers to continue a per-sequence random pattern (a walk s[i+1] = g(s[i]) where the rule g is fresh each sequence, so it can only be read from context, never memorized). Predicting the next token means finding where the current token appeared before and copying what came next — pure induction. On Colab GPU; the numbers are the model's, not ours.
the real attention map of the trained induction head (rows = query token, columns = what it looks at; causal, so only the lower triangle exists). The bright staircase is the head copying from earlier in this sequence; the bright left column is an “attention sink” — a rest position it parks on when there is nothing to copy yet.

Read one bright cell: a query token that has appeared before looks straight back to the position right after its earlier occurrence — the token it should copy next — with attention weight 1.00. The staircase sits at a steady offset here only because this particular sequence's pattern happens to repeat with a fixed period. But that period is different every sequence and written nowhere in the weights — so the model had to find it by matching content. That is exactly what attention is, and exactly why one layer (which can only key off fixed positions) cannot do it.

The phase change is in the depth

With one attention layer the model tops out at 0.55 — it can match tokens by content or copy by position, but it cannot do the two-step move induction needs. Add a second layer and accuracy jumps to 1.00: the two layers compose into the induction circuit — a first head stamps each position with the token before it, and a second head's query matches the current token and reads the token that followed it last time. That leap from 0.55 to 1.00 is a real phase change: the ability appears only once the depth is there to build the circuit.

And a clean negative result: at two layers, going from 1 head to 4 barely moves accuracy (1.00 → 1.00). For this task it is depth (layers that compose) that unlocks the skill, not width (more heads in parallel). Extra heads buy capacity and robustness in real models, but they are not what makes induction possible.

4 · Why attention took over

The Transformer — attention stacked into a backbone — is now the near-universal substrate of computer vision; by our count it underlies at least a quarter to a third of CVPR 2026, and the true share is higher because most papers take it as unstated infrastructure. Three properties explain the takeover:

propertywhy it matters
Content-based, any-to-any routinga token can reach the exact other token it needs, however far away — the long-range links a convolution can't make.
Order-flexible, any lengththe same layer handles a short caption or an hour of video; it doesn't hard-wire positions, so it scales across shapes and sizes.
Layers compose into circuitsas the run showed, stacked attention builds algorithms like induction — which is the root of in-context learning, the ability to pick up a new pattern from the prompt with no weight changes.

5 · The one real weakness — the quadratic cost

There is a catch, and it is the single most-fought problem in the field. If every token compares itself to every other token, the work grows with the square of the sequence length. Double the tokens and you quadruple the cost — and a 4K image or a long video has a lot of tokens (in some video models three-quarters of all compute is attention). So a huge share of research is spent taming it, in two ways: fewer tokens (merge or prune the unimportant ones) and cheaper math (linear or sparse attention, and state-space models like Mamba — which turn out to be a low-rank approximation of the same weighted-average idea). It is the central tradeoff of the whole architecture: attention's power is that everything can see everything, and its cost is exactly the same thing.

6 · The surprise — the same attention now drives robots

Attention did not stay in vision and language. The same mechanism is now a backbone of robotics, in three distinct jobs. As a sensor-fusion operator: cross-attention is how a robot aligns and merges camera, LiDAR, radar, touch, and language, each living in a different frame — queries from one modality attending over another. As a way to reason about other agents: attention over the cars and pedestrians in a scene decides which ones matter to your next move. And as a policy itself: decision- and action-transformers treat a history of observations and actions as tokens and predict the next action, the GPT recipe pointed at control.

Same mechanism, different job. The lookup that lets the word “it” find its noun is the same lookup that lets a robot fuse a LiDAR return with a camera pixel, or attend to the pedestrian about to step out. Learn attention once and you have the shared language of modern vision, language, and control. The in-the-wild page lays out all of it with real papers.
