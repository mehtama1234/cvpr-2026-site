State-space models / Mamba — why it works, mathematically

A compressed memory of the past, updated in linear time via selectivity gates

The problem, as a quantity

Transformers attend to every token, costing O(L²) memory and compute. Vision gets worse: O(L²) where L is pixels, and the cache grows with sequence length. We need a model that holds a lossy summary of history—a state—and updates it efficiently per step, even for very long contexts or streaming data.

The core ideas — and why they work

Linear recurrence as compressed state

The core math behind state-space models
The recurrence h_t = A·h_{t-1} + B·x_t squashes all previous inputs into a fixed-size vector h_t. Because it is LINEAR, you can unroll it globally as a convolution or compute it in parallel via a scan—no step-by-step loop needed. This gives O(L) time to process all L tokens, versus O(L²) for attention. The trade-off: you compress history into h_t, so you can only remember what the state captures. But that's often enough: the state is a sufficient statistic for predicting y_t = C·h_t.

Selectivity: input-dependent gating

What Mamba adds to make linear recurrence competitive with attention
In a time-invariant system, A, B, C never change; the model learns one global memory strategy. Mamba makes B, C, and the step size Δ depend on the input x_t. Now the model can ask: 'for this token, what do I need to store?'—gating at linear cost. Even though the system is no longer time-invariant, the parallel scan still works (it takes only O(log L) depth on GPUs). You get attention-like selectivity—forget unimportant details, preserve key facts—without the quadratic memory bill.

Parallel scan for GPU speed

How linearity unlocks hardware efficiency
A loop h_t = A·h_{t-1} + B·x_t cannot be parallelized: step t waits for step t−1. But if you expand it as a global convolution (or use an associative parallel scan), you expose a tree of O(log L) depth. Each layer of the tree runs in parallel across the GPU, so all L steps compute in O(log L) wall-clock time. The trick works because matrix multiplication is associative. Non-linear models (like RNNs with tanh) break this—you're stuck with sequential step-by-step execution.

State is a lossy summary, not a cache

Why state-space models scale where attention does not
Transformers' KV cache grows: L keys, L values, D dimensions each. For a million-token context, that is Milli × D memory. A state-space model's hidden state is always N dimensions (N ≪ L). You discard information at every step—'state' is lossy compression—but you choose what to keep via selectivity. When selectivity is learned well, the few bits you keep are more useful than the full cache. For vision, this means one fixed-size state summarizes arbitrary image size, enabling inference on small devices.

The approaches, as variations on the math

Apply state-spaces where sequences are long or you need fixed-memory footprint: language (competitive with Transformers on downstream tasks, faster on generation), image & video (one state per image, no quadratic pixel cost), audio streams (constant memory for arbitrarily long audio), and embedded control (a policy's latent state persists across time). Hybrids: use state-spaces for efficient long-context, then apply a cheap attention head to the state for sharp reasoning on critical details. For 2D images, scanning order matters—row-major or Hilbert curves change what the state 'sees' first. Small mobile devices benefit most: state-space can run inference in place (O(1) memory) while Transformers must allocate for the full cache.

1Which order do I read a 2D image
h_t = A_t ⊙ h_{t-1} + B_t ⊙ x_t where A_t, B_t depend on position: adaptive scanning lets image structure choose the state update weights, not raster-scan order
Standard state-space models flatten 2D images into 1D sequences with fixed scanning order (raster or diagonal). Mamba makes this adaptive: each position learns whether to preserve prior state (A_t ≈ 1) or reset it (A_t ≈ 0), and how much to absorb current input. CrackSSM and VMamba show that learned scanning order follows cracks and object boundaries rather than pixel grids, compressing redundant regions while preserving spatial discontinuities.
RNN as Linear Transformer: A Closer Investigation into Representational Power of SSMs — Data-dependent mask gates each timestep proportional to input, replacing fixed attention softmax.
CrackSSM: Reviving SSMs for Crack Segmentation via Dynamic Scanning — Adaptive raster-path selection via learned scan order instead of fixed row-major traversal.
SSM-Aware Token-Efficient VMamba via Adaptive Patch Pruning and Merging — State magnitude directs which patches to retain, pruning low-signal regions before projection.
Scaling Parallel Sequence Models to Vision Foundation Models — Linear-time backbone replaces quadratic attention depth while maintaining foundation-model capacity.
2Where linear time pays off most
Cost ≈ O(L) for full temporal sequence vs O(L²) attention, with dilated state A^(k) applied at multiple strides k: multi-scale branching trades memory for time only at scales where information changes slowly
Attention costs O(L²) because every frame attends to every other frame. Mamba runs one pass at O(L) by compressing to a single hidden state, but coarse-grained tasks (video understanding, temporal grounding) need both fast streaming and multi-scale reasoning. MS-Temba and HieraMamba branch the scan into dilated SSMs that skip frames at different rates—slow changes stay O(L) while fast changes stay precise. TimeViper keeps the cheap backbone for long sequences and uses attention only on small feature tokens where O(L²) is affordable.
TimeViper: A Hybrid Mamba-Transformer Vision-Language Model for Efficient Long Video Understanding — Interleaved Mamba layers (O(n)) with sparse transformer (O(log n)) bottleneck reduce cost and preserve alignment.
MS-Temba: Multi-Scale Temporal Mamba for Understanding Long Untrimmed Videos — Parallel SSM scans at dilated intervals skip[1,2,4,8] frames, merging state updates across temporal scales.
HieraMamba: Video Temporal Grounding via Hierarchical Anchor-Mamba Pooling — Hierarchical anchor tokens guide SSM sweeps at coarse-to-fine temporal resolution, fusing video and text state.
ReMoRa: Multimodal Large Language Model based on Refined Motion Representation — Compressed video codec latent code substitutes for raw pixel sequence, reducing effective length L.
3Every pixel, and unordered 3D
Geometry G guides serialization π(p) of 3D points: h_t = A h_{t-1} + B x_{π(t)} where π preserves local neighborhoods, not Cartesian order
Linear recurrence requires a 1D sequence, but 3D point clouds and volumetric data have no natural order—Cartesian (x, y, z) order scrambles geometry. GeoSemba bakes anatomy into A and B (e.g., anisotropic diffusion along tissue planes). VEMamba uses axial-lateral scans that respect 3D structure. RI-Mamba reorders points by local shape properties (distance to principal axes) instead of coordinates, so rotation changes the sequence order—rotation-invariance emerges from geometry-aware serialization, not learned pooling.
GeoSemba: Reconstructing State Space Model for Cross Paradigm Representation — State transition preserves anatomical geometry via learned manifold projection before 2D→1D flattening.
VEMamba: Efficient Isotropic Reconstruction of Volume Electron Microscopy — Axial-Lateral Cross-SSM interleaves depth-plane and plane-depth scans so information flows in all 3D directions.
Mamba Learns in Context: Structure-Aware Domain Generalization for Multi-View Semantic Segmentation — Point ordering by intrinsic curvature/geodesic distance rather than xyz coordinates preserves shape topology.
RI-Mamba: Rotation-Invariant Mamba for Robust Text-to-Shape Retrieval — Global+local reference frames separate object orientation from scan order, achieving SO(3)-equivariance in SSM state.
4Fast context plus sharp reasoning
Σ_{i} exp(s_i · q) · v_i decomposed as O(1) state for context + O(1) sharp query: attention factorizes into streaming summary plus focused lookup
Attention is expensive but sharp—it can spotlight one token among thousands. State-space models are cheap but smooth—they average all history into one state. Hybrid models split the work: Mamba processes most frames into a lossy state (context), then attention attends over a small window (sharp reasoning). ZipMap uses test-time training to compress an image collection into one state in a single forward pass, showing that state-space can also be sharp when the state itself is trained to encode fine details.
When Transformers Meet Mamba: A Hybrid Transformer-Mamba Network for Visual Object Detection — Mamba backbone extracts global features cheap O(n), transformer head sharpens box reasoning on K anchor regions.
Gated KalmaNet: A Fading Memory Layer Through Test-Time Ridge Regression — Explicit Kalman-filter state with time-decaying covariance replaces generic Mamba hidden state for predictable forgetting.
AKCMamba-YOLO: Selective State Space Models For Real-Time Object Detection — C2f residual blocks replaced with SSM sequential layers, Attention-based channel weighting on SSM output.
ZipMap: Linear-Time Stateful 3D Reconstruction via Test-Time Training — Single compact scene state h accumulates evidence from full image batch in one pass, learned via gradient descent.
5Linear-time vision on a small onboard GPU
Memory ≈ O(D·S) hidden state vs O(L·D) for attention KV cache, where D ≪ L in streaming tasks: state-space trades sequence length for hidden-dimension efficiency
Transformers store full attention keys and values (O(L·D) memory); even with L=10k, this fills edge GPUs. Mamba keeps one state vector (O(D)) updated once per frame—D can be 256-512 while L grows unbounded. CoMamba fuses multi-vehicle sensor data with bidirectional Mamba in place of transformer fusion, halving latency. CM-SSM weaves color + thermal streams into one state, and MambaNUT drops transformers entirely for real-time UAV tracking—linear memory growth makes onboard inference viable for long sequences.
CoMamba: Real-time Cooperative Perception Unlocked with State-Space Models — Bidirectional SSM exchanges vehicle-local features across agents without quadratic pairwise attention cost.
Cross-modal State Space Modeling for Real-time RGB-thermal Wild Scene Understanding — 2D selective scan kernel walks SSM state jointly across RGB and thermal feature maps, fusing modes via gating.
MambaNUT: Nighttime UAV Tracking via Mamba-based Adaptive Curriculum Learning — Pure state-space backbone O(n) scales to arbitrary sequence length, avoiding transformer quadratic memory.
Hybrid Transformer-Mamba Model for 3D Semantic Segmentation — Mamba and transformer combined per-layer via mixed residual paths, each operation contributes to shared hidden state.
6A memory that persists, a policy small enough to run
S_{t+1} = A_θ · S_t + B_θ · (history, query); π_θ ≈ ℓ_p(S_t) where state remembers and policy is lightweight: Mamba backbone fits in edge memory while online maps grow
Robotics needs both persistent memory (map from prior moments) and lightweight inference (policy on onboard hardware). MambaMap stores a memory bank of historical map elements and runs Mamba scan over queries—state accumulates evidence across time. Mamba Policy uses XMamba (Mamba + attention) to replace bulky diffusion backbones in 3D grasping, and GraspMamba processes multi-scale visual features through a Mamba backbone, keeping the policy head tiny so edge devices can run real-time grasping without GPU memory for attention caches.
MambaMap: Online Vectorized HD Map Construction using State Space Model — Memory bank holds historical bird's-eye-view features and map queries, SSM updates current state h from bank history.
Monocular Visual Place Recognition in LiDAR Maps via Cross-Modal State Space Modeling — VMamba backbone embeds RGB and point-cloud inputs to joint compact descriptor via shared state-space bottleneck.
Mamba Policy: Towards Efficient 3D Diffusion Policy with Hybrid Selective Attention — XMamba pairs selective SSM (cheap dynamics) with attention (sharp action head) in diffusion trajectory predictor.
GraspMamba: A Mamba-based Language-driven Grasp Detection Framework with Semantic Hierarchy — Multi-scale Mamba backbone fuses visual hierarchy and language embeddings, SSM state encodes grasp feasibility.
The through-line. Linearity gives you a fast algorithm (parallel scan). Selectivity gives you the power (choose what to remember). Together: O(L) time, O(1) memory, learned memory strategy—the speed of RNNs with the expressiveness of Transformers.
