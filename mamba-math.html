State-space models / Mamba — why it works, mathematically

A compressed memory of the past, updated in linear time via selectivity gates

The problem, as a quantity

Transformers attend to every token with every other, costing O(L²) memory and compute just to read the past — and the cost grows with sequence length. For long contexts, videos, or streaming data, the bill becomes prohibitive. The real tension: attention must re-read the whole past for every new token to stay selective about what matters, but reading everything is expensive. Can you maintain a small fixed-size state instead—a compressed summary of history—and update it in O(L) time while still being selective about what to keep rather than what to forget?

The core ideas — and why they work

Linear recurrence as fixed-memory state

h_t = Ā·h_{t−1} + B̄·x_t, y_t = C·h_t, h_t ∈ ℝ^N, N ≪ L
A linear recurrence compresses all history into a single fixed-size vector h_t. The key insight: linearity unlocks computation. You can unroll this global as a convolution across all L tokens, or compute it in parallel via a scan tree—no step-by-step sequential loop. This trades the quadratic cost of attention (re-reading everything) for a single linear pass over the sequence, updating state in O(L) time. The hard trade-off is real: you compress history, so the state can only encode what it captures. But if the state is a sufficient statistic for the prediction y_t = C·h_t—if the task does not need verbatim recall—this lossy compression is the honest shape of the model. The state is a running summary, not a cache. Same primitive elsewhere: fixed-size state-as-compression is the same low-rank / compression move that powers distillation, codebooks, and world-model latents — useful information lives in fewer dimensions than raw history.

Time-invariant systems are fast but rigid

If A, B, C are constants: h_t = A·h_{t−1} + B·x_t ⇒ closed-form convolution, but one memory strategy for all inputs
In a classical linear time-invariant (LTI) system, the state-space matrices do not change: the model learns a single global strategy for what to remember and forget. All tokens are updated by the same rule. This is computationally beautiful—you can solve the recurrence as a global convolution in O(L log L) time via FFT—but inflexible: the model cannot decide what to keep for this particular token versus that one. A time-invariant system is fast but not selective. The whole power of attention is precisely that it can change its focus per token: attend sharply to some things, ignore others. A classical LTI state-space model gives you speed but hands away that selectivity.

Selectivity: input-dependent gating and step size

Mamba: Δ_t, B̄_t, C_t = f(x_t); h_t = exp(Δ_t · A)·h_{t−1} + (B̄_t / Δ_t)·x_t, y_t = C_t·h_t
Mamba breaks the LTI constraint: the state-space parameters (step size Δ_t, input projection B̄_t, output projection C_t) now depend on the input x_t. The model can ask: for this token, what matters? If the token is important, increase Δ_t to strengthen the state update and hold the information longer; if it is noise, shrink Δ_t to let it decay. This is a learned gate—the model trains f(x_t) to predict what the state needs. And here is the miracle: the recurrence is still linear in state, so the parallel scan still works (depth O(log L) on GPU). You get attention-like selectivity—forget noise, keep key facts—without the quadratic memory bill. Same primitive elsewhere: input-dependent gating is the soft-selection idea that powers Softmax (attention, MoE) and many gating mechanisms — the field keeps reaching for 'read the input, emit a soft decision' because it works.

Constant-memory state scales to arbitrary length

State size N is fixed; KV cache size is L×D. For L → ∞ or streaming: state-space is O(1) memory, Transformer is O(L).
A Transformer's KV cache grows with the sequence length: L tokens, D dimensions each per cache entry = O(L·D) memory. For a million-token context or a video with a million frames, the cache is enormous. A state-space model's hidden state is always the same size: N dimensions, typically 100s or 1000s. You discard information at every step—that is what 'state' means, a lossy summary—but you choose what to discard via the learned selectivity gates. When selectivity is trained well, the few crucial bits you keep are more useful than the full cache. For vision this is remarkable: one fixed-size state summarizes an arbitrarily large image; you never pay the pixel-count tax. For embedded systems and edge devices, state-spaces enable inference in place (O(1) memory), while Transformers must allocate the full cache upfront.

Parallel scan: unrolling linearity for GPU efficiency

Recurrence h_t = A·h_{t−1} + B·x_t can be reformulated as: h_L = (A^L, A^{L−1}·B·x_1 + A^{L−2}·B·x_2 + ... + B·x_L). Associative ops → O(log L) parallel depth.
A sequential loop cannot be parallelized—step t must wait for step t−1. But if you rewrite the linear recurrence as an associative scan (accumulating a binary operation across the sequence), you expose a tree of O(log L) depth. GPUs are built for trees: each layer computes in parallel, and after log L layers all L steps are done. The trick works only because multiplication and addition are associative. Non-linear models—RNNs with tanh, gating—break this: you lose associativity, so you are back to sequential step-by-step execution. Linearity is the key that unlocks hardware parallelism. This is not a free pass: you give up the expressive power of nonlinearities, but Mamba recovers it via the input-dependent selectivity gates, which inject nonlinearity in a hardware-friendly way.

The approaches, as variations on the math

Apply state-space models wherever sequences are long or memory must be fixed: language models (competitive with Transformers on downstream tasks, faster during generation since cache is constant-size), images and video (one state per image, no quadratic pixel cost, enables processing at arbitrary resolution), audio streams (constant memory for arbitrarily long audio, perfect for real-time), and embedded control (a policy's latent state persists across time steps without growing). Hybrids combine both: use state-spaces for efficient long-context backbone, then apply a cheap attention head to the fixed state for sharp reasoning on a few critical details. For 2D images, the scanning order matters—row-major, column-major, or space-filling Hilbert curves change what the state sees first, tuning which patterns it captures. Small mobile devices and edge systems benefit most: state-space inference runs in place (O(1) memory, constant-time updates), while Transformers must allocate for the full KV cache.

A worked numeric example

For a one-dimensional state update h_t=0.8h_{t-1}+x_t, an input from five steps ago is weighted by 0.8^5=0.328. If the learned decay becomes 0.95, the same input still has weight 0.774. The state-space lever is visible in the number: change the decay, and the model changes how long memory survives.

1Which order do I read a 2D image
h_t = A_t ⊙ h_{t-1} + B_t ⊙ x_t where A_t, B_t depend on position: adaptive scanning lets image structure choose the state update weights, not raster-scan order
Standard state-space models flatten 2D images into 1D sequences with fixed scanning order (raster or diagonal). Mamba makes this adaptive: each position learns whether to preserve prior state (A_t ≈ 1) or reset it (A_t ≈ 0), and how much to absorb current input. CrackSSM and VMamba show that learned scanning order follows cracks and object boundaries rather than pixel grids, compressing redundant regions while preserving spatial discontinuities.

2Where linear time pays off most
Cost ≈ O(L) for full temporal sequence vs O(L²) attention, with dilated state A^(k) applied at multiple strides k: multi-scale branching trades memory for time only at scales where information changes slowly
Attention costs O(L²) because every frame attends to every other frame. Mamba runs one pass at O(L) by compressing to a single hidden state, but coarse-grained tasks (video understanding, temporal grounding) need both fast streaming and multi-scale reasoning. MS-Temba and HieraMamba branch the scan into dilated SSMs that skip frames at different rates—slow changes stay O(L) while fast changes stay precise. TimeViper keeps the cheap backbone for long sequences and uses attention only on small feature tokens where O(L²) is affordable.
TimeViper: A Hybrid Mamba-Transformer Vision-Language Model for Efficient Long Video Understanding — Interleaved Mamba layers (O(n)) with sparse transformer (O(log n)) bottleneck reduce cost and preserve alignment.
MS-Temba: Multi-Scale Temporal Mamba for Understanding Long Untrimmed Videos — Parallel SSM scans at dilated intervals skip[1,2,4,8] frames, merging state updates across temporal scales.
HieraMamba: Video Temporal Grounding via Hierarchical Anchor-Mamba Pooling — Hierarchical anchor tokens guide SSM sweeps at coarse-to-fine temporal resolution, fusing video and text state.
ReMoRa: Multimodal Large Language Model based on Refined Motion Representation — Compressed video codec latent code substitutes for raw pixel sequence, reducing effective length L.
3Every pixel, and unordered 3D
Geometry G guides serialization π(p) of 3D points: h_t = A h_{t-1} + B x_{π(t)} where π preserves local neighborhoods, not Cartesian order
Linear recurrence requires a 1D sequence, but 3D point clouds and volumetric data have no natural order—Cartesian (x, y, z) order scrambles geometry. GeoSemba bakes anatomy into A and B (e.g., anisotropic diffusion along tissue planes). VEMamba uses axial-lateral scans that respect 3D structure. RI-Mamba reorders points by local shape properties (distance to principal axes) instead of coordinates, so rotation changes the sequence order—rotation-invariance emerges from geometry-aware serialization, not learned pooling.
GeoSemba: Reconstructing State Space Model for Cross Paradigm Representation — State transition preserves anatomical geometry via learned manifold projection before 2D→1D flattening.
VEMamba: Efficient Isotropic Reconstruction of Volume Electron Microscopy — Axial-Lateral Cross-SSM interleaves depth-plane and plane-depth scans so information flows in all 3D directions.
Mamba Learns in Context: Structure-Aware Domain Generalization for Multi-View Semantic Segmentation — Point ordering by intrinsic curvature/geodesic distance rather than xyz coordinates preserves shape topology.
RI-Mamba: Rotation-Invariant Mamba for Robust Text-to-Shape Retrieval — Global+local reference frames separate object orientation from scan order, achieving SO(3)-equivariance in SSM state.
4Fast context plus sharp reasoning
Σ_{i} exp(s_i · q) · v_i decomposed as O(1) state for context + O(1) sharp query: attention factorizes into streaming summary plus focused lookup
Attention is expensive but sharp—it can spotlight one token among thousands. State-space models are cheap but smooth—they average all history into one state. Hybrid models split the work: Mamba processes most frames into a lossy state (context), then attention attends over a small window (sharp reasoning). ZipMap uses test-time training to compress an image collection into one state in a single forward pass, showing that state-space can also be sharp when the state itself is trained to encode fine details.
When Transformers Meet Mamba: A Hybrid Transformer-Mamba Network for Visual Object Detection — Mamba backbone extracts global features cheap O(n), transformer head sharpens box reasoning on K anchor regions.

AKCMamba-YOLO: Selective State Space Models For Real-Time Object Detection — C2f residual blocks replaced with SSM sequential layers, Attention-based channel weighting on SSM output.
ZipMap: Linear-Time Stateful 3D Reconstruction via Test-Time Training — Single compact scene state h accumulates evidence from full image batch in one pass, learned via gradient descent.
5Linear-time vision on a small onboard GPU
Memory ≈ O(D·S) hidden state vs O(L·D) for attention KV cache, where D ≪ L in streaming tasks: state-space trades sequence length for hidden-dimension efficiency
Transformers store full attention keys and values (O(L·D) memory); even with L=10k, this fills edge GPUs. Mamba keeps one state vector (O(D)) updated once per frame—D can be 256-512 while L grows unbounded. CoMamba fuses multi-vehicle sensor data with bidirectional Mamba in place of transformer fusion, halving latency. CM-SSM weaves color + thermal streams into one state, and MambaNUT drops transformers entirely for real-time UAV tracking—linear memory growth makes onboard inference viable for long sequences.

Hybrid Transformer-Mamba Model for 3D Semantic Segmentation — Mamba and transformer combined per-layer via mixed residual paths, each operation contributes to shared hidden state.
6A memory that persists, a policy small enough to run
S_{t+1} = A_θ · S_t + B_θ · (history, query); π_θ ≈ ℓ_p(S_t) where state remembers and policy is lightweight: Mamba backbone fits in edge memory while online maps grow
Robotics needs both persistent memory (map from prior moments) and lightweight inference (policy on onboard hardware). The through-line. Linearity gives you a fast algorithm: parallel scan in O(log L) depth. Selectivity gives you the power: input-dependent gates let the model choose what to remember and forget per token. Together: O(L) total compute, O(1) memory regardless of length, and a learned strategy for what matters. The trade-off from attention's flexibility is real, but for many tasks—especially long-context and streaming—the speed and memory win is worth it. State-space models solve the same 'read efficiently from the past' tension that runs through the field, but with a different strategy: compress and gate rather than recompute everything.
