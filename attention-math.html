Attention — why it works, mathematically

Soft-weighting to read what matters most

The problem, as a quantity

To fuse information spread across space—image patches, point clouds, sensor streams—you must answer two things at once: which parts matter (a discrete choice with no gradient) and how much (a continuous blend). The real obstacle is that a hard argmax gives zero gradient, so the model cannot learn what to read. You need to turn 'pick one' into something differentiable without losing the ability to focus. And you need to scale: comparing everything to everything else costs O(n²), which breaks on large images and long sequences.

The core ideas — and why they work

Softmax as differentiable selection

weights_j = exp(q · k_j / √d) / Σᵢ exp(q · k_i / √d), output = Σⱼ weights_j · v_j
A hard argmax—'select the biggest dot product'—has zero gradient everywhere, so the model cannot learn. The fix is the single most reused move in deep learning: replace the hard choice with a soft, differentiable weighting. Softmax turns a dot product q · k_j into a probability-like weight weights_j ∈ (0,1) that sums to one. If one match is much stronger, it dominates; if several match equally, they share the weight. Every element sends a nonzero gradient backward, so learning can adjust queries, keys, and values all at once. The output is always a convex combination of values, so it stays bounded—no wild swings. Same primitive elsewhere: this softmax selection is exactly the trick that powers mixture-of-experts (soft routing to experts), CLIP (soft matching between images and text), DETR (soft detection assignment), and slots (soft object binding). Every time the field needs to say 'pick one' but learn it, it reaches for softmax.

Scaling by √d prevents softmax saturation

numerator: exp(q · k_j / √d), denominator: Σᵢ exp(q · k_i / √d), √d is the variance of random dot products in dimension d
When q and k are random vectors in dimension d, their dot product grows as O(√d). Without scaling, exp(q · k_j) explodes to infinity or collapses to zero before softmax sees it, turning softmax into a near-delta function: one weight → 1.0, all others → 0.0. Gradients vanish. The fix is to divide the logit by √d so that the exponent stays in a tame range (roughly [-1, 1] for random vectors), making softmax roughly linear in its input. Now all weights contribute meaningful gradients, and the model can learn fine distinctions. Same primitive elsewhere: this is the same variance-stabilizing trick that batch normalization uses to keep activations in a learnable range—the principle is 'scale by the intrinsic size of your inputs so the nonlinearity stays in its sensitive zone.'

Permutation equivariance through dot-product similarity

if rows of Q, K, V are permuted identically, rows of output are permuted the same way, the computation Q·Kᵀ is a <em>set operation</em>, not a sequence operation
Attention does not depend on which row comes first—only on which keys match which queries. If you shuffle your token positions or spatial indices, the output shuffles identically, but the attention computation itself never breaks. This means attention is a set operation, not a sequence operation: it asks 'which inputs are relevant?' without caring about order. Sets have no natural order; the dot product between q_i and all k_j is the same whether q_i was the 3rd input or the 8th. This is why attention works across modalities and with permuted data: the core mechanism is content-addressed lookup, not positional indexing. Positional encodings are added back in afterward to break ties and teach the model 'where things are,' but the core fusion is order-agnostic.

O(n²) cost is the price of pairwise content-addressing

QKᵀ costs O(n² · d) to compute (n² pairs, each a d-dimensional dot product), then softmax + weighted sum → O(n² · d) total
To ask 'which of n keys match this query?', you must compute a similarity score for all n pairs. In matrix form, that is QKᵀ—an n×n matrix. Each entry costs d multiplications (one per dimension), so the full matrix costs O(n² · d). On high-resolution images (n=4096 patches), this is millions of operations per layer. On video (n=frame_length × patches), it is quadratic in time and space. This quadratic wall is not a bug in the implementation—it is fundamental to pairwise content-addressing. Every method that claims to 'beat quadratic time' either (1) uses kernels to factor the sum (losing softmax exactness), (2) restricts which pairs to compare (sparse attention), or (3) uses a different similarity measure (e.g., Mamba's gating), trading precision for speed. Same primitive elsewhere: this quadratic cost is the same wall that all-pairs matching faces—CLIP's image-text matching, DETR's detection-target assignment, and slots' object binding all pay O(n² · d) for full bipartite matching. The field keeps reaching for sparse, kernel, or hierarchical workarounds.

The approaches, as variations on the math

Every method in this family is tuned on three knobs. Knob 1—reduce what you compare. Sparse attention (local windows, strided patterns, learned routing) restricts which keys each query can attend to, cutting n² to n·k for some small k. Hierarchical attention groups inputs first, then attends. Knob 2—replace exact softmax with something factorable. Linear attention replaces softmax with a kernel k(q, k_i) that factors into Σⱼ k(q, k_j)·v_j = k(q)·Σⱼ b(k_j)·v_j, trading exactness for O(n·d) speed. Knob 3—inject order without breaking permutation equivariance. Positional encodings (sinusoidal, RoPE, ALiBi) add geometric information after content-addressing so nearby positions upweight each other, using phase rotations or relative biases instead of absolute position tokens. The crossover case—cross-attention—pulls keys and values from a different input (image features, lidar, history, text), fusing sensors or time-steps with the same soft-selection principle.

1Beating the quadratic wall
cost = O(n log n) via sparse patterns or local windows: instead of computing all n² pairs, compute only log-linear subsets (local, strided, or learned) then softmax only those relevant entries; output remains Σⱼ∈subset weights_j · v_j
Standard attention computes similarity Q·Kᵀ for all n² token pairs, which dominates cost. Log-linear sparse attention, token merging, and pruning all reduce the denominator: either prune low-salience tokens before attention (fewer rows/columns), compute attention locally in windows, or learn which pairs matter. Each trades coverage for speed; the mathematical core (softmax + weighted sum) stays intact.
Trainable Log-linear Sparse Attention for Efficient Diffusion Transfor — Replaces dense QKᵀ with sparse selection via learned binary mask, reducing O(n²·d) to O(n·log(n)·d) by computing attention only on log(n) neighbors.
Attention Surgery: An Efficient Recipe to Linearize Your Video Diffusi — Linearly approximates softmax(QKᵀ)V via kernel trick ϕ(Q)·(ϕ(K)ᵀV), converting post-hoc without retraining, reducing inference from O(n²) to O(n).
Saliency-Driven Token Merging for Vision Transformers — Prunes tokens before attention via saliency scores s_i = ||∇_xi L||, collapsing low-s_i tokens into neighbors, reducing sequence length n → n' ≪ n before O(n'²) compute.
HAWK: Head Importance-Aware Visual Token Pruning in Multimodal Models — Estimates per-head importance weight w_h, then prunes tokens i where Σ_h w_h·s_{h,i} is minimal, respecting that heads have heterogeneous pruning sensitivity.
2Re-routing what attention looks at
factorized or constrained attention space: replace full QKᵀ with structured similarity matrix (e.g., 1D passes, two-view epipolar geometry, or cross-modal projection matrices); attend over subspace instead of full token set
Standard attention learns what to look at purely from learned queries and keys. These approaches inject domain structure—time ordering in video, geometry in 3D reconstruction, sequential reading in formulas—by constraining which token pairs can attend to each other. The softmax still picks a distribution, but over a reduced or reweighted set of candidates, so the attention mechanism respects the problem structure without learning it from scratch.
Vision Transformers Need More Than Registers — Adds learnable register tokens to prevent class token from lazy aggregation, ensuring output = Σ_j w_j·v_j actually spreads attention weights across image patches not just registers.
Ov3R: Open-Vocabulary Semantic 3D Reconstruction from RGB Videos — Fuses language features via cross-attention output = Σⱼ softmax(Q_lang · K_img)·V_feat, conditioning 3D geometry on semantic embeddings.
IDESplat: Iterative Depth Probability Estimation for Generalizable 3D — Constrains attention matches (Q_left, K_right) by epipolar geometry: only (u, v) in the epipolar line of (u', v') get non-zero softmax weight.
UniMERNet: A Universal Network for Real-World Mathematical Expression — Factorizes 2D attention [n² → n·n] into two 1D passes: first column-wise softmax(QKᵀ)V per row, then row-wise, respecting reading order of formulas.
3Telling attention where things are
position embedding as a rotation or coordinate system: before QK dot product, apply learnable per-head rotations (SVD-parameterized), scale-aware projections, or spherical coordinates (r, θ, φ) so that q and k encode their spatial/temporal location in the dot product
Dot-product attention is permutation-equivariant but position-agnostic; two tokens at different positions yield the same QK score. RoPE, HARoPE, and spherical embeddings bake position into q and k via rotations or coordinate transforms before the similarity is computed. This changes q·k to encode relative offset or absolute location, so the softmax weights naturally penalize or boost distant/adjacent pairs without explicit positional features.
Infinity-RoPE: Action-Controllable Infinite Video Generation Emerges F — Extends rotary position embeddings from RoPE(m) = [[cos(mθ_d), -sin(mθ_d)], [sin(mθ_d), cos(mθ_d)]] with learnable time scaling τ for extrapolating beyond training sequence length.
Cross-Scale Pansharpening via ScaleFormer and the PanScale Benchmark — Maps image resolution to sequence position m via hierarchical pooling, so low-res = short sequence, enabling RoPE to generalize across resolutions naturally.
Head-wise Adaptive Rotary Positional Encoding for Fine-Grained Image G — Learns per-head rotation scale matrix Θ_h = U·Σ_h·Vᵀ (SVD decomposition) so each head has tailored positional frequency θ_{d,h} instead of shared θ_d.
SoPE: Spherical Coordinate-Based Positional Embedding for Enhancing Sp — Encodes position (x,y,z) as (r, φ, θ) angles and radius r, injecting pos_embed = PE(r) + PE(φ) + PE(θ) to respect distance and direction geometry in 3D space.
4Reading attention, and choosing tokens
attention map as interpretable token-to-region correspondence: measure fine-grained alignment (layer-by-layer patch attention, causal information gain, discrete token identity) to identify which input regions generated each output token; select or design tokens to match meaningful objects/words
Standard attention has opaque weights; this sub-theme asks what the weights mean. By grounding attention maps to spatial regions or measuring causal contribution of heads, papers identify which image patches or context tokens matter for each prediction. This feeds back into tokenizer design: if tokens must correspond to objects (not arbitrary patches), the tokenizer can be redesigned to emit discrete semantic units, making attention outputs debuggable and tokens reusable across tasks.
Beyond the Global Scores: Fine-Grained Token Grounding as a Robust Det — Decomposes attention into per-patch, per-layer attention α_{layer,patch,token}, analyzing how each output token distributes softmax(QKᵀ) across fine-grained regions.
CIGMA: Causal Information-Gain Mechanistic Attribution of Attention He — Uses causal intervention (knock out head h) to measure Δ I(h; output | context) and I(h; output | object), isolating which heads rely on foreground vs. background.
AToken: A Unified Tokenizer for Vision — Embeds image/video/3D in shared 4D latent space with unified rotary pos_embed(x,y,z,t), so self-attention operates on aligned token sequences across modalities.
A More Word-like Image Tokenization for MLLMs — Replaces flat patch tokens with semantic tokens s_i via learned discrete codebook, so that attention selects meaningful object regions rather than arbitrary spatial patches.
5Fusing senses and reading other agents
bidirectional or gated cross-attention over heterogeneous inputs: each input stream (vision, touch, language, LiDAR) gets its own encoder; interaction happens via attention (QKV computed from different sources) or learned gating (gate one stream by causal influence from others); output is weighted sum over all streams
Transformers are permutation-equivariant within a single modality. Multi-modal fusion adds cross-modal attention: a visual token queries against language and force tokens, so the softmax distribution picks across sensory boundaries. Some papers replace this with state-space models or causal gates, which ask: does stream A actually influence stream B? The mathematical lever is the same—reweight sums by learned attention scores—but applied to edges between domains rather than within them.
RoBiFusion: A Robust and Bidirectional Interaction Camera-LiDAR 3D Obj — Runs cross-attention at multiple depths: early fusion with Σ_j w_{ij}^{early}·v_j^L + w_{ij}^{early}·v_j^C, late fusion with separate heads, both bidirectional.
ConViTac: Aligning Visual-Tactile Fusion with Contrastive Representati — Learns shared space via contrastive loss, then fuses q_vision·k_touch / √d in softmax, ensuring same-event vision and touch embeddings align in attention scores.
IDAGC: Adaptive Generalized Human-Robot Collaboration via Human Intent — Encodes vision, language, force, state separately, then fuses inside variational posterior q(z | v,l,f,s), using attention to compute posterior mean μ = Σ_modality w_m·μ_m.
Curb Your Attention: Causal Attention Gating for Robust Trajectory Pre — Runs causal discovery on agent interactions to learn adjacency A_ij, then masks attention: w_ij = softmax(Q·K)·A_ij, blocking spurious correlations.
6The transformer as the policy
token sequence as action trajectory: stack sensory observations, past actions, and return-to-go (reward) as tokens; run transformer forward pass; read next token as next action; repeat via in-context conditioning—Q,K,V all drawn from same sensorimotor rollout
A transformer encoder-decoder typically predicts text. Here, the full sequence (observation, action, observation, action, ...) is treated as one long token stream, and the next-token prediction output is the robot's next control. This leverages the transformer's in-context learning: earlier tokens in the trajectory act as implicit instructions (similar context → similar action), and the attention mechanism broadcasts high-level goals (return-to-go tokens) to influence all future action choices without explicit reward models.
ICRT: In-Context Imitation Learning via Next-Token Prediction — Treats trajectory [s_0, a_0, s_1, a_1, ...] as token sequence, predicts next action via softmax(Q·K)·V attending over in-context demos without explicit learning.
Decision Transformer-Based Drone Trajectory Planning with Dynamic Safe — Conditions next-token action prediction on (return-to-go r, state s, timestep t) context, reframing control as argmax_{a_t} p(a_t | [r,s,t]_<t) via decoder attention.
MuST: Multi-Head Skill Transformer for Long-Horizon Dexterous Manipula — Learns K parallel attention heads h_k, each a skill policy, so Transformer computes mixture p(a | s) = Σ_k softmax(Q·K)_k · policy_k(s), multiplexing behaviors.
CoMamba: Real-time Cooperative Perception Unlocked with State-Space Mo — Replaces multi-agent attention fusion with bidirectional state-space: y_t = C_t·x_t + D_t·u_t, x_t = A_t·x_{t-1} + B_t·u_t, avoiding O(n²) pairwise attention.
The through-line. Attention shifts from hand-crafted geometric operations (convolution, pooling) to learned content-addressed lookup: asking 'which parts are relevant to this query?' and blending their values. Softmax makes the selection differentiable (the field's favorite move for any discrete choice), √d scaling keeps gradients alive, and permutation-equivariance reveals that the core is set-like, not sequence-like—order is added back in separately. The O(n²) wall is not a flaw but a feature of pairwise matching; every speedup method trades something (sparsity, factorization, different similarity) to work around it. The principle runs everywhere the field needs to fuse information: attention, mixture-of-experts, CLIP, DETR, slots, and robotics policies all use the same 'pick and blend' foundation.
