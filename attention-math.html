Soft-weighting to read what matters most

The problem, as a quantity

Vision models must integrate information across space (whole images, patches, 3D points). Convolution is local and repeating; we need a mechanism that can ask 'which parts are relevant to this query?' and blend their values. The challenge is making this selection smooth enough for gradients to flow, cost-efficient enough to scale, and flexible enough to work across modalities and sensor types.

The core ideas — and why they work

Softmax as differentiable selection

weights_j = exp(q · k_j / √d) / Σᵢ exp(q · k_i / √d), output = Σⱼ weights_j · v_j
Softmax converts the dot product q · k_j (a real-valued similarity) into a probability-like weight in (0,1) that sums to 1. This is a soft-argmax: if one match is much stronger, that weight dominates; if several are similar, they share the weight. Crucially, every element contributes a nonzero gradient, so learning can adjust all queries, keys, and values. The output is always a convex combination of the values, so it stays bounded and inside their geometric hull.

Scaling by √d stops saturation

q · k_j / √d scales the dot product before softmax, prevents exp(·) from hitting near-zero or near-one too early
When vectors have dimension d, a random dot product q · k grows as O(√d) in magnitude. Without scaling, the exponent exp(q · k_j) becomes huge (→∞) or tiny (→0), crushing softmax into nearly-delta-function weights. Dividing by √d keeps the logits in a gentle range where softmax is roughly linear in its input, maintaining strong gradients throughout training. This is why modern attention without this scaling fails to learn.

Permutation equivariance via weight-sharing

if rows of Q, K, V are permuted identically, output rows permute the same way
Attention does not depend on the order of input sequences—only on which keys match which queries. If you shuffle your input tokens or spatial positions, the output shuffles the same way, but the computation itself (the match Q · Kᵀ) does not break. This is why attention is so useful for sets and sequences: the model learns relationships, not positions. Positional encodings are added back in to tell the model 'where things are,' but the core mechanism is order-agnostic.

O(n²) cost from pairwise similarity

compute full matrix QKᵀ (n × n), then softmax each row, then multiply by V → cost is O(n² · d)
Attention computes a similarity (dot product) between every query and every key, requiring n² comparisons. For images, n is the number of pixels or patches; for 3D point clouds, n is the point count. This quadratic wall limits attention to smaller contexts (images ~32×32 patches, not 2K×2K pixels). Linear attention, sparse patterns, and hierarchical designs break this wall by choosing which pairs to compare or using kernels that can be factored.

The approaches, as variations on the math

Beating the O(n²) wall: linear attention replaces the softmax computation with a kernel method that factors into O(n · d), trading exact soft-selection for approximate weighting. Re-routing what attention sees: sparse attention (local windows, strided patterns, learned routing) selects which keys each query can attend to, reducing n² to n · k for some small k. Positional encoding (sinusoidal, RoPE, ALiBi) re-injects order after the permutation-equivariant weighting, using rotating phases or relative-position biases so nearby patches are upweighted. Interpretability via attention weights: humans and diagnostics read the softmax weights as explanation heatmaps, showing which patches influenced which predictions (a low-bar proxy for what the model 'saw'). Cross-attention: replace K, V from a different modality or time-step, fusing sensors (image + lidar) or temporal frames (current frame attends to history). Transformer as policy: in robotics, action tokens attend to image features and proprioception, predicting the next motor command via weighted state aggregation.

The through-line. Attention is a fundamental shift from hand-crafted geometric operations (convolution, pooling) to learned similarity. By making selection smooth and differentiable, it unlocks end-to-end learning of what to look at and how to combine it—a principle that scales from image patches to 3D points to multi-sensor fusion. The √d scaling and positional encoding are the small details that make this principle work in practice.
