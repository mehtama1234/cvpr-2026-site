1 · Adapting on the fly: entropy, batch-norm, and prototypes at test time

At deployment, real-world data drifts from training distributions, but models freeze after training. Test-time adaptation solves this by learning from unlabeled test streams without retraining. Three core strategies emerge: entropy minimization (confident predictions on uncertain test samples), batch-norm statistics (lightweight layer-wise updates), and prototypes (per-class anchors that adapt to new domains). This deep read traces how vision models stay accurate through distribution shifts in weather, panoramic geometry, segmentation, and vision-language tasks—keeping the learned world relevant as the real world changes.
CVPR'26STAR: Test-Time Adaptation Can Enhance Universal Prompt Learning for Vision-Language Models
Problem
Prompt-tuned vision-language models degrade on out-of-distribution test data and make overconfident predictions on unseen distributions, limiting deployment reliability in open-world scenarios.
Approach
Uses Fisher Information scores per-sample to measure prediction separability, gating entropy-based pseudo-labels only for reliable, low-entropy samples. Maintains class-wise prototype memory across test batches to avoid collapse on OOD subsets.
Why it matters
Once deployed, prompts lock in place—but unlabeled test data reveals which samples are trustworthy. Selective entropy minimization plus prototypes lets vision-language models adapt their prompts without corrupting what they already learned.
CVPR'26Mixture of Prototypes for Test-time Adaptive Segmentation
Problem
Standard test-time adaptation uses single class prototypes, missing within-class diversity. Distribution shifts vary across test samples, but existing methods treat all samples uniformly without accounting for this variation.
Approach
Creates multiple domain experts by clustering prototypes to capture source diversity. A gating network dynamically weights experts per test instance based on correlations. Min-max entropy encourages confident predictions while ensuring all experts are used.
Why it matters
Real segmentation scenes contain diverse variants of each class (roads in sun vs. rain, buildings far vs. near). Multiple expert prototypes let the model activate the right internal representation for each new test image without forgetting its original training.
CVPR'26CD-Buffer: Complementary Dual-Buffer Framework for Test-Time Adaptation in Adverse Weather
Problem
Object detection fails under rain, snow, and fog, but additive refinement methods work best on mild shifts while subtractive pruning dominates under severe shifts. A single strategy cannot handle the full spectrum.
Approach
Measures per-channel domain discrepancy from batch-norm statistics, then dynamically balances two buffers: a subtractive mask suppresses corrupted channels, while an additive refinement module compensates with learned residuals. Severely shifted channels get both removal and strong compensation.
Why it matters
Fog dims signals, rain saturates channels, snow fools depth cues—each degrades the model differently. Real deployment faces mixed severities. Adaptively combining removal and refinement via batch-norm discrepancy keeps detection working across any weather.
CVPR'26Denoise and Align: Towards Source-Free UDA for Robust Panoramic Semantic Segmentation
Problem
Panoramic 360° images distort geometry compared to pinhole training. Without source labels (source-free constraint) and with imbalanced class distributions, pseudo-labels become unreliable guides for test-time adaptation.
Approach
Denoises pseudo-labels by enforcing perturbation consistency and filtering with neighborhood confidence. Cross-resolution attention alignment bridges fine details (high-res crops) with scene context (low-res full views), addressing panoramic distortions and scale variance.
Why it matters
Indoor VR and 360° autonomous driving require learning on-the-fly from unlabeled new imagery without access to labeled training scenes. Denoise-and-align keeps semantic understanding robust as pinhole models encounter equirectangular geometry for the first time.

2 · Test-time tuning: adapting a frozen model per input

Test-time adaptation brings the flexibility of learning to inference without model retraining. Rather than fine-tuning parameters offline on a dataset, these methods take a frozen foundation model and adapt per-input by tuning prompts, weighting decisions, or guiding attention based on the test sample itself. Some methods add no labels, using only gradient signals or self-consistency; others rely on lightweight feedback from the environment or visual evidence. This theme explores practical strategies for in-the-wild adaptation: calibrating prompt embeddings to match test-time uncertainty, using perturbations and delayed feedback to correct action overconfidence, harnessing attention patterns to refocus on visual detail, and grounding reasoning step-by-step in visual evidence.
CVPR'26Improving Calibration in Test-Time Prompt Tuning for Vision-Language Models via Data-Free Flatness-Aware Prompt Pretraining
Problem
Vision-language models adapted at test time via prompt tuning produce poorly calibrated predictions: confidence does not align with accuracy. Existing regularization approaches improve calibration but degrade downstream performance.
Approach
Identifies that calibration correlates with prompts converging to flat regions of the loss landscape. Proposes Flatness-Aware Prompt Pretraining (FPP): initialize prompts in flat-minimum regions before test-time tuning begins, using alignment and flatness losses that require no labels. Integration with existing test-time prompt tuning is seamless.
Why it matters
At test time, the model stays frozen; only prompt embeddings are adapted. By starting from a flatter initialization, subsequent test-time tuning produces both better calibration and better performance simultaneously, with zero additional cost at inference.
CVPR'26Test-Time Perturbation Tuning with Delayed Feedback for Vision-Language-Action Models
Problem
Vision-language-action models overfit to task-irrelevant visual patterns during training, then reproduce learned action sequences at test time regardless of actual object poses, causing failure under small environmental shifts.
Approach
PDF (Perturbation with Delayed Feedback) uses uncertainty-based action voting to adaptively allocate augmentation budgets, then applies a lightweight perturbation module that retrospectively adjusts action logits guided by environment feedback. No verifier training or base model fine-tuning required.
Why it matters
At test time, the model itself remains frozen; only a small adapter corrects action logits per trajectory based on delayed environmental signals. This corrects overconfidence and trajectory overfitting without retraining.
CVPR'26Seeing What Matters: A Training-Free Self-Guided Framework for Multimodal Detail Perception and Reasoning
Problem
Multimodal models struggle with fine-grained visual details: attention sinks onto irrelevant regions, and fixed resolution prevents zooming into detail. Detail-sensitive tasks like reading text in images suffer.
Approach
SLoFo (Scan-Locate-Focus) runs entirely at inference without training: uses gradient backpropagation and PCA reconstruction error to identify semantically important and structurally unique visual regions, then progressively prunes attention over multiple transformer layers while retaining focused regions.
Why it matters
The frozen model processes data identically, but internal attention and tokens are dynamically reallocated per input based on self-guided visual signals. No retraining or external supervision; the model itself provides the guidance through its existing attention patterns and feature structure.
CVPR'26See It, Say It, Sorted: An Iterative Training-Free Framework for Visually-Grounded Multimodal Reasoning in LVLMs
Problem
Long chain-of-thought reasoning in vision-language models drifts from visual grounding: language priors dominate, leading to hallucinated conclusions even if earlier logic was sound. Existing learned zooming/cropping policies are expensive and model-specific.
Approach
ECRD (Evidence-Constrained Reweighting Decoding) maintains a pool of textual evidence at test time. At each decoding step, an uncertainty test optionally triggers a lightweight visual decider to extract micro-observations with image coordinates. Token selection mixes base model distribution with evidence-induced preference.
Why it matters
The base model stays frozen; only decoding is adjusted per input to re-weight candidate tokens toward evidence-grounded choices. The visual decider activates only when needed, keeping inference cost low while binding reasoning to visual ground truth.

3 · Adapting to the moment: test-time adaptation for video, action, and viewpoint

Test-time adaptation lets models learn from the test stream itself, with no new labels required. A video arriving at inference shows a new viewpoint, a different action sequence, or a shifted visual style. These papers ask: can we adapt the model at test time using only the data moment we encounter? From ego-centric to exo-centric action anticipation, interactive video segmentation that learns from user corrections on the fly, cross-view geo-localization that handles unknown viewing angles, to domain-shift-proof object detection that mixes content and style—each approach treats the test data as the only supervision signal.
CVPR'26Test-time Ego-Exo-centric Adaptation for Action Anticipation via Multi-Label Prototype Growing and Dual-Clue Consistency
Problem
Ego-centric and exo-centric views of the same action show large temporal-spatial gaps and occlusions. Adapting from one viewpoint to another at test time—without labeled target examples or retraining—requires bridging these gaps while handling multiple overlapping actions.
Approach
Uses a Dual-Clue enhanced Prototype Growing Network that adapts online during inference. Multi-label prototypes grow via entropy-weighted memory to handle overlapping actions. A lightweight narrator generates textual clues about action progression, then visual and textual logits are aligned via dual-clue consistency to cross the ego-exo gap at test time.
Why it matters
The test stream carries its own clues: visual motion patterns and implicit action language. By adapting prototype memory and enforcing consistency between visual and textual signals during inference, the model learns to navigate the viewpoint shift without external labels.
CVPR'26Live Interactive Training for Video Segmentation
Problem
Interactive segmentation systems like SAM2 accept user corrections to fix immediate mask errors, but discard the learning signal once used. Users repeat similar corrections across frames, wasting effort on the same failure modes across a video.
Approach
Live Interactive Training (LIT) trains lightweight LoRA modules on-the-fly when users provide corrections during inference. Each correction is immediately folded back into the model via a parameter-efficient update, so the learned correction generalizes to subsequent frames of the same video.
Why it matters
The test video itself is the teacher. Each user correction carries domain knowledge about the specific scene, occlusions, and errors at that moment. Adapting immediately to that correction means subsequent frames benefit without requiring the user to repeat the same fix.
CVPR'26SinGeo: Unlock Single Model's Potential for Robust Cross-View Geo-Localization
Problem
Existing cross-view geo-localization models are trained on fixed camera fields of view (FoV) and orientations. When tested on unseen FoVs or unknown viewing angles, they collapse. Practitioners deploy separate models per FoV, complicating real-world use.
Approach
SinGeo uses a progressive curriculum learning strategy that schedules difficulty from simple to challenging viewing conditions. Dual discriminative learning branches enhance per-view feature quality. The model learns to adapt its internal representations across FoVs without explicit transformations or auxiliary modules.
Why it matters
The test query's unknown viewpoint is a natural curriculum signal. By training to handle progressively harder viewpoint shifts, the model learns to extract view-invariant geo-spatial clues from the test image itself, generalizing to extreme FoVs it has never seen.
CVPR'26Generalizable Co-Salient Object Detection via Mixed Content-Style Modulation
Problem
Co-salient object detection finds common objects across image groups, but models memorize domain-specific textures and lighting. When tested on new camera types, lighting conditions, or visual styles, segmentation fails because the model overfit to seen appearance statistics.
Approach
CoMCS uses CLIP to extract domain-robust semantic content, then applies randomized AdaIN-style modulation during training that mixes channel statistics with scaled Gaussian noise. This forces the model to ignore low-level style cues and rely on content. A semantic collaborative module aligns co-objects across the group using hyperspherical prototypes.
Why it matters
The test image's style—its texture, lighting, camera response—is a signal to ignore. By training with randomized style mixing, the model learns to factor out appearance statistics and focus on content structure, making it robust to any visual style in the test group without adaptation.

4 · When the road shifts: adapting driving policies and perception to new domains

A robot or vehicle trained in one world rarely survives first contact with another. Weather changes the ground from asphalt to ice. A highway becomes a muddy road. Nighttime reverses daylight into shadow. The policy that drove perfectly yesterday now crashes into things it should see but does not. This is the test-time adaptation problem: when the ground truth shifts after training ends, the system must either adapt on the fly or fail catastrophically. These papers attack the problem from three angles: letting the policy learn which of its own predictions to trust, retraining perception without labels, and grafting small learnable modules onto frozen models to capture new domains while keeping old ones alive.
ROBOTICS'25LoRD: Adapting Differentiable Driving Policies to Distribution Shifts
Problem
A learned self-driving system trained in one environment performs worse when moved to a new location, and adapting it tends to make it forget how to drive in the original environment. The model overfits to the new data and erases old knowledge, creating a tradeoff between old and new performance.
Approach
A small low-rank add-on module (LoRD) is inserted into the driving model and trained on data from the new environment while the rest of the model stays mostly unchanged, keeping old knowledge intact. Only a small part of the model learns; the backbone is frozen to prevent catastrophic forgetting.
Why it matters
Changing only a small part of the model limits how much old knowledge gets overwritten, so performance in the new environment improves without large losses in the original one. The policy adapts to the distribution shift without collapsing its capability on the domain it was built for.
ROBOTICS'25Validity Learning on Failures: Mitigating the Distribution Shift in Autonomous Vehicle Planning
Problem
A self-driving car trained by copying expert drives makes growing errors once it reaches situations the expert never encountered, and there are no expert labels available for those failure states. When the planner faces a distribution shift, it has no way to know it is wrong.
Approach
They let the existing planner drive, record the situations where it fails, and train a second model on those unlabeled failure situations to judge which planned paths are safe versus not without needing an expert to re-annotate anything. A validity classifier learns to distinguish good plans from bad ones using only the self-driving system's own experience.
Why it matters
By training on actual failure cases, the validity model learns exactly what the planner gets wrong, letting it filter out bad plans at the moments that matter most. The car adapts by learning to distrust itself when it enters unfamiliar territory, rather than blindly executing invalid plans.
ROBOTICS'25RMSeg-UDA: Unsupervised Domain Adaptation for Road Marking Segmentation Under Adverse Conditions
Problem
Models that detect road markings from clear daytime images fail badly at night and in rain, and there are no labeled examples of road markings under those bad conditions to retrain with. The perception system crashes the moment weather changes because it was never trained on adverse domains.
Approach
They adapt the model using only unlabeled rainy and nighttime images: a self-training step gradually assigns labels to those images, while an adversarial training step forces the model to produce similar outputs for both normal and adverse conditions, class by class. The two losses pull the model toward domain invariance without requiring human annotation.
Why it matters
The two steps together push the model to treat adverse-condition images more like the normal-condition ones it was trained on, closing the gap without needing any manual labels. Road perception adapts at deployment time to weather shifts by teaching itself to recognize markings under conditions it was never explicitly shown.
ROBOTICS'25Commonsense Reasoning for Legged Robot Adaptation with Vision-Language Models
Problem
A legged robot encounters unexpected obstacles—a gap to crawl through, debris to climb—and fails because its controller was never programmed for those specific situations. When the terrain shifts, the policy has no way to reason about novel obstacles.
Approach
VLM-Predictive Control (VLM-PC) sends the robot's camera view and history of recent moves to a vision-language model, which decides several steps of locomotion skills in advance and replans online if things do not go as expected. The VLM carries broad knowledge from internet-scale pretraining and applies it to physical reasoning in real time.
Why it matters
A vision-language model carries broad everyday knowledge about how things work physically, so it can reason about new obstacles and pick suitable movement skills without any task-specific training. The policy adapts to novel domains by grounding a pre-trained commonsense model in the robot's proprioceptive feedback and live camera feed.

5 · Adapting online: self-supervised and meta-learned adaptation on the robot

A deployed robot must adapt to the specific conditions it encounters—wind gusts, unfamiliar terrain, unknown objects, lighting changes—without access to labeled data or retraining. The papers in this collection show four complementary paths to online adaptation: training the entire control network to anticipate disturbances and safely update all layers in flight; grounding neural motion estimation in classical features then updating selectively when scene type shifts; adjusting manipulation commands on the fly from tactile feedback without object models; and replanning navigation efficiently as new obstacles appear. Together, they show how robots stay accurate and responsive after deployment by learning from their own experience.
ROBOTICS'25Self-Supervised Meta-Learning for All-Layer DNN-Based Adaptive Control with Stability Guarantees
Problem
Control systems that use neural networks to adapt to sudden forces or disturbances can only update a small part of the network online, which limits how fast and how well they adapt.
Approach
Before deployment, the full neural network is trained offline to predict upcoming disturbances from recent movement history using a self-consistency signal (no labels needed). During flight, all layers of the network update in real time within a control loop that is mathematically proven to remain stable.
Why it matters
Training the whole network to anticipate disturbances and proving that updating all layers stays safe lets the controller correct for large wind gusts far faster than methods that freeze most of the network.
ROBOTICS'25ORB-SfMLearner: ORB-Guided Self-supervised Visual Odometry with Selective Online Adaptation
Problem
Deep learning methods for tracking a camera's movement through a scene are less accurate than classical feature-based methods and struggle when the environment looks different from training data.
Approach
The method feeds hand-crafted visual features (ORB keypoints) into a self-supervised neural network that estimates motion, using attention to let the network focus on reliable feature matches; when the scene type changes, the network updates only a small set of its weights on the fly to adapt.
Why it matters
Anchoring the neural network to reliable classical features improves baseline accuracy, and updating only selected weights during a domain change lets the network adjust fast without forgetting what it already learned.
ROBOTICS'25Enhancing Adaptivity of Two-Fingered Object Reorientation Using Tactile-Based Online Optimization of Deconstructed Actions
Problem
Rotating an object to a new angle with just two fingers is hard when the object's shape and weight are unknown, because the contact forces change unpredictably and the fingers must stay within tight limits.
Approach
The system splits finger commands into three separate types based on their purpose (moving toward the goal, staying within limits, coordinating the two fingers), measures the actual touch forces with tactile sensors, and then updates each command type on the fly using gradient-based math to keep everything consistent.
Why it matters
Breaking the command into separate types means each part can be adjusted independently using direct sensor feedback, so the robot adapts to unexpected contacts without needing a model of the object.
ROBOTICS'25Air-FAR: Fast and Adaptable Routing for Aerial Navigation in Large-Scale Complex Unknown Environments
Problem
Planning a 3D flight path through a large unknown space with thousands of obstacles in real time is too slow with standard graph-search methods.
Approach
Air-FAR builds a layered visibility map that only updates the parts of the graph affected by new sensor data, then finds a near-shortest path by dividing the space and solving smaller sub-problems in sequence (divide-and-conquer).
Why it matters
Updating only what changed instead of rebuilding the full map each time, combined with breaking the path search into smaller pieces, keeps planning fast enough to run in real time on a flying drone.

6 · Closing the gap: sim-to-real and cross-modal adaptation

A model trained in one world often fails in another: simulation versus reality, or one sensor modality versus another. Test-time adaptation techniques let systems close these distribution shifts by learning or adjusting on-the-fly in the target domain, without retraining. Whether through compact state representations that transfer better than raw pixels, multi-modal sensor fusion that adapts to new environments, or clever feature alignment that runs efficiently on robot hardware, these papers show how adaptation and alignment principles let a single trained model work across domains. The core insight is honest and grounded: measure the gap, bridge it locally, and keep the model fast enough to matter on real robots.
ROBOTICS'25Watch Less, Feel More: Sim-to-Real RL for Generalizable Articulated Object Manipulation via Motion Adaptation and Impedance Control
Problem
Reinforcement learning policies trained in simulation to manipulate doors and drawers fail on real objects because raw camera and point cloud inputs differ drastically between simulation and reality.
Approach
The policy operates on compact state signals from off-the-shelf perception modules rather than raw images, tracking object motion to infer properties, and uses impedance control that adjusts force based on resistance felt in both training and deployment.
Why it matters
Compact state representations change less between sim and real than raw pixels do; force-sensitive control lets the robot feel and adjust to real-world friction and stiffness that simulation cannot replicate, closing the distribution gap through embodied feedback.
ROBOTICS'25Manipulability Transfer and Tracking Control: Bridging Domain Adaptation with Predictive Feasibility
Problem
When human arm motions are replayed on a robot arm with different kinematics, the robot gets stuck in unreachable positions because the two systems have different ranges of motion.
Approach
The system converts the human arm's manipulability ellipsoid into the robot's joint space, checks feasibility along the entire path before execution, and uses a quadratic program controller to maintain the desired shape throughout motion.
Why it matters
Adapting human manipulability to robot capability space before motion closes the feasibility gap; predictive checking prevents start-stop failures, letting one controller work across different morphologies through geometric alignment.
ROBOTICS'25Multi-Modality Test-Time Adaptation for Semantic Segmentation in Robotic Perception
Problem
Scene-understanding models degrade when deployed to new environments, and existing adaptation methods handle only single sensor types like camera alone, not multi-modal setups like camera plus laser scanner.
Approach
A teacher-student framework guides adaptation while a fusion module blends camera and laser features based on confidence scores from each sensor; laser 3D positions sharpen camera-based predictions in the new domain.
Why it matters
Multi-modal adaptation at test time closes the domain gap by leveraging complementary sensor strengths: laser depth corrects camera features, uncertainty-weighted fusion lets both modalities guide each other, avoiding reliance on any single noisy source.
ROBOTICS'25A Light-Weight Framework for Open-Set Object Detection with Decoupled Feature Alignment in Joint Space
Problem
Open-set object detectors that recognize unseen categories are too computationally expensive for real-time deployment on resource-constrained robot platforms.
Approach
DOSOD replaces expensive per-frame cross-modal matching in YOLO-World with a small learned adapter that maps text and image features to the same space once during setup, then runs standard fast detection at inference.
Why it matters
Decoupling the language-image alignment step from real-time detection bridges the speed-accuracy gap through one-time feature alignment; the adapter closes the vision-language modality gap upfront so runtime stays efficient on edge hardware.
