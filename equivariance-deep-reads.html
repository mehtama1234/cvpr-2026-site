1 · Built-in symmetry: rotation and SE(3)-equivariant networks

Equivariance bakes a known geometric symmetry into a network so it does not have to learn it from raw data. When you rotate the input by 90 degrees, the output rotates the same way—guaranteed by design, not by luck. This principle applies across domains: 3D point clouds benefit from respecting rigid motion (SE(3)) symmetries, panoramic imagery needs rotation awareness on spheres (SO(3)), and remote sensing must handle arbitrary viewing angles. The payoff is measurable: better data efficiency, robustness to unseen poses, and cleaner transfer between domains (sim-to-real). Rather than augmenting data or hoping the model learns these symmetries, equivariant architectures encode them directly into convolutions, transformers, and kernels.
CVPR'26Learning Coordinate-based Convolutional Kernels for Continuous SE(3) Equivariant and Efficient Point Cloud Analysis
Problem
3D point cloud networks face a hard choice: use strict group convolutions that respect rigid motion (rotation and translation) but demand expensive irreducible representation math, or use discrete methods that sacrifice true symmetry for speed. Neither path scales well to real-world problems.
Approach
ECKConv (Equivariant Coordinate-based Kernel Convolution) embeds SE(3) symmetry via an intertwiner framework with kernels in double coset space. It replaces costly representation decomposition with coordinate-based MLPs that learn symmetric kernel parameters directly from normalized local neighbors, keeping computation and memory lean.
Why it matters
By building SE(3) symmetry into the kernel itself, the model avoids learning that rigid motion does not change shape—a property true for all point clouds. This frees up data and capacity for task-specific patterns, improving performance on classification, segmentation, and pose estimation without augmentation tricks.
CVPR'26SO(3)-Equivariant ViT-Adapter for Data-Efficient Zero-Shot Sim-to-Real Indoor Panoramic Depth Estimation
Problem
Perspective-trained vision models fail on panoramic imagery because equirectangular projections distort space and rotation relationships. A frozen ViT backbone, trained on perspective scenes, cannot predict depth for 360-degree views without relearning how rotations affect geometry.
Approach
An SO(3)-Equivariant ViT-Adapter wraps the frozen ViT with trainable modules: an Equivariant Spherical Prior Module (ESPM) based on spherical CNNs extracts rotation-equivariant features via Wigner-D matrices on a spherical grid, and a deformable attention module fuses these with ViT features while respecting the spherical manifold geometry.
Why it matters
By making the adapter rotation-equivariant on the sphere, it translates the ViT's learned depth priors to any rotation without retraining. Training on 6,500 synthetic panoramas then generalizes to real data—a data efficiency win that would be impossible if the model had to memorize each viewing angle.
CVPR'26Tunable Soft Equivariance with Guarantees
Problem
Real-world data rarely satisfies strict equivariance: a slightly rotated or occluded object breaks perfect symmetry. Yet rigid equivariance can hurt performance when the task contains noise or asymmetries. Existing soft-equivariance methods require specialized architectures and cannot adapt pre-trained foundation models.
Approach
A projection-based framework constructs soft-equivariant layers by modifying model weights into a designated subspace. It extends anti-aliasing ideas from CNNs to arbitrary groups (rotation, reflection), with theoretical bounds on how much equivariance error grows. The method works with any pre-trained backbone—ViT, ResNet, Segformer—without architectural surgery.
Why it matters
Controlling equivariance strength lets you tune the symmetry-expressiveness trade-off for each task. By trading strict symmetry for task performance while keeping most of the data-efficiency benefit, the method proves that a little learned asymmetry, guided by theory, beats either pure equivariance or pure flexibility.
CVPR'26Rotation Invariant and Symmetry Aware Pixel Difference Network for Remote Sensing
Problem
Satellite imagery can arrive at any orientation, and terrain often has natural symmetries (river networks, crop fields). Standard CNNs are blind to rotation; they learn different filters for each angle, wasting data and failing on unseen poses.
Approach
A pixel difference network builds rotation-invariant features by computing differences at multiple angles and pooling them invariantly. It then layers on symmetry awareness via symmetric kernels, group convolutions (C8), and reflection-equivariant processing to capture both rotation-invariance and scene symmetries.
Why it matters
Rather than storing rotated copies of every feature map, rotation invariance bakes angles into the computation. For remote sensing, this means the model generalizes to imagery acquired from new viewpoints immediately, and scene symmetries are no longer learned losses—they are built-in constraints that guide interpretation.

2 · Canonicalize it: aligning inputs to remove the symmetry

Equivariance—building symmetry into every layer—is powerful but data-hungry. A cheaper cousin is canonicalization: instead of letting the model handle every rotation, view angle, or configuration variant, align the input first into one canonical pose or representation, so the downstream backbone only ever sees one version of each thing. These four papers take this shortcut across color space (color grading), viewpoint (satellite-ground pose), camera configurations (multi-camera 3D), and orientation (rotating boxes in aerial images). Each frontloads the symmetry-breaking work in a lightweight encoder module—computing a dominant angle in Fourier space, transforming coordinates to polar, modulating features by camera intrinsics—so the core detector or regressor gets cleaner input and learns faster.
CVPR'26CanonCGT: Reference-Based Color Grading via Canonical Pivot Representation
Problem
Color grading methods produce unstable tone mappings that either over-shift colors or inconsistently retain them, failing to preserve color harmony and scene structure when applying a reference style.
Approach
CanonCGT introduces a canonical pivot—a style-neutral intermediate representation. Stage 1 canonicalizes the input by removing intrinsic tonal bias; stage 2 color-grades from this canonical baseline to match reference style, decoupling tonal bias removal and style transfer.
Why it matters
Once you normalize colors into a canonical space, both input and reference sit on the same tonal manifold, so the mapping is simpler and more stable. The model doesn't need to learn style transfer from dozens of natural color distributions—only from one canonical one.
CVPR'26VIRD: View-Invariant Representation through Dual-Axis Transformation for Cross-View Pose Estimation
Problem
Cross-view pose estimation (ground-to-satellite matching) struggles with the viewpoint gap and limited spatial correspondences; geometry-based methods require exact camera calibration and produce artifacts around vertical structures.
Approach
VIRD constructs view-invariant representations through dual-axis transformation: polar transformation aligns horizontal viewpoint differences, and context-enhanced positional attention (CEPA) handles vertical misalignment without requiring camera parameters. View-reconstruction loss trains invariance directly.
Why it matters
By canonicalizing the viewing geometry first—rotating to polar coordinates, normalizing vertical perspective—the pose estimator only needs to match canonical view descriptors, not learn view-dependent corrections for every camera configuration.
CVPR'26CoIn3D: Revisiting Configuration-Invariant Multi-Camera 3D Object Detection
Problem
Multi-camera 3D object detection models fail to generalize to unseen platforms with different camera configurations, as spatial prior discrepancies in focal length, field-of-view, mounting positions, and array layouts overwhelm domain-invariant features.
Approach
CoIn3D explicitly embeds spatial priors via Spatial-aware Feature Modulation: four pixel-level embeddings encode inverse focal map, ground depth gradients, and Plücker ray coordinates, normalizing all camera configurations into a shared geometric space before detection heads.
Why it matters
Rather than asking the backbone to handle cameras with different focal lengths and orientations, canonicalize by modulating features with the actual camera parameters first. The detector then works on intrinsic-invariant, extrinsic-normalized BEV features.
CVPR'26Fourier Angle Alignment for Oriented Object Detection in Remote Sensing
Problem
Oriented object detection suffers from directional incoherence across FPN scales (coarse high-level orientations versus precise low-level cues) and a task conflict where one RoI feature must support both rotation-invariant classification and rotation-sensitive angle regression.
Approach
Fourier Angle Alignment (FAA) estimates each feature map's dominant orientation via 2D DFT spectral analysis, then rotates the feature to a canonical 0-degree reference. FAAFusion applies this at the neck; FAA Head applies it at detection, aligning the RoI feature before splitting into classification and regression branches.
Why it matters
The Fourier spectrum of rectangular objects reveals orientation directly: rather than learning orientation invariance across all scales and feature types, rotate everything to canonical 0 degrees upfront. The detector sees normalized boxes and learns faster.

3 · Symmetry as structure and prior: detecting it, preserving it, obeying it

Symmetry is not merely aesthetic—it is a powerful structural prior about the world. These papers span the full arc of symmetry in deep learning: detecting it from images (architectural facades), preserving it during generation (pose-invariant diffusion), analyzing it as a semantic invariant in classifiers, and obeying it as a physical law (conservation laws in world models). Whether explicit (reflectional symmetry in geometry) or implicit (invariance to pose or null-space structure), symmetry constrains the hypothesis space and grounds models in the physical and semantic structure of data.
CVPR'26ArchSym: Detecting 3D-Grounded Architectural Symmetries in the Wild
Problem
Existing symmetry detection methods fail on real-world architectural scenes because they are trained on synthetic or object-centric datasets and cannot handle monocular scale ambiguity—the fundamental challenge of inferring true 3D structure from a single image.
Approach
ArchSym detects 3D-grounded reflectional symmetries by parameterizing them as signed distance maps relative to predicted scene geometry, resolving scale ambiguity. A scalable annotation pipeline leverages structure-from-motion (SfM) reconstructions to automatically curate a large-scale dataset of in-the-wild landmark symmetries.
Why it matters
Symmetry is structure: the model explicitly learns to detect and localize symmetries as a 3D geometric property, treating symmetry as a hard constraint that should be satisfied by the 3D scene. This geometric grounding is the prior that makes monocular detection possible.
CVPR'26Semantic Alignment for Pose-Invariant Identity Preserving Diffusion
Problem
Controllable diffusion methods struggle to preserve identity when changing pose or structure because they re-synthesize appearance features to fit new spatial configurations, causing identity leakage and loss of fine-grained subject details.
Approach
SeAl (Semantic Alignment) preserves identity by infusing it directly via semantic matching of U-Net attention key-value pairs rather than re-imagining features. Three modules handle spatial alignment (AnchorAlign), identity injection via semantic matching, and mediation of text-appearance conflicts (Delta-Bridge).
Why it matters
Pose-invariance is a prior: the model respects the invariant that identity should remain constant across pose changes by aligning identity features semantically rather than spatially, effectively enforcing that pose transformations should not alter the core subject representation.
CVPR'26Make it SING: Analyzing Semantic Invariants in Classifiers
Problem
Classifiers possess null-space invariants—input transformations that do not change the output—but these remain unexplained and uninterpretable, obscuring what spurious correlations or semantic leakage the model may harbor.
Approach
SING decomposes the null space of classifier layers via SVD and maps discovered invariant directions into CLIP's vision-language space using learned translators. This yields human-readable semantic explanations and visual examples of what the classifier treats as interchangeable.
Why it matters
Semantic invariance is structure: by grounding null-space geometry in vision-language semantics, the method reveals which visual transformations the classifier deems irrelevant, exposing the implicit priors (sometimes spurious) embedded in the model.
CVPR'26DreamSAC: Learning Hamiltonian World Models via Symmetry Exploration
Problem
Learned world models capture statistical correlations but fail to extrapolate to novel physical scenarios because they do not internalize conservation laws and physical invariances—the true symmetries governing dynamics.
Approach
DreamSAC combines Hamiltonian-based intrinsic motivation (symmetry exploration) to collect physically informative data with a Hamiltonian world model trained via contrastive learning. The Hamiltonian structure encodes conservation laws, enabling the model to respect the symmetries of physics.
Why it matters
Physical symmetry is a prior: by building the world model around Hamiltonian mechanics and energy conservation, the method imposes a deep structural constraint that forces extrapolation to respect the true invariants of the physical world rather than learned correlations.

4 · Geometry-aware and data-efficient: equivariance for grasping and policy

Equivariance and geometric deep learning embed physics-aware symmetries directly into model architecture, allowing networks to reason about 3D rotations, scales, and rigid transformations the way classical mechanics does. Rather than learning these symmetries from data, equivariant networks bake them in as inductive biases. This approach proves especially powerful for robotic manipulation and 3D perception: dexterous grasping networks that respect object rotation and scale reduce training data by 80%; visuomotor policies using SE(3)-equivariance achieve better sample efficiency; depth estimation on spherical panoramas can transfer from synthetic domains with minimal real data. The core insight is that geometric structure is not a task-specific quirk but a built-in prior that lets models generalize to novel poses and objects with far fewer labeled examples.
CVPR'26GeoDexGrasp: Geometry-aware Generation for Data-efficient and Physics-plausible Dexterous Grasping
Problem
Generating physically plausible dexterous grasps for arbitrary objects requires large labeled datasets and fails to generalize to novel object geometries. Existing methods ignore how grasp configurations scale and rotate with object shape, leading to high penetration rates and poor physical plausibility.
Approach
GeoDexGrasp uses a SIM(3)-equivariant network backbone that disentangles two complementary feature types: rotation/scale-equivariant features that transform predictably with object pose (encoding grasp orientation), and SIM(3)-invariant features that remain constant under pose changes (encoding object shape). Self-supervised pretraining aligns these representations, then a three-stage diffusion pipeline generates grasp configurations: first sampling root rotation on SO(3), then generating hand pose and contact via diffusion conditioned on shape features, finally refining via physics simulation.
Why it matters
SIM(3)-equivariance acts as a geometric prior that encodes how grasps must transform when an object rotates or scales. This constraint dramatically reduces the hypothesis space the model must search, enabling learning from fewer than 20% of the training samples required by non-equivariant methods while achieving lower penetration rates (40% reduction) and competitive success rates on novel object categories.
CVPR'26Efficient Hybrid SE3-Equivariant Visuomotor Flow Policy via Spherical Harmonics
Problem
Visuomotor policies must understand 3D manipulator geometry and respond consistently to object rotations, but standard CNNs lack geometric inductive biases, requiring large amounts of sample data to learn rotation consistency implicitly.
Approach
This work constructs an SE(3)-equivariant visuomotor policy by representing visual features on the sphere using spherical harmonics basis functions rather than sampling dense rotational grids. A flow-matching module then generates action distributions that respect SE(3) transformations, with a hybrid architecture combining equivariant backbone modules for rigid spatial reasoning and learned non-equivariant components for task flexibility.
Why it matters
SE(3)-equivariance ensures the policy responds identically to rotated and translated observations, eliminating the need to learn this symmetry from data. Spherical harmonics basis representation achieves this efficiency without expensive rotational augmentation, improving sample efficiency and enabling generalization to novel object poses without extra training examples.
CVPR'262D-LFM: Lifting Foundation Model without 3D Supervision
Problem
Single-image 3D shape lifting requires either expensive 3D labeled datasets or permutation-equivariant transformers that lose landmark correspondence information. Existing depth foundation models produce geometrically distorted reconstructions across diverse object categories.
Approach
2D-LFM recovers geometric correspondence within transformers by injecting structure-from-motion-inspired positional encodings at every layer rather than relying solely on permutation equivariance. This correspondence-aware encoding restores the model's ability to reason geometrically about how 2D landmarks map to consistent 3D structure, trained exclusively on 2D landmark supervision across 45+ object categories.
Why it matters
Correspondence encodings act as a geometric prior that enforces landmark consistency across the model depth, recovering the implicit geometric reasoning needed for 3D lifting without requiring expensive 3D labels. This geometric structure embedded in the encoder reduces the learning burden, allowing a single model to generalize across diverse object types and achieve 8.1mm MPJPE versus >100mm MPJPE from non-geometric methods.
CVPR'26SO(3)-Equivariant ViT-Adapter for Data-Efficient Zero-Shot Sim-to-Real Indoor Panoramic Depth Estimation
Problem
Perspective-pretrained vision transformers lack rotational consistency on panoramic (360-degree) imagery due to equirectangular projection distortions. Zero-shot transfer from perspective to panoramic depth fails, and collecting large-scale real panoramic depth data is prohibitively costly.
Approach
An SO(3)-Equivariant ViT-Adapter augments a frozen Depth Anything ViT backbone with trainable modules: an Equivariant Spherical Prior Module using spherical convolutions (S2Conv and SO3Conv with Wigner-D matrices) to extract rotation-equivariant features on the sphere, plus an SO(3) Deformable Cross-Attention module that aligns features on the spherical manifold using rotation-consistent Spherical Contextual Relative Positional Encoding.
Why it matters
SO(3)-equivariance on the spherical manifold enforces that depth estimates respond consistently to panoramic rotations, embedding 3D geometric structure as a hard architectural constraint. This prior enables training on only 6,548 synthetic panoramas without real data, achieving zero-shot sim-to-real transfer that outperforms methods using real unlabeled data and demonstrating that geometry can substitute for large-scale real-world supervision.

5 · SE(3) in the action space: equivariant manipulation and control

In robotics, the state and actions of the world are fundamentally geometric: objects move through 3D space, and their poses live on the Lie group SE(3) (rigid transformations). When a policy respects this structure—outputting object trajectories or control signals that transform predictably under rotations and reflections—it inherits a powerful prior: generalization across placements, sample efficiency, and compatibility with real physics. The papers here show how building SE(3) and equivariance into the network itself—whether through diffusion models that operate on poses, learned reward functions that respect group symmetries, or controllers that handle rotations correctly—makes robot learning faster and more reliable.
ROBOTICS'25SPOT: SE(3) Pose Trajectory Diffusion for Object-Centric Manipulation
Problem
Imitation learning policies are tied to a specific robot body; demonstrations from one robot or human hands cannot easily teach a different robot to perform the same task.
Approach
Tasks are described as object movements in 3D space (SE(3) pose trajectories) rather than robot joint motions; a diffusion policy then converts those object trajectories into actions for any available robot, learning from as few as eight demonstrations including videos of human hands.
Why it matters
Describing tasks in terms of what the object does, not what the robot does, separates the goal from the body, allowing any robot to follow the same object-centric instructions.
ROBOTICS'25Simultaneous Pick and Place Detection by Combining SE(3) Diffusion Models with Differential Kinematics
Problem
Grasp pose generators often produce poses the robot arm physically cannot reach, or that conflict with where the object needs to be placed, requiring slow filtering after generation.
Approach
An SE(3) diffusion model proposes grasp poses; while refining them, it simultaneously checks that the arm can reach both the grasp and target placement spot using joint-limit-aware inverse kinematics to steer refinement.
Why it matters
Enforcing reachability and placement compatibility during generation rather than after reduces wasted candidates and ensures consistent success without extra computation.
ROBOTICS'25Reinforcement Learning with Lie Group Orientations for Robotics
Problem
Common 3D rotation representations (Euler angles, quaternions) fed into learning algorithms do not match the true mathematical structure of rotation, slowing learning and hurting performance.
Approach
Inputs and outputs of the neural network are encoded and decoded to respect the correct Lie group structure of 3D rotation (SO(3)); this small change to how data enters and leaves the network requires no other algorithmic modifications.
Why it matters
When data format matches the true structure of rotations, the network sees consistent, meaningful inputs and training signals are cleaner, so controllers learn faster and perform better.
ROBOTICS'25Deep Equivariant Multi-Agent Control Barrier Functions
Problem
Teaching groups of robots to stay safe around each other using learned safety rules does not scale well because learning ignores that safety rules look the same under rotation or reordering of the group.
Approach
Safety rules and control policies are built using neural networks whose outputs change predictably under rotations or permutations (equivariant networks), so robots can share learning across all these symmetric situations.
Why it matters
Because networks understand that rotations and reorderings do not change the underlying problem, far less training data is needed, and learned rules work immediately on larger swarms the system was never trained on.

6 · Equivariant estimation and canonical perception: symmetry in a robot's state

A robot's pose in the world, the shape of an object it manipulates, or its trajectory through space all obey symmetries—invariances under rotation, translation, or reflection. Equivariant neural networks and geometric estimation methods respect these symmetries, ensuring that when a robot or object rotates, the learned representation transforms in a mathematically consistent way rather than breaking down. Canonical representations anchor objects and poses to a meaningful frame—upright, forward-facing, or aligned to natural geometry—so that perception remains robust across viewpoint and context. Whether building filters that fuse distance-only measurements into a SLAM estimate, learning grasp-ready object poses without labels, distilling driving policies across diverse environments, or planning navigation on asymmetric terrain, respecting symmetry makes estimation tighter, policies more transferable, and planning more efficient. These four papers show how symmetry and invariance run through state estimation, 3D perception, imitation learning, and navigation planning.
ROBOTICS'25Equivariant Filter Design for Range-Only SLAM
Problem
Tracking a robot's position using only distance measurements to fixed points is unreliable when those landmark locations are unknown ahead of time, forcing the filter to estimate both pose and map simultaneously without initialization.
Approach
The filter is designed around a Lie group symmetry structure that matches how distance measurements behave under rigid motion, so the estimation equations respect the group action directly rather than using a generic filter that ignores the problem's geometric structure.
Why it matters
By building the filter on the correct symmetry of range-only measurement and rigid-body motion, estimation errors shrink faster and more reliably; the filter's convergence exploits the fact that the robot's pose and landmark positions live in a symmetric space where translation and rotation act predictably.
ROBOTICS'25Learning Upright and Forward-Facing Object Poses using Category-level Canonical Representations
Problem
Discovering a canonical orientation for a category of objects—like all chairs or mugs—without labeled data is difficult when objects within a category vary widely, and standard methods fail to align to a physically meaningful upright-and-forward frame.
Approach
The method uses an SE(3)-equivariant network that processes paired views of the same object and separates shape from pose; surface-orientation labels derived from unlabeled in-the-wild data anchor the learned canonical frame to a true upright direction.
Why it matters
The equivariant architecture ensures that when an object rotates, the learned pose representation transforms in a mathematically consistent way; anchoring to surface normals tethers the canonical frame to a pose that respects the object's intrinsic geometry rather than settling on an arbitrary one.
ROBOTICS'25Multi-Task Invariant Representation Imitation Learning for Autonomous Driving
Problem
A driving policy trained by copying human demonstrations learns to rely on irrelevant environment-specific cues that break when deployed in new locations, making the policy unsafe and non-transferable.
Approach
MIRIL trains on multiple diverse driving environments simultaneously and enforces invariant risk minimization: the shared representation learns only features that predict driving actions consistently across all environments, while separate output heads specialize steering, scene prediction, and dynamics.
Why it matters
A feature that only predicts actions in one environment but not others receives canceling gradients during training; the invariance constraint forces the shared representation to capture only truly directional symmetries—steering relationships, collision physics, lane geometry—that hold across contexts.
ROBOTICS'25QuasiNav: Asymmetric Cost-Aware Navigation Planning with Constrained Quasimetric Reinforcement Learning
Problem
Standard robot navigation assumes motion costs the same in all directions, but real terrain like hills and mud impose directional asymmetries—uphill costs more energy than downhill—that standard symmetric metrics cannot represent.
Approach
The system uses a quasimetric embedding that captures direction-dependent costs and trains a reinforcement-learning policy with tightening safety constraints; the quasimetric structure explicitly breaks symmetry where the environment does, modeling one-way energy expenditure.
Why it matters
By embedding asymmetric costs directly into the geometric structure of the cost space, the planner learns paths that genuinely optimize for terrain directionality; respecting the one-way structure of the environment—rather than symmetrizing it away—makes planning both efficient and safe.
