1 · Calibrating confidence: making 90 percent mean 90 percent

When a neural network says it is 90% confident, that confidence is almost never reliable. Calibration fixes this mismatch: it adjusts the output scores so that a predicted 90% confidence actually corresponds to 90% correctness. This theme covers four approaches to the same core problem—making confidence trustworthy in vision and language models, with and without labeled data, and with formal mathematical guarantees.
CVPR'26Improving Calibration in Test-Time Prompt Tuning for Vision-Language Models via Data-Free Flatness-Aware Prompt Pretraining
Problem
Vision-language models adapted via Test-Time Prompt Tuning (TPT) often become overconfident when they shift to new data, producing predictions whose confidence scores do not match their true accuracy. Existing calibration methods fix this via regularization, but they often sacrifice performance.
Approach
This work identifies that prompts initialized in flat regions of the loss landscape—where small perturbations do not sharply increase loss—naturally produce more calibrated outputs. It proposes Flatness-Aware Prompt Pretraining (FPP), a data-free pretraining step that initializes prompts in these flat regions before any test-time adaptation begins, requiring no labeled data or extra computation at test time.
Why it matters
By understanding the connection between loss-landscape geometry and calibration, the method improves both reliability of confidence scores and downstream accuracy at once, giving practitioners a practical way to deploy adapted VLMs with confidence they can trust.

Approach
InsCal combines calibration-aware objectives with prompt tuning during test-time adaptation, adjusting prediction scores and class logits in real time using only the test data itself. CVPR'26LATA: Laplacian-Assisted Transductive Adaptation for Conformal Uncertainty in Medical VLMs
Problem
Medical vision-language models provide predictions without labeled data (zero-shot), but they lack calibrated uncertainty. Conformal prediction can wrap outputs in prediction sets with a guaranteed coverage rate, but adapting a model to new medical data with labels breaks that mathematical guarantee, and naive conformal methods produce inefficiently large sets.
Approach
LATA performs label-free transductive refinement on a kNN graph of images, smoothing zero-shot probabilities using a graph Laplacian while preserving conformal validity via symmetric transformations. It pairs this with failure-aware conformal scores that penalize uncertain medical images, tightening prediction sets without violating coverage guarantees.
Why it matters
In medical imaging, formal coverage guarantees are non-negotiable, yet efficiency matters too. LATA delivers both: mathematically valid 95% coverage with 7-12% tighter prediction sets than prior methods, all without retraining the model or needing labeled calibration data.

2 · Knowing the unknown: out-of-distribution detection

A classifier trained on one world is dangerously confident on unfamiliar inputs, unable to flag what it has never seen. Out-of-distribution detection teaches models to recognize the boundary of their training data and abstain from predictions beyond it. This matters urgently: autonomous vehicles must reject anomalous objects, medical systems must flag pathologies unseen in training, and deployed classifiers in shifting environments must know when to ask for human help. The papers below explore ranking-based scoring, distribution priors for geometry, co-occurrence patterns, and vision-language consistency—each attacking the core challenge of teaching confidence to mean what we want it to mean.
CVPR'26RankOOD - Class Ranking-based Out-of-Distribution Detection
Problem
Existing OOD detection methods either stay simple and compatible but underutilize network information, or require retraining at the cost of reduced accuracy on known classes. The field lacks a unified way to capture how class predictions should co-vary when the model is certain versus when it encounters a stranger.
Approach
RankOOD trains a second round using the Plackett-Luce loss on learned class rankings. Each class gets a fixed rank permutation; during inference, OOD examples that assign high probability to an ID class but violate its learned ranking structure are flagged as unfamiliar.
Why it matters
By modeling entire output rankings rather than single scores, the method captures inter-class dependencies that reveal when a prediction pattern is out-of-character for the model—teaching the network to say not just this is class A but this ranking makes sense for class A.

Problem

Approach
Neural Distribution Prior (NDP) learns adaptive reweighting of OOD scores via cross-attention to a learnable distribution matrix, paired with Perlin noise-based synthetic OOD generation and soft labels for uncertain void regions. 3 · Two kinds of doubt: aleatoric and epistemic uncertainty

Aleatoric uncertainty is irreducible noise baked into the data itself—a pixel too ambiguous to label clearly, a trajectory with genuine multimodal futures. Epistemic uncertainty is the model's own ignorance, the gaps in its learned causal structure or domain knowledge. Systems that distinguish these two can quantify not just a prediction, but how much to trust it: is this wrong because the data is inherently fuzzy, or because the model has never seen this pattern before? These four papers build that distinction rigorously—from medical segmentation through causal inference to trajectory forecasting—each grounding uncertainty in the actual patterns that make prediction hard.
CVPR'26Delving Aleatoric Uncertainty in Medical Image Segmentation via Vision Foundation Models
Problem
Medical image segmentation requires reliable uncertainty estimation to identify samples that may misguide training. Existing methods struggle to quantify the intrinsic ambiguity of noisy or borderline samples—the aleatoric uncertainty that lives in the pixels themselves, not the model's knowledge gaps.
Approach
Uses feature vectors from medical vision foundation models to measure aleatoric uncertainty via singular value energy distribution. Easy-to-segment samples show high energy diversity across singular values; noisy, ambiguous samples show sparse, concentrated distributions. This metric then filters misguided training samples and adjusts loss dynamically based on sample difficulty.
Why it matters
By measuring aleatoric noise at the pixel level, the system avoids training on inherently contradictory examples and focuses learning on samples the model can actually resolve. Separating data noise from model ignorance sharpens what the segmenter can learn to trust.

Problem

Approach

Learns the causal structure of inter-channel dependencies in each domain, constrains transport plans to preserve these structures, and uses entropy-aware pseudo-labeling to select only high-confidence samples where the learned causal model is trustworthy.

CVPR'26CGU-BAYES: Causal Graph Uncertainty-Guided Bayesian Inference for Domain Generalization
Problem
Limited or biased data produces inaccurate causal graph estimates, leaving the model uncertain about which features actually drive outcomes. Standard approaches pick a single causal graph without capturing epistemic uncertainty about whether the structure is correct for unseen domains.
Approach
Performs Bayesian inference over causal graph structure itself—sampling multiple plausible graphs from posterior distribution, extracting invariant causal features from each, and quantifying how well each graph fits unseen test domains. Aggregates predictions using these uncertainty estimates as weights in a weighted Bayesian scheme.
Why it matters
Causal uncertainty directly reflects model doubt about which relationships transfer across domains. Weighting predictions by graph reliability ensures that in distribution shift, the system trusts predictions grounded in robust causal structures and discounts those resting on domain-specific artifacts.

4 · When the model makes things up: detecting hallucination and knowing when to abstain

Modern vision-language models hallucinate with high confidence, inventing objects, attributes, or events that never appear in the image or video. Uncertainty for the VLM era means detecting when the model is unsure—or when it should be unsure—and building the capacity to abstain. This theme brings together four complementary strategies: fine-grained detection of where hallucinations occur at the span level, uncertainty-guided lookback during long reasoning chains, frame-level detection of stitched chimera hallucinations in video, and direct training for embodied agents to know when they lack the evidence to answer. Together, they show the path forward: not a single detector, but a toolkit for knowing when not to answer.
CVPR'26ZINA: Multimodal Fine-grained Hallucination Detection and Editing
Problem
MLLMs generate hallucinations—outputs that deviate from visual content—but existing detection is coarse-grained, classifying only broad categories or detecting at sentence level. Diverse hallucination forms (objects, attributes, numbers, relations) require fine-grained span-level detection with error-type classification for comprehensive evaluation and correction.
Approach
ZINA separates the problem into two components: a detector identifying hallucinated spans and a reviewer determining tag placement and suggesting refinements. The method is trained on VisionHall, a dataset of 6.9k real MLLM outputs (from 12 models, 211 annotators) plus 20k synthetic samples via graph-based error injection. A six-category taxonomy classifies hallucinations into Object, Attribute, Number, Text, Relation, and Fact, enabling both detection and correction.
Why it matters
Uncertainty at the span level is the path to reliability. By knowing where a model went wrong and what type of error it made, downstream systems—or human reviewers—can decide whether to trust the hallucination or request correction. Fine-grained detection is the first step toward trustworthy multimodal AI.

CVPR'26When to Think and When to Look: Uncertainty-Guided Lookback
Problem
Large vision-language models in thinking mode generate long reasoning chains that often ignore the visual input, producing long-wrong trajectories that underperform standard instruct mode on visual recognition tasks.
Approach
The method uses a token-level visual sensitivity probe: for each step in the thinking trace, compute perplexity under real image, noise image, and no image conditions. This reveals pause phrases (where the model mentions but ignores the image) and lookback templates (phrases that successfully re-anchor reasoning to the visual content). At test time, when a pause phrase is detected during reasoning, a lookback prompt is injected to redirect the model back to the image. Optional parallel sampling selects the continuation with highest visual grounding.
Why it matters
Uncertainty in long reasoning chains is silent: the model generates plausible text divorced from visual evidence. By identifying where reasoning drifts and injecting lookback prompts, the model can be nudged to ground itself. This is training-free and works across families—a lightweight uncertainty correction that doesn't require retraining.

CVPR'26Unstitching the Chimera: Frame-Level Risk and Train-Free Mitigation for Video Hallucination
Problem
Video MLLMs suffer from Chimera Hallucination: stitching visual segments from causally unrelated events into a spurious continuous narrative. This failure mode—where the model links frames that do not belong together—is prevalent in video and differs mechanistically from object hallucination.
Approach
CH-Risk is a single-forward, reference-free measure combining segment coverage (how many event segments are needed to cover a fraction of text-to-frame support, exposing stitching) and alignment with early temporal pathway (checking if evidence follows the causal main pathway learned in early layers). CH-M (Chimera Mitigation) is a train-free two-stage intervention at inference time: segment-aligned frame routing favors aligned segments, and residual token calibration clips over-dominant tokens within segments.
Why it matters
Video hallucination requires a frame-first view, not token-level image analysis. By detecting when the model stitches unrelated frames and applying lightweight post-hoc corrections, the model can be steered toward coherent temporal reasoning without any parameter updates. Uncertainty here means knowing which frames actually support which claims.

CVPR'26When Robots Should Say "I Don't Know": Benchmarking Abstention in Embodied Question Answering
Problem
Existing embodied question answering benchmarks assume agents must answer every query, ignoring that real-world communication often involves incomplete information, ambiguous instructions, or missing evidence. Forcing responses without sufficient evidence causes hallucinations and safety risks.
Approach
AbstainEQA introduces a benchmark with 1,636 human-annotated abstention cases paired with original OpenEQA instances. Five abstention categories derived from cognitive error theory guide annotation: actionability limitation (unavailable capabilities), referential underspecification (ambiguous references), preference dependence (missing subjective context), information unavailability (unobserved evidence), and false presupposition (invalid assumptions). Evaluation measures how often agents correctly recognize when they should decline to answer.
Why it matters
Uncertainty is not just about confidence scores—it is about knowing when you don't know. An embodied agent that hallucinates an answer to an unanswerable question can cause physical harm. By training agents to abstain when evidence is missing or references are ambiguous, robots can maintain trust and safety. Abstention is the embodied face of uncertainty.

5 · Acting under doubt: uncertainty-aware grasping and risk-bounded planning

On a robot, uncertainty is not an academic afterthought—a confident but wrong grasp leads to a failed pick, and a misjudged trajectory becomes a collision. This deep-dive explores how robots learn to measure their own doubt and use it to act safely. From underwater grasping in murky reconstructions to autonomous vehicles predicting human intent, the papers here share a vision: quantify the gap between what you see and what is, then route decisions through that gap. Some robots calibrate grasps to high-confidence geometry regions. Others bound total risk in a planning horizon so no single mistake breaks the budget. A few harvest human priors to narrow the space of possible worlds before acting. In each case, uncertainty is not paralyzing—it is a signal that guides the robot toward robust, safe action.
ROBOTICS'25PUGS: Perceptual Uncertainty for Grasp Selection in Underwater Environments
Problem
Underwater 3D scans are noisy and incomplete, so a robot picking objects underwater may try to grab based on corrupted geometry and fail.
Approach
The system learns to score how uncertain each part of the 3D scan is, then ranks potential grasps to favor holds in well-measured regions over poorly measured ones. By filtering grasps through a confidence map of the scene, the robot avoids committing to contacts it cannot trust.
Why it matters
A grasp is only as good as the geometry it rests on. By refusing to grab in regions the sensor barely sees, the robot selects holds that match reality, not the sensor's hallucinations.

6 · Knowing the unknown and when to ask: OOD and human-in-the-loop for robots

Uncertainty is not a problem to minimize away—it is the signal that triggers the most important robot behavior: stopping and asking for help. Whether a robot encounters unfamiliar objects, rare scenarios, or food types outside its training, the systems that matter most are those that recognize the boundary of their knowledge and defer to humans at exactly the right moment. This theme traces four approaches to embodied uncertainty: generating out-of-distribution scenarios to stress-test autonomy, anchoring language reasoning to a robot's own internal state (not just vision), learning when asking is worth the human cost, and recovering from perception failures at object boundaries—the edges where a robot's confidence should rightfully fall.
ROBOTICS'25Generating Out-of-Distribution Scenarios Using Language Models
Problem
Autonomous vehicles are rarely tested on rare or strange driving scenarios that would most likely cause crashes, because such situations almost never appear in real-world driving data.
Approach
A large language model generates a branching tree of unusual driving scenarios, and automated tools construct those scenarios in a simulator (CARLA). Vision-language models are then evaluated on their ability to handle those unfamiliar situations.
Why it matters
Generating rare cases through language reveals where a system's confidence exceeds its actual capability—the unseen OOD cases that demand either robust fallback or human intervention.

ROBOTICS'25To Ask or not to Ask: Human-in-the-loop Contextual Bandits with Applications in Robot-Assisted Feeding
Problem
A robot helping people eat encounters food types it cannot handle, but asking the user for help too often is tiring—especially for people with limited mobility.
Approach
The system uses a contextual bandit (LINUCB-QG) that learns when asking is justified by predicting how much effort a question imposes on a particular user before deciding whether to ask.
Why it matters
Uncertainty about food type becomes the trigger to ask, but only when the cost to the human is worth the robot's gain—turning the decision to ask into a learned, personalized judgment call.

ROBOTICS'25High-Quality Unknown Object Instance Segmentation via Quadruple Boundary Error Refinement
Problem
When a robot looks at a cluttered scene, early object detection often leaves messy edges—objects merged or split incorrectly—causing grasping failures.
Approach
QuBER refines boundaries by classifying each edge pixel into one of four error types, then uses that error map to fix both fine and coarse boundary mistakes without redoing the full detection.
Why it matters
Boundaries are where the robot's confidence should be lowest; by targeting error correction at those edges, the system recovers certainty in the instances most critical for safe grasping.
