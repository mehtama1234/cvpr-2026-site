Detection as a set — DETR across CVPR & Robotics

The why page argued the idea from first principles: a fixed set of learnable queries each emit one object, matched one-to-one to the ground truth, so the anchor grid and the de-duplication pass both disappear. This page shows what happened next — the query-decoder-plus-matching template stopped being a detector and became the default architecture for detection, segmentation, tracking, counting, and grounding. Below, the same machinery with its query re-pointed at a new kind of thing. Real papers for every use, from the analyzed corpora.

How big it is

Two things to hold onto. In vision, DETR won by deletion — removing the anchor grid and the NMS pass — and that clean set-prediction frame turned out to fit almost every task where the answer is a variable-length set of things. In robotics, the same deletion (no NMS to babysit) plus the fact that a scene is now a small set of object vectors is exactly what makes perception cheap to run and cheap to share between agents.

The uses — one template, its query re-pointed

Six threads. Uses 1-5 are the vision work (the detector itself, then set prediction spreading to segments, to a universal query interface, to tracking-through-time, and into 3D / open-vocabulary); use 6 is the robotics crossover (CVPR'26 vision · ROBOTICS'25 ICRA/IROS).

1 · The end-to-end detector, still being fixed

The original job — one clean set-prediction detector, no anchors, no NMS. Nobody re-derives vanilla DETR; they harden the queries against the things that break them: catastrophic forgetting when new classes arrive, class imbalance, and the slow-convergence tax. The query-and-matching core stays; the training around it gets smarter.
Mathematical move

Quantity. In 1 · The end-to-end detector, still being fixed, the recurring quantity is the set of objects and their one-to-one assignments.

Rule. The mathematical rule is to use object queries plus matching loss so each real instance is claimed once instead of detected through duplicate proposals.

Why this use exists. The same set-prediction rule is reused for boxes, masks, parts, tracks, lanes, and robot targets.

CVPR'26EW-DETR: Evolving World Object Detection via Incremental Low-Rank DEtection TRansformer — couples incremental learning, domain adaptation and unknown-object detection into one exemplar-free detection transformer that keeps growing its world.
CVPR'26Parameterized Prompt for Incremental Object Detection — feeds the detector small learnable prompts (fused by top-k importance + directional consistency) so it learns new classes without forgetting old ones.
CVPR'26Balanced Hierarchical Contrastive Learning with Decoupled Queries for Fine-grained Object Detection in Remote Sensing Images — decouples the DETR queries per hierarchy level to fight data imbalance and task interference in fine-grained detection.

3 · The query as a universal interface

A query is just a learnable slot that attends to the input and emits one answer — so it need not stand for an object at all. It can stand for a thing to count, a human-object interaction, a video moment, a grounded phrase. The interface outlived the task it was invented for.

4 · Queries that persist — tracking and video

Carry a query across frames and it becomes a track: the same slot follows one object through time, so multi-object tracking and video segmentation become set prediction over a video. The persistence is powerful — and, as one paper shows, a new attack surface.
Mathematical move

Quantity. In 4 · Queries that persist — tracking and video, the recurring quantity is the nearest failure direction or hidden trigger.

Rule. The mathematical rule is to measure worst-case risk around real examples instead of average accuracy alone.

Why this use exists. The use cases differ by where the attack enters: pixels, features, training data, sensors, prompts, or policies.

CVPR'26Out of Sight, Out of Track: Adversarial Attacks on Propagation-based Multi-Object Trackers via Query State Manipulation — exposes how the zero-sum query budget and temporal memory of query-based trackers can be adversarially hijacked.
CVPR'26Progressive Multi-cue Alignment for Unaligned RGBT Tracking — progressively aligns mismatched RGB and thermal cues with difficulty-aware experts for robust query-based tracking.
CVPR'26When Transformers Meet Mamba: A Hybrid Transformer-Mamba Network for Video Object Detection — pairs deformable attention with bidirectional Mamba scanning to carry detection queries efficiently across frames.

5 · Into 3D and the open world

The hardest detection: queries that pull from multi-view geometry or point clouds, name categories never seen in training, or report calibrated uncertainty per prediction. Same set-prediction frame, unfamiliar territory — even edge detection is recast as end-to-end matching.
Mathematical move

Quantity. In 5 · Into 3D and the open world, the recurring quantity is how much the evidence supports the answer.

Rule. The mathematical rule is to make confidence track actual risk by using disagreement, probability shape, residuals, or shift signals.

Why this use exists. The same math matters for abstention, triage, planning, medical review, and safety monitors.

CVPR'26VGGT-Det: Mining VGGT Internal Priors for Sensor-Geometry-Free Multi-View Indoor 3D Object Detection — mines a foundation encoder's internal attention and features so object queries do 3D detection without depth sensors or known geometry.
CVPR'26SRA-Det: Learning Omni-Grained Open-Vocabulary Detection Beyond Category Names — splits each text description into semantic facets with soft-min matching so open-vocabulary queries do not collapse to a single word.
CVPR'26Query2Uncertainty: Robust Uncertainty Quantification and Calibration for 3D Object Detection — fits a normalizing flow to detector query features as a density estimator, giving each 3D detection a calibrated confidence.
CVPR'26MatchED: Crisp Edge Detection Using End-to-End Matching-based Supervision — recasts edge detection as trainable matching-based supervision, replacing the hand-crafted post-processing with the DETR-style end-to-end idea.

6 · On the robot — end-to-end detection you can share

What crossed into robotics is the whole pipeline being end-to-end and NMS-free — cheap to run on-board — and one deeper trick: because a scene is now a small set of object queries, one agent can compress what it sees into queries and send just those, and a matching step fuses them with another agent's. Set prediction becomes shared perception.

What changes when the set is something to act on

Same set prediction — a different reason to want it.

axisCVPR 2026 (vision)Robotics 2025 (ICRA+IROS)
What a query stands foran object, mask, track, count, or phrase to reportan object to act on — or a compact summary to transmit
Why NMS-free matterscleaner training, one end-to-end lossless to tune and less to compute on-board, in real time

The standing costslow convergence — better matching, denoising, deformable attentionsame slow training, plus a fixed query budget under a bandwidth limit
The through-line. DETR turned detection into predicting a set: a fixed row of query slots, each emitting one thing, matched one-to-one so duplicates cannot form and the hand-built clean-up pass vanishes. That frame was so clean it stopped being about objects — re-point the query and it segments, tracks, counts, or grounds, which is why query-based decoders are now the default across vision. In robotics the same NMS-free pipeline runs on-board, and because a scene is now a handful of object queries, one robot can compress its view into them and share it with another. Vision predicts a set to report; a robot predicts a set to act on and pass along.
